一、公司概况

主营业务与产品服务

Cerebras Systems（总部加州 Sunnyvale，2026 年 5 月在 Nasdaq 上市，代码 CBRS）是晶圆级（wafer-scale）AI 芯片公司：底层是 Wafer-Scale Engine（WSE）系列超大芯片（当前主力 WSE-3 / WSE-3 Turbo，单芯片 4 万亿晶体管、90 万个 AI 核心），向上分为整机系统（CS-3、CS-4 机架级方案）与云服务（Inference Cloud 推理 API、Training Cloud 训练云）两层收入结构，主打"全球最快 AI 推理"（官方宣称比 GPU 方案快至 30 倍）。

整体战略方向

  • 从"训练用晶圆级超算"转型为"推理优先"：CS-4（2026-08 发布）明确面向 frontier 模型推理与 agentic AI 负载
  • 云化分发：Inference Cloud 按 token 计费、OpenAI API 兼容，同时提供 Dedicated 与 On-Prem 部署，覆盖数据主权/合规场景
  • 生态借力：与 OpenAI（GPT-5.6 Sol Ultrafast、Codex-Spark 上 Cerebras）、Meta（Llama API）、AWS（Trainium + CS-3 分离式推理）、AMD（Helios + WSE 分离式推理）等头部方结盟，借其渠道进入主流市场
  • 产能扩张：与 Flex 合作在硅谷 Milpitas 扩产 CS-3（预期产能提升 7 倍），并在北美/欧洲扩建数据中心（如芬兰 Mikkeli 165MW 项目）
  • Sovereign AI：以整机 + 云服务帮助国家/地区建自主 AI 算力（G42 Condor Galaxy、韩国 Upstage 合作等）

二、产品分类

整机系统

  • CS-4：2026-08 发布的新一代机架级方案，集成 3 颗 WSE-3 Turbo，主打超大规模推理（官方称比 GPU 快至 30 倍），2026 年三季度开始出货
  • CS-3：现役 AI 超算系统（WSE-3 驱动），支持训练与推理，由 Flex 在硅谷代工扩产
  • Condor Galaxy：与 G42 合作的超算集群网络（CG-1 达 4 exaFLOPs FP16）

芯片

  • WSE-3 Turbo（WSE-3T）：当前旗舰晶圆级处理器，4 万亿晶体管、90 万 AI 核心、250 PFLOPS 算力、43.2 PB/s 片内内存带宽
  • WSE-3：上一代旗舰，支撑 CS-3 系统
  • Wafer Scale Engine SDK：面向底层的开发工具包

云平台产品

  • Inference Cloud：推理 API 服务，按 token 计费，OpenAI API 兼容，上架 GPT-5.6 Sol Ultrafast、Kimi K2.6、GLM-4.7、Gemma 4、Qwen、Llama 等模型（GPT-5.6 Sol Ultrafast 官方称达 750 token/s）
  • Training Cloud：训练/微调云，宣称无需 sharding 与模型并行改写即可训练 1B 至数十万亿参数模型

三、服务分类

推理服务

  • 公共端点按量计费（pay-as-you-go），免费试用，<30 秒接入
  • Dedicated 专属实例与 On-Prem 本地部署，满足延迟、数据驻留与合规要求
  • Multi-LoRA 等多租户微调模型服务能力

训练与模型服务

  • Training Cloud：按训练需求弹性计量，含预配置环境、安全存储与网络
  • Model Development（AI Model Services）：由 Cerebras 专家团队为客户定制设计、训练、微调 SOTA 模型（"数周交付定制模型"）
  • 数据与模型所有权承诺：客户数据/模型不被存储、记录或复用

开发者支持

  • Inference Docs / Training Docs、Cerebras Model Zoo、Hugging Face 集成、OpenRouter 等第三方分发

六、总结

强势业务或产品推荐

  • Inference Cloud：推理速度是其最锋利卖点，OpenAI API 兼容 + 免费试用降低尝试门槛，上架模型覆盖主流开源与 OpenAI 旗舰，值得跟踪其 token 价格与模型上新节奏
  • CS-4 / WSE-3T：晶圆级硬件代际优势明确（带宽、延迟、整机简化），分离式推理（与 AMD、AWS 合作）是其切入数据中心推理市场的关键打法

强势战略留意

  • 与 OpenAI 的绑定深度：GPT-5.6 Sol Ultrafast / Codex-Spark 上 Cerebras 是里程碑式背书，需留意合作是否扩大为长期算力采购
  • 2026-05 上市（CBRS）后的资本开支与数据中心扩张（北美、欧洲、芬兰 165MW），决定其云收入兑现能力
  • 训练→推理的战略重心转移是否持续：训练云与 Model Development 服务仍在，但传播口径已全面转向推理
  • 与 AMD、AWS 的分离式推理若跑通，等于承认"prefill 用 GPU/ASIC、解码用 WSE"的混合架构，对其"全替代 GPU"叙事是修正也是放量机会
