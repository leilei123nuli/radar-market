LimX Dynamics 逐际动力

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：5. 具身智能 | 地区：国内 | 类型：新型 | 成立：2022 护城河：足式机器人运动控制见长

一、公司概况

主营业务与产品服务

逐际动力 LimX Dynamics 是一家具身智能机器人主机厂（全球总部：深圳），专注于通用机器人的研发、制造与商业化应用。产品分两层：硬件侧为全尺寸人形机器人 LimX Oli、LimX Luna 与模块化多形态机器人 TRON 系列；平台/软件侧为人形大脑系统 LimX COSA（具身 Agentic OS）、标准化 VLA 工程底座 FluxVLA Engine（已开源）、具身操作算法 VGM、训练范式 DreamActor 等。公司已完成天使轮、Pre-A、A 轮（阿里巴巴战略领投）、B 轮（2 亿美元，京东战略领投）及 Pre-IPO 轮融资（2026-07，半年合计融资 4 亿美元）。

整体战略方向

  • 定位"具身智能主机厂 + 平台"：三大核心技术为本体硬件原创设计与制造、大小脑融合技术、人形大脑系统 COSA
  • 平台化野心：创始人张巍提出"做具身智能行业的英伟达"，通过开源 FluxVLA Engine、开放 SDK、LandX 开发者社区建设全球开发者生态，释放 AGI 在物理世界的泛化能力
  • 商业化路径：科研教育（TRON 系列低门槛科研平台）→ 商业服务/文旅表演（Luna 群控表演）→ 工业制造（与上汽北京共建具身智能联合实验室等），远期目标是机器人走进千家万户
  • 数据方法论：不堆真机数据，提出多元数据配方策略 LimX Data Recipe 与 DreamActor 训练新范式（含"刷视频学操作"方向，CoRL 2025 双收录）
  • 出海：创始人称三年内向全球交付数千台机器人，Oli 曾亮相 CES 2026 与百度 Create 2026

二、产品分类

人形机器人（全尺寸）

  • LimX Oli：全尺寸通用人形机器人，31 自由度，运控/感知双芯片，自研 6 轴 IMU + 深度相机，快拆模块化设计、电池快速换装，完善二开支持；2025-07 开放预订（¥15.8 万起），2026-07 搭载 COSA 0.5 全自主完成长程移动操作
  • LimX Luna：全尺寸交互人形机器人（2026-05-25 发布），160cm、27 自由度，第二代自研高性能运控引擎，织物包覆外观，主打多模态交互与 200+ 台毫秒级集群表演，面向文旅演出/商业服务场景

多形态模块化机器人（TRON 系列）

  • TRON 1：首款多形态双足机器人（2024-10 发布），"三合一"模块化足端（双点足/双足/双轮足），主打人形 RL 科研入门，全开放 SDK、支持 Python 全流程开发与 NVIDIA Isaac/MuJoCo/Gazebo 仿真
  • TRON 2：多形态具身机器人（2025-12-18 发布，¥4.98 万起），双臂/双足/双轮足自由组合，单臂 7 自由度、双臂 10kg 负载，定位"一站式 VLA 平台"，含自主移动操作与感知建图套件，双轮足模式支持 30kg 负载与自动回充

早期/技术验证产品

  • W1：首款四轮足机器人（2023 发布）
  • P1：双足机器人（2023 年 IROS 发布），2024-03 成为中国首个基于强化学习完成野外徒步的双足机器人
  • CL-1：全尺寸人形机器人技术验证机（2023 首次公开动态测试，2024-08 完成上楼梯/大负载搬运验证），为 Oli 前身

软件/平台产品

  • LimX COSA：人形大脑系统（具身 Agentic OS，2026-01 发布，2026-07 更新至 0.5，含人形 VLA V³-0 全身能力升级）
  • FluxVLA Engine：标准化 VLA 工程底座（2026-04-30 开源，有 GitHub 仓库），单一配置文件管理数据/模型/训练/部署，模块解耦，全流程仿真到真机跑通约 30 分钟
  • LimX VGM：具身机器人操作算法（2026-07 发布）
  • LimX DreamActor：基于多元数据的具身智能训练新范式（2025-09 发布，配 Data Recipe 数据配方策略）
  • FluxTraining：训练平台（官网页脚产品位，公开信息有限）

六、总结

强势业务或产品推荐

  • TRON 系列（科研平台）：¥4.98 万起的 TRON 2 + 全开放 SDK + FluxVLA Engine 开源底座，构成国内具身智能科研入门的高性价比组合，生态打法清晰
  • LimX Oli + COSA 人形大脑：全尺寸人形全自主长程移动操作已落地演示，是"大小脑融合"路线的代表作
  • 运动控制基本功：P1 野外徒步、CL-1 上楼梯等验证记录说明其足式运控为长板，与公司护城河定位一致

强势战略留意

  • 平台化路线（"做具身智能行业的英伟达"）：开源 FluxVLA Engine + LandX 社区能否形成开发者标准，是其从本体厂跃迁为平台厂的关键
  • 融资节奏极快（半年 4 亿美元，阿里/京东先后战略领投，已进 Pre-IPO）：关注 IPO 进程及资本方产业协同（京东物流场景、阿里算力/云）
  • 数据方法论差异化（DreamActor/视频学习，不堆真机数据）：若成立将显著降低具身模型训练成本，值得跟踪其开源与论文产出
  • 商业化兑现：Luna 文旅表演、工业联合实验室、出海交付目标（三年数千台）的实际订单转化
