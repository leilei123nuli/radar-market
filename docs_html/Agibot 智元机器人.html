版本：v1（首次建档） | 建档日期：2026-10-08 赛道：5. 具身智能 | 地区：国内 | 类型：新型 | 成立：2023 护城河：稚晖君创立，全栈自研，量产进度国内最快

一、公司概况

主营业务与产品服务

智元机器人（AGIBOT Innovation (Shanghai) Technology Co., Ltd.）是通用 AI 机器人公司，以具身智能为核心技术方向，公司名即 "AGI + BOT"。业务覆盖机器人本体（人形 AGIBOT A/X/Genie 系列、四足 D1 系列、商用清洁 C5）、核心零部件（OmniHand 灵巧手）、具身数据服务与开源生态（AGIBOT World 数据集、AimRT 框架），按官网口径已建成"机器人平台 + 智能算法 + 开放平台"三大支柱的全栈软硬件体系。据官网援引 IDC 数据，其 2026 年上半年人形机器人出货量全球第一。

整体战略方向

  • 使命"以智能机器创造无限生产力"，愿景是成为全球智能机器人领导者、构建通用机器人生态
  • 全栈自研 + 量产优先：多形态产品矩阵（全尺寸人形、中小型交互人形、四足、清洁机器人、灵巧手）并行推进，量产进度国内最快
  • 商业化以场景落地驱动：交互服务（零售门店）、文娱商演（主题公园群控）、工业制造、商用清洁、科研教育
  • 数据与开放在位：自建具身数据采集方案（AIDEA）+ 开源数据集/框架，形成数据飞轮与开发者生态
  • 出海加速：与越南国家创新中心（NIC）合作、海外零售批量部署（X2 进入 100 家门店）

六、总结

强势业务或产品推荐

  • AGIBOT X2 系列：交互服务人形的出货主力，零售门店批量落地已验证商业化能力
  • AGIBOT A2/A3 全尺寸系列：文娱商演 + 工业双线，车规级测试与量产体系是国内稀缺能力
  • 具身数据服务（AIDEA + AGIBOT World）：数据采集方案 + 开源数据集构成数据飞轮，是区别于纯本体厂商的关键壁垒

强势战略留意

  • 量产与出货领先（官网援引 IDC：2026 H1 人形机器人全球出货第一），关注其毛利与交付质量能否守住
  • "本体 + 数据 + 开源生态"三位一体打法：AimRT、AGIBOT World 若在开发者侧形成标准，护城河将显著加深
  • 出海动作（越南 NIC、海外零售部署）与主题乐园等重运营场景的可复制性
  • 人形 + 四足 + 清洁多线并行的资源聚焦风险，留意产品线收缩或整合信号
