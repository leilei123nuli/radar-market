一、公司概况

主营业务与产品服务

OceanBase 是原生分布式关系型数据库，起源于阿里巴巴/蚂蚁集团的大规模交易场景，2020 年独立商业化。产品支持 HTAP、强一致多副本、金融级高可用和水平扩展，提供自托管数据库、OB Cloud 多云服务、OCP 管理平台、OMS 迁移工具和 OBD 部署工具。客户覆盖金融、政务、电信、互联网和能源等行业，核心卖点是核心交易系统的分布式替换和降本。

整体战略方向

  • 以金融级分布式数据库承接核心系统替换，主打高可用、强一致和低成本
  • 单机分布式一体化，降低中小规模场景的部署门槛
  • 多云 OB Cloud 与私有化部署并行，覆盖不同合规和成本需求
  • 扩展多模能力（JSON、GIS、向量检索），承接 AI 和实时分析场景

二、产品分类

分布式数据库

  • OceanBase Database：原生分布式关系型数据库，支持 HTAP、强一致多副本和水平扩展
  • OceanBase 单机分布式一体化：一套架构兼顾单机部署和分布式扩展，降低中小场景门槛
  • OB Cloud：多云数据库服务，支持 AWS、阿里云、腾讯云等云平台

管理与迁移

  • OCP (OceanBase Cloud Platform)：集群管理、监控、备份和运维平台
  • OMS (OceanBase Migration Service)：异构数据库迁移与实时数据同步
  • OBD (OceanBase Deployer)：数据库自动化部署工具

多模能力

  • OceanBase 向量检索：向量数据类型与索引，支持语义检索和 RAG
  • OceanBase 多模能力：JSON、GIS 等数据类型，支持半结构化和空间数据

三、服务分类

数据库服务

  • 数据库云服务：OB Cloud 托管、弹性扩缩容和按量计费
  • 迁移与实施：核心系统迁移、异构数据库同步
  • 运维与培训：高可用架构、性能调优、认证培训

六、总结

强势业务或产品推荐

  • OceanBase Database：金融级分布式数据库的代表，核心系统替换的主力
  • OB Cloud：多云托管降低使用门槛，承接中小客户和弹性场景
  • OMS / OCP：迁移和运维工具链决定核心系统能否平滑上线

强势战略留意

  • 与达梦、TiDB、华为 GaussDB、云厂商原生数据库在核心系统正面竞争
  • 金融级高可用是优势，但中小客户更关注成本和易用性
  • 向量检索和多模能力是新增量，需观察产品成熟度和生态支持
