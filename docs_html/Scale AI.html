Scale AI

版本：v1（首次建档） | 建档日期：2026-10-29 赛道：3. 云 / 开发者基础设施 | 地区：国外 | 类型：新型 | 成立：2016 护城河：AI 数据引擎与标注/评估服务，前沿模型数据供应链

一、公司概况

主营业务与产品服务

Scale AI 是面向 AI 模型的数据基础设施公司，核心业务是为大模型和自动驾驶等场景提供训练数据生产、标注、评估和 RLHF 服务。Scale Data Engine 把数据采集、标注、质量管理和模型评估串成一条流水线，客户覆盖前沿模型实验室、云厂商、自动驾驶公司、金融机构和公共部门。公司从人工标注起家，逐步转向“数据 + 评估 + 强化学习环境”的生成式 AI 数据服务。

整体战略方向

  • 从人力密集型标注转向平台化的数据引擎和自动化评估
  • 生成式 AI：RLHF、SFT、红队、模型评估和 RL 环境
  • 行业化：自动驾驶、国防/公共部门、金融、医疗等高价值数据场景
  • 数据供应链安全与合规，承接政府和企业的高敏感数据需求

二、产品分类

数据引擎

  • Scale Data Engine：多模态训练数据生产、标注、质量管理和数据集管理平台
  • Scale Rapid：快速数据标注与模型评估服务，面向小批量、高频迭代场景
  • Scale Studio：面向生成式 AI 的数据、提示词和评估工作台

生成式 AI

  • Scale Generative AI：RLHF、SFT、红队和模型评估的一体化数据服务
  • Scale Evaluation：模型能力、安全性和对齐效果评估
  • Scale RL Environments：面向 Agent 和强化学习的交互环境与数据

行业数据

  • Scale Self-Driving：自动驾驶数据标注、采集和仿真数据服务
  • Scale Federal：面向公共部门的安全数据与 AI 服务

三、服务分类

数据服务

  • 数据采集与标注：图像、视频、文本、音频和多模态数据
  • 模型评估与红队：人工评估、自动化评估、安全对齐
  • 数据托管与合规：高敏感数据的隔离、安全和审计

六、总结

强势业务或产品推荐

  • Scale Data Engine：数据生产与管理的核心平台，覆盖多模态和高价值行业数据
  • Scale Generative AI：RLHF/评估/红队一体化，直接服务前沿模型实验室
  • Scale Self-Driving：自动驾驶数据服务是公司早期高价值场景，客户壁垒深

强势战略留意

  • 合成数据和自动化评估可能削弱人工标注的长期价值，公司需要持续平台化
  • 数据标注赛道竞争激烈（Labelbox、Appen、海天瑞声等），价格与合规是差异点
  • 公共部门与国防业务增长快，但受政策和地缘政治影响大
