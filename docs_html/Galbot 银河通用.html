Galbot 银河通用

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：5. 具身智能 | 地区：国内 | 类型：新型 | 成立：2023 护城河：轮式双臂 + 仿真数据驱动，宁德时代/美团投资

一、公司概况

主营业务与产品服务

北京银河通用机器人有限公司成立于 2023 年 5 月（创始人王鹤），是一家以具身大模型为核心的通用机器人公司。底层是自研端到端具身大模型「银河星脑 AstraBrain」（集大脑—小脑—神经控制于一模）与虚实融合数据基建「银河星数 AstraData」（百亿级数据集），向上形成「本体硬件（ET1 / G1 / S1）→ 二次开发平台（GalbotSDK / 场景包 / 定制方案）→ 行业解决方案（零售、工业、教育、医疗、家庭）」的完整产品与服务体系。据公开报道，公司两年累计融资超 24 亿元（截至 2025-06 的 11 亿元 A 轮由宁德时代领投），2026 年报道估值超 200 亿元，2026-09 中标宁德时代 2.36 亿元项目。

整体战略方向

  • 模型优先：以 AstraBrain 大模型 + AstraData 仿真数据基座走「仿真合成数据驱动」路线，强调 Sim2Real 零样本迁移，与依赖真机采集的路线形成差异化
  • 场景闭环：从数据基座构建、模型学习到真实场景落地全链条闭环，零售（银河太空舱、美团买药无人药店）与工业（宁德时代产线）为两大先行场景
  • 全本体覆盖：轮式双臂（G1）、工业重载（S1）、人形演艺（ET1）三线产品，模型跨本体适配
  • 生态化：开放二次开发平台与开发者订阅体系，争夺具身智能开发者生态入口；牵头获批具身智能大模型重点实验室（官网称"中国唯一"）

二、产品分类

机器人本体

  • Galbot G1：通用轮式双臂具身机器人，1730mm 高、单臂负载 5kg、4 轮全向底盘、末端可在灵巧手/吸盘/夹爪间更换，面向零售、工业、康养、教育等场景；另有 G1 Lite 变体
  • Galbot S1：工业重载具身机器人，双臂最高负载 50kg，作业高度 0–2.3m，电池热插拔支持 24/7 连续作业，面向工业、仓储、物流
  • Galbot ET1「银河星仔」：面向娱乐演艺的人形机器人（1250mm、32kg、26 自由度，可配 12 自由度灵巧手），主打实时多模态交互与运动，2026-09 开启预订，官网自称"物理世界原生智能体"

具身大模型（AstraBrain 银河星脑体系）

  • AstraBrain-WAM（通用大脑）：全域数据、跨本体隐式世界-动作基座模型（3B–13B），解决异构数据割裂难题
  • AstraBrain-WBC（通用小脑）：全球首个人形机器人通用小脑 GPT 基础模型，8040 万参数、2 万小时人类动作语料训练
  • AstraBrain-Dex / DexNDM：灵巧手世界模型与神经动力学模型，实现任意姿态下手内旋转等灵巧操作
  • GraspVLA：端到端抓取基座大模型，十亿帧合成「视觉-语言-动作」对预训练，Sim2Real 零样本迁移
  • TrackVLA / NavFoM：端到端具身导航与全域环视导航基座模型，支持自主导航与智能跟随
  • WAM-TTT：后训练部署技术，仅凭无标注人类视频完成模型部署适配
  • Any2Track：人形机器人通用全身追踪系统，已开源通用动作跟踪框架 OpenTrack

三、服务分类

二次开发平台（developer.galbot.com）

  • L1 · GalbotSDK：基础开发工具，覆盖感知、规划、控制、导航、交互五大能力，高低双层接口
  • L2 · 场景开发包：垂直场景半解决方案，已上线迎宾导览方案包，物料分拣、场地巡检方案包规划中
  • 开发者订阅：FREE（¥0）/ PRO（¥5万/机/年）/ ENTERPRISE（¥20万/机/年）三档，含训练营认证、SLA 支持、在线仿真与真机部署权益

交付与运营服务

  • L3 · 端到端定制方案：需求评估 → 方案设计 → 实施 → 长期运维的五阶段交付
  • 银河开拓者训练营：初/中/高级集训与认证，线上线下公开课
  • 仿真资产服务：高保真场景与物品仿真资产、机器人数字模型（URDF / MJCF / USD）

四、解决方案分类

零售

  • 银河太空舱：无人零售舱，官网称已在全国 40 余个城市落地超 170 个点位
  • 商超零售：取货交付、盘点补货全天候自动化
  • 即时零售仓储物流：取货、打包、出仓全流程自主运行，官网称百家即时零售仓 7×24 小时值守、连续作业超一年半；与美团买药合作无人药店

工业

  • 工业搬运/制造：零部件分拣、物料搬运、组装与上下料；已中标宁德时代 2.36 亿元项目（2026-09，公开报道）

教育

  • 面向院校实验室的教育方案，从课程到设备全程交付

其他场景

  • 家庭服务：清洁、整理、取物、拿快递（G1 场景展示）
  • 医疗服务：官网称机器人已在医疗服务场景持续运行（公开信息有限，未披露细节）
  • 娱乐演艺：ET1 游乐场互动、门店迎宾、舞台表演等

六、总结

强势业务或产品推荐

  • G1 + 银河太空舱零售闭环：城市级规模化运营（170+ 点位）在国内具身智能商业化中属第一梯队，值得跟踪单点经济模型
  • AstraBrain / GraspVLA 模型体系：仿真合成数据路线论文产出密集（WAM-TTT、DexNDM 等），技术辨识度强
  • 二次开发平台：三层产品 + 订阅制定价在同类公司中少见，是观察其生态野心的窗口

强势战略留意

  • 宁德时代深度绑定：既是领投方又是大客户（2.36 亿元中标），股东与客户高度重合已引发媒体对其营收质量的质疑（虎嗅 2026-09），需持续观察
  • ET1 演艺人形：从轮式实用路线切入人形演艺市场，预订量与交付情况待验证
  • 资本与 IPO 节奏：三年累计融资约 70 亿元、估值超 200 亿元，媒体多次提及 IPO 动向，上市进展值得跟踪
