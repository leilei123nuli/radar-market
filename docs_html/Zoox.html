一、公司概况

主营业务与产品服务

Zoox 是全自动驾驶网约车（Robotaxi）公司：自研 purpose-built 无人车（无方向盘、无踏板、双向行驶、对坐式车厢），并通过 Zoox App 自营叫车服务，车辆充电、维护、升级均由 Zoox 负责。2020 年加入亚马逊（收购）。当前已在 Las Vegas 正式运营（服务时段 8 a.m.–1 a.m.，含 Harry Reid 机场接驳），San Francisco 处于免费 preview 阶段（App + waitlist 制）；官网"即将上线"城市包括 Austin、Miami、Atlanta、Los Angeles。CEO Aicha Evans，联合创始人兼 CTO Jesse Levinson。

整体战略方向

  • 垂直整合：自研整车 + 自研自动驾驶栈 + 自营出行网络，区别于"改装量产车"路线
  • "It's not a car"：围绕乘客而非司机重新定义车辆形态（对坐布局、无驾驶舱、100+ 项传统汽车没有的安全创新）
  • 安全为先的合规路径：发布 Safety Case Framework 与多份安全报告（2018/2021/2024），取得 Nevada DMV 公共道路运营授权及 FMVSS 相关豁免
  • 依托亚马逊的资本与资源推进多城扩张与量产（2020 年收购后扩产、扩测试至 Las Vegas/Seattle 等）

二、产品分类

整车产品

  • Zoox Robotaxi：专用无人驾驶电动车，无前后之分可双向行驶；四轮转向（窄位路边精准停靠）；电动滑门；主动悬架；对坐式 carriage seating 车厢
  • 传感与计算：摄像头 + lidar + radar + 长波红外传感器组合，360° 感知、探测距离达 200 米，关键系统全冗余、无单点故障

乘客端产品

  • Zoox App：叫车入口（iOS/Android，"GET THE APP"），按城市开放注册与 waitlist
  • 车内交互：每个座位配触摸屏（行程进度/音乐/温控）、分区空调、无线充电、空间音频、氛围灯

三、服务分类

出行服务

  • Las Vegas：正式商业化运营（含 Strip 沿线站点、机场接驳说明），服务时段 8 a.m.–1 a.m.
  • San Francisco：免费试乘 preview（waitlist 制）
  • 规划中：Austin、Miami、Atlanta、Los Angeles

运营与支持服务

  • Mission Control：车队健康与效率监控
  • TeleGuidance：远程操作员为车辆提供引导
  • Zoox Support：车内一键实时人工协助、Emergency Call Button 紧急呼叫
  • First Responders 协作：与急救/警方建立应急协议，车外留联系方式与二维码

四、解决方案分类

自动驾驶技术栈

  • AI-driven mapping：测试车队为运营城市构建并持续更新 3D 高精地图
  • Real-time perception：实时检测与分类行人、车辆、骑行者、障碍物
  • Prediction & collision avoidance：建模预测道路参与者行为，提前规避
  • Intelligent route planning：基于实时数据的城市路径规划

安全体系

  • Safety Case Framework：量化硬件、软件、运营如何共同保障乘车安全，目标是显著优于人类司机
  • 被动安全：环绕式气囊、智能安全带与监测、溃缩区设计
  • 公开安全报告（2018 安全创新 / 2021 设计与功能 / 2024 运营安全）

城市出行方案

  • 全电动车队，定位"更安全、更清洁、更高效"的城市交通替代方案，按城市逐城落地（建图 → 测试 → 授权 → 运营）

六、总结

强势业务或产品推荐

  • Zoox Robotaxi 整车：原生无方向盘设计中进度最靠前的玩家，已获 Nevada 公共道路运营授权与联邦安全标准豁免，落地含金量高
  • Las Vegas 运营：从 preview 走向常态化收费运营的第一个城市，是观察其单位经济模型的窗口

强势战略留意

  • 多城扩张节奏：SF 转正式运营的时间点，以及 Austin/Miami/Atlanta/LA 的落地速度——直接检验"逐城建图运营"模式的可扩展性
  • 与 Waymo（改装车 + 多平台）路线的差异化竞争：purpose-built 的舒适/安全叙事能否转化为获客优势
  • 亚马逊协同的深度：资本输血之外的物流、云、渠道协同尚未显性化，值得跟踪
