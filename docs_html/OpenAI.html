一、公司概况

主营业务与产品服务

OpenAI 是全球 AI 模型与产品双龙头：底层是 GPT 系列基础模型（当前主力为 GPT-6，2026-10-07 发布，主打智能 UI），向上分为消费者产品（ChatGPT、Sora）与开发者/企业服务（API 平台、Agent 工具链）两层收入结构。

整体战略方向

  • 使命导向 AGI，但商业上已转为"模型 → 产品 → 基础设施"三线并进
  • 消费者端：把 ChatGPT 做成超级应用（搜索、购物、浏览器、智能 UI 入口）
  • 企业端：API + Agent SDK + Enterprise 套餐，正面争夺企业 AI 预算
  • 基础设施端：Stargate 计划联合 Oracle、软银等自建超大规模算力，降低对单一云厂商依赖

二、产品分类

消费级产品

  • ChatGPT：核心入口，Free/Plus/Pro 订阅分层，周活全球第一
  • Sora：视频生成产品，独立 App 形态运营
  • ChatGPT Atlas / 智能 UI：浏览器与生成式界面，争夺下一代入口

模型产品

  • GPT-6 系列：旗舰模型（2026-10 发布），主打 Intelligent UI 与推理能力
  • o 系列推理模型：深度推理场景
  • 多模态模型：图像（GPT-image）、语音、视频生成

开发者/企业产品

  • OpenAI API：模型调用平台（Responses API）
  • Codex：编程智能体
  • Agent SDK：智能体开发工具链

三、服务分类

订阅服务

  • ChatGPT Free / Plus / Pro / Team：C 端与小团队订阅
  • ChatGPT Enterprise / Edu：企业与教育版

平台服务

  • API 按量计费：模型推理、微调、向量存储
  • Agent 运行环境：代码执行、浏览、文件检索等工具调用

四、解决方案分类

企业解决方案

  • ChatGPT Enterprise：企业知识库 + 安全合规 + 管理后台
  • 行业落地：金融、医疗、客服等场景的定制部署

生态合作方案

  • 与微软 Azure 的模型分发合作（Azure OpenAI Service）
  • 与硬件/终端厂商的入口级集成（如 Apple Intelligence 合作）

六、总结

强势业务或产品推荐

  • ChatGPT：消费者 AI 入口事实标准，值得持续跟踪其留存与订阅结构
  • API + Agent SDK：开发者生态粘性最强的一环

强势战略留意

  • GPT-6 的 Intelligent UI 方向：交互范式级动作，可能重塑产品形态
  • Stargate 自建算力：资本开支巨大，决定其长期成本曲线
  • 消费者超级应用化（购物/浏览器/支付）与微软渠道的关系演变
