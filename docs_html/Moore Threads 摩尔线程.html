一、公司概况

主营业务与产品服务

摩尔线程成立于 2020 年，以全功能 GPU 为核心，向全球提供加速计算基础设施和一站式解决方案。自研 MUSA 统一系统架构，单颗 GPU 同时支持 AI 计算加速、3D 图形渲染、超高清视频编解码、物理仿真与科学计算等组合工作负载，产品线覆盖"芯片 → 显卡/智算卡 → 整机/模组 → 集群（夸娥 KUAE）"全栈。2025-12-05 正式挂牌科创板（股票代码 688795），成为国内全功能 GPU 第一股之一；截至 2026 年主推 MTT S5000 智算卡与夸娥万卡级智算集群。

整体战略方向

  • "AI 工厂"理念（2025-07 提出）：以系统级工程创新提升大模型训练效率；2026-05 产品发布会进一步提出建设三大"AI 工厂"，打造"全场景 AI 算力基石"
  • "云边端"智算矩阵：云端夸娥智算集群（千卡→万卡，与京东云合作拟建十万卡集群）、边缘 MTT E300 模组、端侧 MTT AIBOOK 算力本与 MTT AICUBE 家庭 AI 中枢
  • 生态适配抢位：对 DeepSeek-V4.1-Flash、智谱 GLM-5.3-Flash 等新模型做 Day-0 适配；与中国移动共建 AI 可信计算生态；切入具身智能（S5000 训练对齐国际主流 GPU、MT Lambda 仿真平台）与 AI4S 科学计算（Protenix-v2 药物研发全链路）
  • 消费端不放弃图形显卡：MTT S80/S70 游戏显卡持续驱动优化，守住"全功能 GPU"差异化定位

二、产品分类

融合智算中心

  • MTT KUAE（夸娥）：基于大模型智算加速卡和训推一体机的一体化交付方案，支持国产全功能 GPU 万卡万亿大模型训练，解决大规模 GPU 算力建设与运营管理问题

系统与设备

  • MTT SGX5000：针对大模型训练集群与推理场景深度优化的服务器硬件系统
  • MTT AIBOOK：AI 算力本，面向"超级个体"开发者，搭载国产芯片、支持多系统
  • MTT AICUBE：家庭 AI 中枢，搭载智能体"小麦"（2026-05 发布）
  • MTT E300：GPU/CPU/NPU 多核异构边缘 AI 模组，面向行业边缘智能
  • 智娱摩方：面向玩家的整机平台

全功能 GPU / 显卡

  • MTT S5000：旗舰智算卡，面向大模型训练、推理与高性能计算，具身 RL 训练曲线对齐国际主流 GPU
  • MTT S4000：针对万亿规模大模型训练/微调/推理优化，兼具图形渲染与超高清显示
  • MTT S3000：4096 个 MUSA 核心，面向 AI 推理训练、云手机、云渲染、视频云（单卡至高 32 路 vGPU 云电脑）
  • MTT S2000：图形渲染 + AI + 编解码 + 科学计算，适配 x86/Arm/LoongArch
  • MTT S80 / S70：消费级游戏显卡（S80 为首款国潮显卡，PCIe Gen5、16GB 显存）
  • MTT X300 / S50：专业视觉加速卡，面向国产化行业图形与创作场景
  • MTT S30 / S10：数字办公显卡，CAD/GIS 等场景

软件

  • 驱动程序：月度更新游戏与应用专项优化
  • MUSA SDK：全功能开发平台（编译器、运行时库、调试工具、API）
  • Moore Perf System：可视化性能分析工具
  • MUSACODE：AI 辅助并行编程工具（代码生成、Kernel/TileLang 算子开发）
  • KUAE AI 训练套件 / AI 推理套件：生产级训练微调与推理部署优化
  • GPU 虚拟化（vGPU）：动态弹性切分，高密度 vGPU 并发
  • KUAE 云原生套件：容器化与 Kubernetes 支持，自动部署与弹性调度
  • PES 控制中心：显卡驱动与状态管理客户端
  • MTVerse XR：OpenXR 应用流式传输到 XR 设备
  • Smart Media Engine：视频编解码/转码/直播，面向云游戏、云桌面等
  • MUSA 科学计算套件：底层数学库到行业应用的科学计算支撑

应用与模型

  • 摩笔马良：基于自研 GPU 的 AI 智能绘画助手
  • MooER 摩耳：语音识别与合成的开源语音工具

六、总结

强势业务或产品推荐

  • 夸娥 KUAE 智算集群：从千卡到万卡、再到与京东云合作的十万卡规划，是其承接国产大模型算力需求的核心抓手
  • MTT S5000 智算卡：当前旗舰，具身 RL 训练对齐国际主流 GPU 的验证值得持续跟踪
  • MUSA 软件栈 + Day-0 模型适配：DeepSeek/GLM 新模型 Day-0 适配能力是其生态竞争力的直接体现

强势战略留意

  • "AI 工厂"与"云边端"矩阵：从卖卡转向系统级算力交付，AICUBE/AIBOOK 等端侧新品类能否起量待观察
  • 科创板上市后资本运作：688795 财报与募资投向是跟踪其扩张节奏的最佳窗口
  • 具身智能与 AI4S 新赛道：MT Lambda 仿真平台、Protenix-v2 药物研发链路，属于从通用算力向垂直场景深化的信号
  • 风险点：消费级显卡直面国际巨头竞争，图形驱动生态仍需长期投入；国产 GPU 同业（华为昇腾、寒武纪、海光等）在智算中心招标中竞争激烈
