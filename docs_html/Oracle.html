一、公司概况

主营业务与产品服务

Oracle（NYSE: ORCL，总部 Austin, Texas）是企业级软件与云计算双料巨头，业务分四层：云基础设施（OCI，IaaS）、云应用（Fusion Cloud Applications + NetSuite，SaaS）、数据库与数据平台（Oracle AI Database 26ai、Exadata，全球第一企业数据库）、传统本地软件授权与硬件。收入结构正快速向云迁移：FY2027 Q1（截至 2026-08-31，2026-09-10 发布）总营收 $19.3B（+30%），其中云收入 $11.6B（+62%，IaaS $7.4B +121%、SaaS $4.2B +10%），本地软件 $5.5B（-3%），服务 $1.4B、硬件 $0.8B。RPO（剩余履约义务）达 $664B，同比 +$209B，主要由 AI 云训练/推理大单驱动。

整体战略方向

  • All-in AI 云基础设施：激进扩产 GPU 数据中心——Q1 新增 850MW 数据中心容量，Q4 FY26 以来向 AI 云客户交付超 30 万块 GPU（约为 Q4 交付量的 3 倍）；Q1 资本开支 $28.5B，自由现金流 -$5.4B，靠发债 + $20B ATM 股权增发 + 客户预付款（$11.4B）支撑扩产。公开报道显示 Oracle 是 Stargate 计划的核心算力合作方
  • 全线产品 AI 化：数据库更名 Oracle AI Database 26ai，AI 原生进数据库（AI Vector Search、Select AI、Private Agent Factory）；应用软件转向 Agentic 形态（Fusion Claw 运行时 + 75 个 Agentic Applications）
  • AI Data Platform 正面切入 Palantir 领地：自动生成企业本体（Enterprise Ontology），让企业用前沿大模型推理私有数据
  • Multicloud 分发：Oracle AI Database 进入 AWS / Microsoft Azure / Google Cloud，辅以 Cloud@Customer 混合云与 Exadata 本地部署，避免客户锁定、扩大数据库触达面
  • 行业云纵深：医疗（Oracle Health，全新 100% Agentic 电子病历/健康管理系统）、金融、零售等 22 个行业方案

二、产品分类

云基础设施（OCI）

  • OCI Compute：虚拟机/裸金属实例（AMD EPYC、Intel、Ampere Arm，基于 Oracle Acceleron 平台），主打同配置比 AWS/Azure/GCP 低约 51–57% 的价格
  • GPU 实例：NVIDIA H100/H200/B200、GH200/GB200 超级芯片、AMD MI300X，裸金属 + RDMA 集群网络，面向大模型训练与推理
  • OCI Kubernetes Engine (OKE) / Functions / Container Registry：云原生与 Serverless 计算
  • Oracle Cloud VMware Solution：VMware 工作负载整体上云
  • OCI Full Stack Disaster Recovery：跨 region 一键容灾

数据库与数据平台

  • Oracle AI Database 26ai：旗舰数据库，AI 原生架构（AI Vector Search、JSON-Relational Duality）
  • Autonomous AI Database / Autonomous AI Lakehouse：自治数据库与湖仓
  • Oracle AI Data Platform：自动生成 Enterprise Ontology，支撑企业私有数据上的 AI 推理与智能体（2026-09 随 Q1 财报发布）
  • Exadata：数据库一体机（本地/Cloud@Customer）
  • MySQL / Java：开源数据库与开发生态基本盘

企业应用软件（SaaS）

  • Oracle Fusion Cloud ERP / HCM / CX / SCM：财务、供应链、人力、营销销售服务一体化套件，15 项 Gartner 魔力象限领导者
  • Fusion Agentic Applications + Fusion Claw：2026-09-29 发布的受治理智能体执行运行时（AI 推理 + 确定性企业计算），新推 25 个 Claw 驱动的 Agentic Applications，总数达 75 个
  • Oracle AI Agent Studio：Agentic 应用构建平台（no-code/pro-code）
  • NetSuite：面向中小型企业的云 ERP（SuiteWorld 2026 于 10/25–28 举行）

传统本地软件

  • E-Business Suite / JD Edwards / PeopleSoft / Siebel：存量本地应用，持续向 Fusion Cloud 迁移

行业产品

  • Oracle Health：100% Agentic 的 AI 医疗管理与电子病历（EHR）系统，按专科（全科到肿瘤、放射）配置 AI 智能体
  • 金融、零售、通信等行业应用与 Industry Playbooks（覆盖 22 个行业）

三、服务分类

云服务

  • IaaS 订阅：OCI 计算/存储/网络/GPU 按量或订阅计费，全球统一低价；Free Tier（20+ 永久免费服务 + $300 试用额度）
  • SaaS 订阅：Fusion Cloud 套件每 90 天滚动更新；NetSuite 订阅

软件支持服务

  • Software Support：本地软件授权的支持续约，Q1 收入 $4.9B（-1%），高毛利现金流基本盘

咨询与实施服务

  • Services 收入 Q1 $1.4B（+5%），规模相对小，主要为实施与咨询

开发者与 AI 服务

  • OCI AI Services / Generative AI / ML Services：模型调用、模型路由、AI Agent 开发（与 DeepLearning.AI 合作 Agent Memory 课程）

四、解决方案分类

AI 基础设施解决方案

  • AI 云训练/推理集群（RDMA 网络 + 裸金属 GPU），需求持续供不应求；Q1 新签超 $30B AI 云合同
  • 主权/隔离场景：Compute Cloud@Customer Isolated

企业 AI 落地解决方案

  • AI Data Platform + AI Database：在企业私有数据上构建 AI 应用与智能体（Private Agent Factory）
  • Fusion Agentic Applications：ERP/HCM/CX/SCM 流程的端到端智能体自动化

部署形态解决方案

  • Multicloud：Oracle AI Database @ AWS / Azure / Google Cloud
  • Hybrid：Oracle Cloud@Customer（公有云服务搬进客户机房）
  • On-premises：Exadata、Oracle Database Appliance

行业解决方案

  • 医疗健康（Agentic EHR）、金融、零售等 22 个行业的模块化应用 + 行业实验室（Industry Labs）

六、总结

强势业务或产品推荐

  • OCI GPU 云：IaaS +121% 的增速与 $664B RPO 是当前 AI 算力卖方市场最直接的受益者，值得持续跟踪其产能交付（MW/GPU 数）与大单签约节奏
  • Oracle AI Database 26ai + Multicloud：数据库基本盘借 AI 化与多云分发重新扩张，Gartner OLTP 关键能力第一
  • Fusion Agentic Applications + Fusion Claw：企业软件 Agentic 化最激进的大厂路线（75 个 Agentic 应用），正面竞争 Salesforce/ServiceNow

强势战略留意

  • 资本开支与资金链：FY27 资本开支规模（单季 $28.5B、FCF 持续为负）靠发债 + $20B ATM 增发 + 客户预付款支撑，是大胆的杠杆化扩张，留意 RPO 客户集中度与履约风险
  • AI Data Platform 对标 Palantir：自动生成本体的打法若成立，将重塑企业 AI 数据层竞争格局
  • Oracle Health 的 100% Agentic EHR：医疗行业云的差异化赌注
  • 即将举行的 Oracle AI World（2026-10-25~28，拉斯维加斯）：原 CloudWorld 更名而来，届时预计发布全年最重要的 AI 产品更新，是下一版档案的重点信息源
