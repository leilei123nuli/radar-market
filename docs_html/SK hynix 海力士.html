SK hynix 海力士

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：2. 芯片 / AI 基础设施 | 地区：国外 | 类型：龙头 | 成立：1983 护城河：HBM 份额第一，AI 内存瓶颈最大受益者

一、公司概况

主营业务与产品服务

SK hynix（SK 海力士）是韩国存储芯片龙头、全球第二大内存厂商，主营 DRAM 与 NAND Flash 两大存储产品线。当前收入与战略重心高度集中于 AI 内存：HBM（高带宽内存）全球份额第一，是 NVIDIA AI GPU 的主力 HBM 供应商；2025-09 宣布完成全球首个 HBM4 开发并进入量产准备。官网产品组合分五大类：DRAM、CMM（CXL 内存模组）、SSD、NAND Storage、MCP（多芯片封装），面向 Server / AI / Mobile / PC / Automotive / Consumer / Networking 等应用市场。旗下拥有企业级 SSD 子公司 Solidigm（源自收购 Intel NAND 业务）。

整体战略方向

  • 核心战略：从"AI 内存供应商"升级为 "Full-Stack AI Memory Creator"（全栈 AI 内存创造者）——2025-11 SK AI Summit 提出，2026 Future Forum / Global Forum 持续深化；即从单一 HBM 扩展到 HBM + AI-DRAM + AI-NAND + CXL 的内存层级组合，按工作负载做系统级协同设计
  • 产品代际先发：HBM4 全球首家完成开发，绑定 NVIDIA 下一代平台节奏；同步推进 3D 堆叠内存、HBF 等下一代技术
  • 定制化路线：与客户共同设计 custom HBM / custom 内存方案，从标准品走向深度绑定
  • 生态扩张：2026-09 在硅谷成立 SK hynix Ventures，投资全球 AI 生态；积极参与 TSMC OIP、AI Infra Summit 等产业联盟，卡位 AI 基础设施话语权

二、产品分类

DRAM

  • HBM4 / HBM3E：AI 加速卡核心内存，HBM4 已完成开发（2025-09，全球首家），12 层堆叠；公司份额全球第一
  • DDR5 / RDIMM / 3DS RDIMM：服务器主内存，含 256GB 3DS RDIMM 等大容量模组
  • LPDDR5X / SOCAMM2：移动端与 AI 服务器低功耗内存（SOCAMM2 为 LPDDR 基 AI 服务器模组）
  • AiM / AiMX：PIM（Processing-in-Memory）存算一体技术，用于 LLM 推理加速

CMM（CXL Memory Module）

  • CXL 内存扩展模组：基于 Compute Express Link 的内存池化/扩展方案，已展示 CXL 3.2 模组，面向 AI 数据中心内存瓶颈

SSD

  • PS1010 / PS1030：PCIe Gen5 企业级 SSD（eSSD），面向数据中心
  • PEB110 E1.S：数据中心用 E1.S 形态 eSSD（2025-01 发布）
  • 消费级 SSD 及 Solidigm 品牌企业级产品线（Solidigm 具体产品公开信息以官网为准，本档未逐项抓取）

NAND Storage

  • NAND Flash 颗粒及嵌入式存储方案（eMMC、UFS 等）
  • UFS 4.0：移动端旗舰存储

MCP（Multi-Chip Package）

  • 多芯片封装产品（DRAM + NAND 合封），主供智能手机等移动设备

六、总结

强势业务或产品推荐

  • HBM 系列（HBM3E → HBM4）：全球份额第一 + HBM4 开发全球首家完成，AI 算力链最确定的瓶颈受益环节，需持续跟踪其对 NVIDIA 下一代平台的供货份额与三星/美光的追赶差距
  • 服务器 DRAM + eSSD 组合：HBM 溢出效应带动服务器内存整体规格升级，3DS RDIMM、CXL 模组、大容量 eSSD 构成"全栈 AI 内存"叙事的产品底座

强势战略留意

  • "Full-Stack AI Memory Creator" 转型：从卖标准品到与客户共同设计 custom HBM / AI-DRAM / AI-NAND，若成立将显著加深客户绑定、抬高转换成本；关注其在 custom HBM 上相对三星的先发是否兑现
  • CXL 与下一代内存（3D 堆叠、HBF）：布局内存池化与后 HBM 时代架构，决定 2027+ 竞争位势
  • 资本开支与产能：M15X 等新厂扩产节奏 vs. 内存周期下行风险
  • 生态动作：SK hynix Ventures（硅谷）投资方向；与 Intel/台积电等在美生产合作的传闻动向（官方已澄清部分传闻未确认）
