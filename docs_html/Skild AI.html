Skild AI

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：5. 具身智能 | 地区：国外 | 类型：新型 | 成立：2023 护城河：通用机器人大脑模型，软银/贝索斯投资

一、公司概况

主营业务与产品服务

Skild AI 是机器人基础模型公司，核心产品是通用机器人大脑 Skild Brain——一个跨本体（omni-bodied）的机器人基础模型，用同一套权重控制四足、人形、桌面臂、移动操作机器人等不同形态，公司不自造机器人本体。旗舰模型 S1（2026-08-18 发布）是业内首个以 in-context learning 为核心的机器人基础模型：给一段任务演示视频作为 prompt，无需微调即可执行训练时未见过的长程任务（最长 10 分钟）。商业化进度在同类公司中领先：2026-09 宣布 ARR 突破 1 亿美元（首次商用部署后 10 个月），60+ 付费客户，约 90% 收入来自操作类（manipulation）任务，约 10% 来自移动类（含收购 Zebra/Fetch 所得的 AMR 业务，占 4%）。创始人为 Deepak Pathak（CEO）与 Abhinav Gupta（President），均为 CMU 机器人学习领域学者。

整体战略方向

  • Omni-bodied intelligence：拒绝"一个机器人一个模型"的垂直路线，做任意本体、任意任务的统一大脑，以此解锁更大规模训练数据（含人类视频）
  • Deployment-first（部署即研究）：把真实商业部署当作研究支柱而非终点——部署暴露速度/精度/变化适应问题（S1 的 ICL 方向即由部署教训驱动），并形成"通用模型 → 部署特化 → 数据回流通用模型"的物理版递归自我改进飞轮
  • 数据飞轮：预训练靠大规模仿真（NVIDIA Isaac Sim）+ 互联网人类视频，后训练靠遥操作 + 真实部署数据；宣称数据质检投入是采集投入的 3 倍
  • Physical Self-Play：2026-09-23 公布的后训练突破，S1 在仿真中自我对弈 140 年（模拟时间）学会踢足球并 sim2real 迁移到人形机器人，目标是突破人类数据能力上限
  • 资本与生态：2024-07 A 轮 3 亿美元（估值 15 亿，Lightspeed/Coatue/软银/Bezos Expeditions）；2026-01 C 轮 14 亿美元（估值超 140 亿，软银领投，NVentures/NVIDIA、Macquarie、Bezos、LG、Schneider Electric、Salesforce Ventures 等跟投）

二、产品分类

模型产品

  • Skild Brain：统一机器人基础模型，分层架构（低频高层操作/导航策略 + 高频低层关节力矩策略），跨本体泛化
  • S1：旗舰模型（2026-08），in-context learner——单段视频 prompt 即学新任务，未见任务成功率 66%（对比语言 prompt VLA 的 9%），单条演示约等效 380 条后训练数据；基于 NVIDIA AI 基础设施训练
  • LocoFormer：前代运动控制 in-context learner（2025），通过 prompt 中累积实时经验适应未见本体与环境

应用平台产品（官网列示）

  • Security/Inspection Robot Platform：安防/巡检机器人平台，面向非结构化、危险环境的自主巡检
  • Mobile Manipulation Platform：移动操作平台，抓取、递送、导航等低层技能封装为 API 调用，用户无需处理现实环境细节
  • Autonomous Packing：高精度灵巧技能驱动的自动化包装/装箱

仓储物流产品（收购所得）

  • Symmetry Fulfillment：收购 Zebra Technologies 机器人部门（原 Fetch Robotics）获得的仓储编排平台，协调机器人与一线工人，配套 AMR 车队

三、服务分类

机器人智能服务

  • Skild Brain/S1 能力授权与部署：以技能 API（抓取、导航等抽象接口）形式向机器人应用方提供智能层
  • 部署特化服务：针对客户产线/场景的后训练与蒸馏，满足生产级速度与可靠性

商业化落地服务

  • 按行业场景的持续运营服务（ARR 模式）：货物搬运、配送、站点巡检、安防、备餐，覆盖仓库、工厂、数据中心
  • 公开信息有限：具体定价、API 开放程度、开发者自助入口未见公开

四、解决方案分类

制造业解决方案

  • 高精度装配：与 NVIDIA、Foxconn 合作，双臂操作机器人装配 Blackwell 系统（产品换代即换任务，传统产线需重编程）
  • 线束制造：与 Sumitomo Wiring Systems 合作自动化此前被认为"不可能自动化"的线束工序

物流仓储解决方案

  • 基于 Symmetry 平台 + AMR + Skild Brain 的端到端仓储履约自动化（收购 Zebra 机器人部门后重点方向）

食品/商用厨房解决方案

  • 与 Mitsui（三井物产）试点 S1 驱动的通用机器人进入商业厨房（其供应链在日本日供 140 万份餐食）

安防巡检解决方案

  • 危险/非结构化环境（如油井、机房）的机器人巡检替代人工

六、总结

强势业务或产品推荐

  • S1 的 in-context learning 路线：把机器人学习从"每任务采集+微调"拉到"一段视频 prompt"，若 scaling law 持续成立（其 ICL 与 VLA 的差距随数据量指数级拉大），是范式级优势，值得作为赛道技术风向标持续跟踪
  • 商业化兑现能力：10 个月做到 1 亿美元 ARR、60+ 客户，在"具身智能是否可规模化收入"这一赛道核心问题上是当前最强证据之一
  • Zebra/Fetch 收购：直接获得经过验证的仓储渠道与 AMR 装机基础， Mobility 收入即时入账

强势战略留意

  • Deployment-first 与数据飞轮：部署数据回流通用模型的"物理 RSI"叙事是其区别于纯研究型对手（如 Physical Intelligence）的关键，需跟踪部署规模是否真转化为模型代差
  • Physical Self-Play：若自我对弈后训练能从足球迁移到日常任务，将突破人类演示数据的能力上限，是下一代模型最大看点
  • 与 NVIDIA 的深度绑定（训练基础设施 + NVentures 投资 + Blackwell 装配合作）：既是加速力也是依赖点
  • 估值 140 亿美元 vs 1 亿 ARR：估值隐含极高增长预期，收入结构（操作类占 90%）能否跨行业复制是主要风险观测点
