一、公司概况

主营业务与产品服务

海光信息技术股份有限公司（688041.SH）成立于 2014 年，主要从事高端处理器、加速器等计算芯片产品和系统的研发，是国内 x86 架构 CPU 与 DCU（深度计算处理器）双线布局的算力芯片龙头。两大产品线： - 海光 CPU：兼容主流 x86 指令集的高性能国产处理器，分 7000/5000/3000 三大系列，覆盖数据中心、行业客户、入门及工控场景；内置国密算法加速引擎与可信计算方案。 - 海光 DCU（深算系列）：基于通用并行计算架构（GPGPU 路线）的高算力加速卡，面向 AI 训练/推理与科学计算，可搭配海光 CPU 组成异构计算方案；软件栈走开源生态路线，适配主流 AI 框架与大模型。

整体战略方向

  • "CPU + DCU"双轮驱动：CPU 吃信创与通用服务器国产替代，DCU 吃 AI 算力国产化，构成"C86 + DCU"计算平台
  • 产品节奏坚持"量产一代、研发一代、规划一代"持续迭代
  • 生态优先：兼容 x86 生态降低迁移成本；DCU 全面适配主流大模型（截至 2025 年末已适配 DeepSeek、Qwen、混元、智谱等 365 款大模型，覆盖 20 多个行业、300 余个应用场景）
  • 安全可信作为差异化卖点：芯片级信任根、国密支持、可信/机密计算，面向关键信息基础设施
  • 生态组织建设：发起"光合组织"，联合 OEM、OS、ISV 共建国产通用计算生态（全国 34 个生态适配中心、4 个 OEM 联合实验室、41 个 ISV 联合实验室）

二、产品分类

海光 CPU（x86 兼容处理器）

  • 7000 系列：面向数据中心的旗舰级高性能处理器，16-32 核、128 路 PCIe、8 通道 DDR4，应用于云计算、大数据、数据库、分布式存储、人工智能等（官网在售型号含 7185/7169/7165/7159/7155/7151 及新一代 7390/7380/7375/7360 等，新品升级至 PCIe 4.0、DDR4-3200）
  • 5000 系列：面向行业客户的主流中端处理器，8-16 核、64 路 PCIe、4 通道内存，适用云计算、边缘计算、分布式存储（型号含 5185/5131、5390/5380 等）
  • 3000 系列：面向多场景的高性价比处理器，4-8 核、最高加速频率 3.3 GHz 级别，面向入门级服务器、工作站、工业控制（型号含 3188、3350/3350E 等）

海光 DCU（深度计算处理器 / 加速卡）

  • 深算系列 DCU：通用并行计算架构加速卡，用于科学计算与 AI 模型训练/推理；深算三号已投入市场，深算四号研发推进中（公司互动平台口径，2025-12 起）
  • 配套软件栈：统一底层驱动平台 + 层次化软件栈，适配常见计算框架、库和编程模型，主打低迁移成本

六、总结

强势业务或产品推荐

  • 海光 CPU（7000 系列）：x86 兼容 + 国密安全 + 信创主渠道，是国产通用服务器 CPU 里生态迁移成本最低的一档，营收基本盘
  • 海光 DCU（深算系列）：国产 AI 算力第二极（对标昇腾之外的 GPGPU 路线），大模型适配数量（365 款）与行业覆盖是其核心卖点；2026Q1 营收同比 +68%、2026H1 预增超 55%，DCU 放量是主要弹性来源

强势战略留意

  • 深算三号 → 深算四号迭代：DCU 代际进展（含 FP4 等新精度支持）直接决定其在国产 AI 训练卡市场的站位
  • 吸收合并中科曙光终止（2025-12-09）：1160 亿元换股合并因"交易规模大、市场环境变化"终止，但公司称与中科曙光的产业协同不受影响；后续是否重启或以其他形式整合值得跟踪
  • x86 授权与制裁风险：美国实体清单背景下的先进制程获取、x86 授权可持续性，是长期最大不确定性
  • 信创 + AI 双逻辑叠加：政策端"人工智能+"与信创推进带来稳定订单，但需区分真实 AI 需求与政策红利
