CoreWeave

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国外 | 类型：新型 | 成立：2017 护城河：GPU 专有云，与 NVIDIA 深度绑定

一、公司概况

主营业务与产品服务

CoreWeave 自我定位为 "The AI Hyperscaler"——专为 AI 打造的 GPU 专有云。业务分三层：底层是自建/自营的 AI 数据中心与 NVIDIA GPU 集群（Hopper / Blackwell / Vera Rubin，覆盖美国与欧洲）；中层是 CoreWeave Cloud Platform（计算、网络、存储、Kubernetes 编排与可观测性）；上层是 2026 年 9 月底发布的 CoreWeave Forge——把 Weights & Biases、OpenPipe、marimo 整合成模型与智能体的训练-推理开发闭环。公司 2017 年起家于加密挖矿，后全面转型 AI 云，2025 年 3 月在纳斯达克上市（代码 CRWV）。客户高度集中于头部 AI 实验室与大企业，官方称"10 家领先基础模型厂商中的 9 家"使用 CoreWeave；截至 2026Q2，营收约 25.7 亿美元（同比 +112%），在手合同 backlog 约 1040 亿美元（第三方财报汇总口径）。

整体战略方向

  • 垂直整合的"AI 工厂"：从"GPU 出租"升级为覆盖基础设施 → 平台 → 开发工具的全栈，强调与"GPU 租赁商"的品类区隔
  • 与 NVIDIA 深度绑定：每一代 NVIDIA 平台首批上线——GB200 NVL72 的首个 NVIDIA Exemplar Cloud、Vera Rubin NVL72 全球首个上线验证并进入限量可用（Cognition 为首个生产客户）
  • 从训练扩展到推理与 Agent：以 Forge 把 Run → Observe → Curate → Improve → Evaluate 的"AI Loop"产品化，向高毛利的开发平台层跃迁
  • 并购补全软件栈：收购 Weights & Biases（实验管理）、OpenPipe（post-training/RL）、marimo（开源 notebook）整合为 Forge；对 Core Scientific 约 90 亿美元的全股票收购于 2025-10 被对方股东否决后终止，电力与产能扩张转为自建/租赁路线
  • 长约锁定需求：OpenAI 约 119 亿美元承诺等大客户长约驱动收入，同时带来客户集中度与重资本开支/债务的结构

二、产品分类

基础设施产品（CoreWeave Cloud / Infrastructure）

  • GPU Compute：集群规模的最新 NVIDIA GPU（Vera Rubin / Blackwell / Hopper）
  • CPU Compute：通用算力，承接辅助性负载（含面向 AI agent 的 NVIDIA Vera CPU）
  • Bare Metal Compute：无虚拟化开销的裸金属直取
  • Networking：面向 AI 集群的高带宽、低延迟无损网络 fabric
  • AI Object Storage：为训练/推理调优的对象存储（LOTA 加速、跨区写入加速、Archive 层）
  • Dedicated Storage：面向高数据需求的独立 VAST 集群
  • Zero Egress Migration (0EM)：零出口费的数据迁入服务

平台与控制（Infrastructure Control）

  • CoreWeave Kubernetes Service (CKS)：为 AI 负载打造的托管 Kubernetes
  • Inference on CKS：在自有 CKS 集群上服务模型
  • Mission Control：fleet 健康、监控与控制一体（含 MCP 与 console Agent）
  • Fleet / Node Lifecycle Controller：集群与节点级自动化生命周期管理
  • Observability / Security / IAM：指标、日志、链路追踪与企业级安全（Remote Key Encryption 等）
  • Tensorizer：优化序列化，加速模型加载

开发平台（CoreWeave Forge，2026-09 发布）

  • Training：Weights & Biases Models（实验跟踪）、Serverless SFT（免运维微调）、Serverless RL（托管强化学习）、Model Distillation（预览）
  • Inference：Serverless Inference（开放模型统一 API、按 token 计费）、Dedicated Inference（自有权重 + 指定 GPU 的托管推理）
  • Agent 开发：Agent Lens（预览，生产失败聚类与可观测）、Sandboxes（agent/RL 代码隔离执行）
  • 工具：ARIA（AI 研究智能体，已 GA）、Registry（模型/智能体/数据集的 system of record）、Notebooks（基于 marimo 的响应式 Python notebook）

六、总结

强势业务或产品推荐

  • GPU 专有云基础设施：唯一三次获得 SemiAnalysis ClusterMAX Platinum 评级的 AI 云，MLPerf 训练/推理成绩持续领先，是"算力质量"维度的标杆
  • CoreWeave Forge（含 Weights & Biases）：把实验管理入口、post-training 与推理连成闭环，是从卖算力走向卖平台的关键一跳，值得跟踪其付费转化

强势战略留意

  • 与 NVIDIA 的双向绑定：首发每一代平台带来性能溢价，但供应、定价与投资关系深度耦合，一荣俱荣
  • 财务结构：千亿美元级 backlog 对应巨额资本开支与债务融资，且客户集中度高（OpenAI、微软系占比大），需跟踪履约与利润率走势
  • Core Scientific 收购告吹后的电力路径：1.3GW 电力缺口如何以自建/租赁补上，决定扩张速度
  • 从训练到推理/Agent 的重心迁移：官方明确"AI 重心已从训练转向推理"，Forge 与 Dedicated Inference 是其卡位动作
