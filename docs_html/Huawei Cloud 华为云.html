Huawei Cloud 华为云

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国内 | 类型：龙头 | 成立：2017 护城河：昇腾算力 + 政企渠道

一、公司概况

主营业务与产品服务

华为云是华为公司的云服务品牌（2017 年成立云 BU），国内头部全栈云厂商：底层是覆盖全球的云基础设施（34 个 Region、103 个可用区、服务 170+ 国家和地区、2800+ CDN 节点），向上分为基础云服务（计算/存储/网络/数据库/大数据/容器/安全）、AI 全栈（昇腾算力 + ModelArts 训推平台 + 盘古大模型 + Tokens 服务）与开发者工具（华为云码道 CodeArts）三层结构，并以华为云Stack 覆盖政企混合云市场。

整体战略方向

  • 当前核心战略定位："做企业级 AI 创新的硅基黑土地"，三线并进——高性能 AI Infra（昇腾算力底座）、行业智能体开发平台、行业 AI"梦工厂"生态
  • 行业深耕：携手伙伴深入 30+ 行业、500+ 场景，主打政企与工业智能化（IDC 中国工业云 IaaS+PaaS、工业互联网平台等多项第一）
  • 生态伙伴路线：50,000+ 合作伙伴、850 万+ 开发者，2026 年初连续发布全球销售伙伴政策与生态政策，强调伙伴商业正循环
  • 全球化扩张：以本地化运营切入土耳其、沙特、埃及、东南亚等新兴市场（IDC 土耳其公有云 IaaS 领导者、华为云Stack 中东及巴基斯坦混合云第一）
  • 权威认可：Omdia 全球云服务厂商领导者（战略与创新维度全球第一、中国厂商第一）

二、产品分类

人工智能

  • 盘古大模型（Pangu）：自研行业大模型系列，面向政务、金融、矿山、医疗等行业场景
  • ModelArts（魔坊）：一站式模型训推平台，覆盖数据准备、开发调试、分布式训练、推理部署全流程；昇腾原生适配 DeepSeek 系列模型
  • Tokens 服务：大模型 Token 调用服务（MaaS 形态）
  • 智能体平台 / 智能体 / 行业大模型 / AI Kits：智能体开发平台与行业大模型工具套件（官网 AI 产品分类）

计算

  • 弹性云服务器 ECS：旗舰云主机，最大 384vCPU，支持按需/包周期/竞价计费，千万级 PPS 转发实例
  • 异构算力实例：昇腾（AI）、鲲鹏（ARM）、GPU 等多架构算力

存储

  • 对象存储 OBS：标准/低频/归档/深度归档四级存储，单 AZ 数据持久性 11 个 9
  • 云硬盘 / 云备份 CBR：块存储与统一备份服务

网络

  • VPC（虚拟私有云）：云上网络基础，与容器网络深度融合
  • 其余网络产品线本次建档未逐一抓取，详见官网产品列表（公开信息有限）

容器与中间件

  • 云容器引擎 CCE：企业级 K8s 服务，分 Standard / Turbo / Autopilot（Serverless）三型，自研 Volcano 调度器；CCE AI 容器面向 AI 训推场景（连续五年中国容器市场份额第一）
  • 应用中间件：消息、缓存等中间件服务（官网分类，未逐一抓取）

数据库

  • GaussDB：自研旗舰数据库，集中式（单副本/一主多备）与分布式（混合部署）双形态，覆盖个人学习到企业级场景
  • 关系型 / 非关系型 / 数据库生态工具&中间件：官网三大子类（具体产品未逐一抓取）

大数据

  • MapReduce 服务 MRS：云原生数据湖（Hadoop/Spark/Flink/HBase/Hudi），存算分离，单集群 20000+ 节点
  • DataArts Studio / DLI / DLV：数据治理、数据湖探索、数据可视化

安全

  • Web 应用防火墙 WAF / 企业主机安全 HSS 等 20+ 云原生安全服务，按"保护应用服务 / 云工作负载 / 数据资产 / 安全态势管理"四类组织

开发工具

  • 华为云码道 CodeArts：一站式 DevOps 平台（需求管理/代码/CI-CD/测试/制品仓），含码道代码智能体（信通院智能编码工具评估 4+ 级最高评级）；IDC 中国 DevOps 平台双第一
  • 应用运维管理 AOM / 云日志服务 LTS / CodeArts Inspector：运维观测与漏洞管理

混合云

  • 华为云Stack：政企自建混合云，中东及巴基斯坦区域混合云市场第一，连续三年位居中国企业自建云、资源能源云子市场第一

企业应用与其他

  • WeLink：企业协同办公平台
  • 企业协同、智能客服、专属云、应用与数据集成、物联网、工业软件、云通信、CDN 与边缘计算、运维管理与迁移等官网大类（未逐一抓取明细）

六、总结

强势业务或产品推荐

  • 昇腾算力 + ModelArts + 盘古大模型：国产 AI 全栈闭环最完整的一家，昇腾原生适配 DeepSeek 的动作值得持续跟踪
  • 华为云Stack 混合云：政企/工业渠道护城河最深的一环，IDC 工业云多项第一
  • CCE 容器 + 码道 CodeArts：开发者基础设施双拳头，均为 IDC 中国市场第一

强势战略留意

  • "企业级 AI 硅基黑土地"定位下，Tokens 服务（MaaS）能否把昇腾算力转化为按量收入
  • 行业大模型/智能体的"梦工厂"生态打法：与伙伴共做交付而非自做应用，跟踪其伙伴政策落地
  • 新兴市场本地化扩张（中东、土耳其、东南亚）对国内云厂商出海格局的影响
