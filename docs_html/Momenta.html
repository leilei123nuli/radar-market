Momenta

一、公司概况

主营业务与产品服务

Momenta（北京初速度科技有限公司，总部苏州）是量产智能驾驶方案商，自我定位为"全球领先的物理AI公司"。业务"两条腿"并行：一是量产业务（Mass Production），为车企提供覆盖 L2++ 到 L3 的量产智能驾驶方案；二是规模化无人业务（Scalable Robo），以 Robotaxi 和 Robovan 为核心，拓展 Robotruck 等场景。技术底座为"数据飞轮"（量产数据回流驱动算法迭代）与 Momenta R7 世界模型。已于 2026-07-08 在香港联交所主板上市；2026 年上半年营收 16 亿元，同比增长 76%；量产方案累计搭载量突破 100 万台（2026-07）。

整体战略方向

  • "一个飞轮两条腿"：以数据飞轮为核心洞察，量产（规模化数据与现金流）与无人业务（终局商业化）互相喂养
  • 以世界模型为基座做"物理AI"：R7 世界模型已上车量产，定位"物理AI正式上车的第一步"，并向强化学习大模型（AEB/AES 等安全功能）延伸
  • 深度绑定全球主机厂：客户覆盖奔驰、宝马、通用（凯迪拉克/别克）、丰田、上汽（智己/荣威/上汽大众）、广汽、日产、比亚迪等，走"全球品牌的共同选择"路线
  • 全球化布局：设有东京、斯图加特、阿布扎比办公室；获德国 KBA 全境 L4 级自动驾驶测试许可（2026-07），随车企客户进入欧洲及全球市场
  • 无人业务商业化：Robotaxi（与上汽出行合作运营）、Robovan（2026-07 落地苏州）推进规模化落地

二、产品分类

量产智能驾驶产品（Mass Production）

  • Super CP：超级巡航辅助，在自适应巡航、车道居中基础上提供无图过路口、红绿灯启停、拨杆变道等功能
  • Super Parking：泊车辅助产品，含自动泊车、遥控泊车及记忆泊车领航辅助
  • L2++ 端到端全场景方案：覆盖全场景的端到端智能驾驶体验
  • L3 级自动驾驶方案：特定运行范围内车辆系统全面接管驾驶任务，正与全球多家主流车企推进量产落地

规模化无人产品（Scalable Robo）

  • Robotaxi：无人驾驶出租车，与上汽出行等合作运营
  • Robovan：无人配送，2026-07 在苏州落地
  • Robotruck：无人货运，处于持续拓展阶段（公开信息有限）

底层技术产品

  • Momenta R7 世界模型：具备物理世界认知框架的车载世界模型，支撑预测、规划与博弈能力，已搭载于奔驰、凯迪拉克、日产等量产车型
  • 强化学习大模型：应用于 AEB/AES 等主动安全功能（上车奔驰纯电 GLC、CLA、别克、传祺等车型）
  • CLA（Closed Loop Automation）闭环自动化工具链：自动筛选海量黄金数据、驱动算法自动迭代的数据闭环工具链

三、服务分类

量产方案服务

  • Momenta 主线：平台化解决方案，一套架构、一套算法，为众多量产车型高效快速适配
  • Momenta Open Solution 开放解决方案：在主线基础上支持主机厂灵活打造定制化产品，兼顾标准化与定制化
  • 联合开发服务：与车企共研（如奔驰×Momenta 共研城区及高速领航辅助驾驶系统）

无人运营服务

  • Robotaxi 商业化运营（与上汽出行旗下合作运营）
  • Robovan 无人配送运营（公开信息有限）

六、总结

强势业务或产品推荐

  • 量产智驾方案（Super CP / R7 世界模型上车）：搭载量破 100 万、客户覆盖奔驰/宝马/通用/丰田/上汽/广汽/日产，是国内量产智驾第一梯队，值得持续跟踪其装车量与新客户定点
