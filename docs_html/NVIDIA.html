一、公司概况

主营业务与产品服务

NVIDIA 是 GPU 加速计算的开创者，官方定位四大市场：游戏（Gaming）、专业可视化（Professional Visualization）、数据中心（Data Center）、汽车（Automotive）。当前业务重心是面向 AI 时代的全栈加速计算平台：底层为 GPU（Rubin 新一代架构）/ CPU（Vera，面向 agentic AI 的主控 CPU）/ DPU（BlueField）与网络（Spectrum-X 以太网），中间层为 CUDA 及各类加速库，上层为 AI Enterprise 软件、Omniverse 数字孪生、Isaac 机器人平台等，形成"芯片 → 系统 → 软件栈 → 行业方案"的完整收入结构。

整体战略方向

  • "AI 工厂"（AI Factory）叙事：把数据中心重塑为生产 token 的工厂，卖整套全栈基础设施（GPU+CPU+网络+软件），而非单颗芯片
  • 从生成式 AI 转向 agentic AI 与推理（reasoning）：Rubin 平台主打降低训练与推理的 token 成本，Vera CPU 专为强化学习与 AI 智能体工作流设计
  • Physical AI / 具身智能是明确的下一条增长曲线："三台计算机"方案（DGX 训练 + Omniverse/Cosmos 仿真 + Jetson 边缘推理）打通机器人开发全链路
  • 生态绑定：与云厂商（Microsoft 等）、模型厂商（Anthropic Claude 已跑在 NVIDIA 平台上）、机器人厂商（Apptronik、Boston Dynamics、Agility 等）双向锁定

二、产品分类

数据中心硬件

  • NVIDIA Rubin GPU：下一代 AI 架构，七芯协同设计，主打 agentic AI 与推理的 token 成本下降
  • NVIDIA Vera CPU：面向强化学习与 agentic AI 的主控 CPU，与 GPU 配对调度数据流
  • NVIDIA BlueField（BlueField-4）：DPU 平台，运行 DOCA 微服务，卸载网络/存储/安全负载
  • NVIDIA Spectrum-X / Spectrum-XGS Ethernet：AI 数据中心以太网，可跨多数据中心组成 giga 级 AI 超级工厂
  • DGX 系统：AI 训练整机系统（机器人三机方案中的训练侧）

游戏与创作

  • GeForce RTX 50 系列：消费级显卡（含笔记本端），DLSS 5 / DLSS 4.5 AI 渲染
  • NVIDIA RTX Spark / RTX Station GB300：桌面级 AI 工作站形态新品
  • GeForce NOW：云游戏服务

边缘与机器人硬件

  • Jetson（Jetson AGX / Jetson Orin）：边缘 AI 与机器人实时推理计算平台
  • IGX Thor：工业级边缘计算模组（亦用于 Space-1 太空计算方案）
  • RTX PRO Server：工业数字化、机器人仿真与合成数据生成的服务器平台

软件与模型产品

  • CUDA 及加速库：全栈根基，开发者生态护城河核心
  • NVIDIA AI Enterprise：企业级 AI 软件套件
  • NVIDIA Omniverse：数字孪生与仿真平台（基于 OpenUSD）
  • NVIDIA Cosmos：物理 AI 世界模型/仿真平台
  • Nemotron / NeMo：开放模型与模型定制工具链
  • Isaac 平台：Isaac Sim（仿真）、Isaac Lab（机器人学习）、Isaac ROS（基于 ROS 2 的加速包）
  • NVIDIA DRIVE：自动驾驶平台（含 Alpamayo 等）

三、服务分类

企业与开发者服务

  • NVIDIA Developer Program：开发者计划，提供 GPU 加速容器、模型与 SDK
  • NVIDIA Inception：初创企业扶持计划（市场支持、技术专家、培训与融资机会）
  • 培训与认证：自定进度课程（OpenUSD、数字孪生、AI 智能体安全等学习路径）

云端与基础设施服务

  • GeForce NOW：C 端云游戏订阅
  • 云 GPU 合作分发：通过云厂商与 NVIDIA Partner Network（NPN）伙伴交付数据中心方案
  • vGPU 虚拟化软件：虚拟桌面/工作站与虚拟化数据中心授权

四、解决方案分类

数据中心与云

  • 全栈数据中心基础设施：GPU+CPU+DPU+Spectrum-X 网络一体化方案
  • 工作负载方案：AI 推理（宣称 MoE 模型最高 10 倍性能）、生成式 AI、数据科学、HPC、渲染（RTX Server）、虚拟化
  • 部署形态覆盖：云、办公室、数据中心、边缘四层场景；Space-1 Vera Rubin 模组把方案延伸到在轨太空计算

机器人与 Physical AI（具身智能）

  • "三台计算机"方案：DGX 训练 + Omniverse/Cosmos on RTX PRO Server 仿真 + Jetson AGX 实时推理部署
  • 落地场景：人形机器人（Apptronik、Agility Digit、Boston Dynamics）、工业机器人功能安全（Foxconn）、工厂数字孪生（Pegatron PEGAVERSE）、合成数据生成、多摄像头追踪、机器人仿真学习
  • 生态：Isaac ROS 接入 ROS 2 开源社区，Jetson Partner Network 提供板卡/传感器/设计服务伙伴

行业解决方案

  • 汽车：NVIDIA DRIVE 自动驾驶开发 + Omniverse 工厂/零售数字孪生，robotaxi 生态（与 Uber 等合作）
  • 工业数字化：数字孪生、合成数据、视觉 AI 智能体
  • HPC/科研：Earth-2 气候模拟、NVQLink 量子-GPU 互联等

六、总结

强势业务或产品推荐

  • 数据中心全栈平台（Rubin GPU + Vera CPU + BlueField + Spectrum-X）：AI 基础设施事实标准，从芯片竞争升维到"AI 工厂"整厂竞争，护城河最深
  • CUDA + AI Enterprise 软件栈：生态粘性最强的一环，竞争对手最难复制的部分
  • Isaac/Jetson/Omniverse 机器人全栈：具身智能赛道里少有的"训练-仿真-部署"闭环平台，值得作为赛道 5 的基准锚点持续跟踪

强势战略留意

  • Rubin/Vera 一代对推理与 agentic AI 的押注：token 成本曲线是核心竞争力，需跟踪其实际交付与客户迁移节奏
  • Physical AI"三台计算机"叙事能否复制 CUDA 式的生态锁定（人形机器人伙伴阵营已成型）
  • 网络（Spectrum-X）与 CPU（Vera）收入占比提升：全栈化是否侵蚀传统服务器/网络厂商利益而引发生态反噬
  • 与模型厂商（Anthropic）和云厂商（Microsoft）的深度绑定关系演变
