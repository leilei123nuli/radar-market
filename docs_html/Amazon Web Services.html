Amazon Web Services

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国外 | 类型：龙头 | 成立：2006 护城河：全球云份额第一，自研 Trainium/Inferentia 降本

一、公司概况

主营业务与产品服务

Amazon Web Services（AWS）是 Amazon 旗下的云计算业务，全球云市场份额第一。业务覆盖从基础设施（计算 EC2、存储 S3、数据库 Aurora/RDS、网络）到 AI 全栈（自研 Trainium/Inferentia 芯片、Amazon SageMaker AI、Amazon Bedrock 模型平台、Kiro/Amazon Quick 等智能体应用）的完整产品体系。据 Amazon 2026 年 Q2 财报（经财经媒体报道），AWS 季度收入 422 亿美元、同比增长约 37%（五年来最快增速），年化收入 run rate 约 1690 亿美元，在手订单（backlog）约 4960 亿美元。

整体战略方向

  • AI 全栈垂直整合：从自研芯片（Trainium 宣称比同级 GPU 性价比高 30–40%）→ 模型平台（Bedrock 聚合 Anthropic、OpenAI、Google、Meta、Amazon 等数百个模型）→ 智能体（AgentCore、Strands 开源框架）→ 应用（Kiro 编程、Amazon Quick 办公、Amazon Connect 客服），"From chips to agentic solutions" 是当前官方叙事主线
  • Agentic AI 落地：官网主推"生产级 AI 智能体"，强调安全、治理、数据主权（数据不出客户指定的边界），主打企业级可信 AI
  • 超大规模资本开支：Amazon 2026 年资本开支指引上调至约 2200 亿美元，绝大部分投向 AWS 的 AI 数据中心，管理层称需求到 2027 年都将超过产能
  • 数据与分析补强：2026-08-26 签署协议收购 DuckDB 背后的 DuckLabs，强化分析型数据库与 AI 数据底座
  • 中立模型超市定位：不绑定单一模型，以"多模型可选 + 不被锁定"对抗微软-OpenAI、谷歌-Gemini 的垂直绑定

二、产品分类

官网产品目录共分 19 大类：Analytics、Application Integration、Artificial Intelligence、Business Applications、Compute、Customer Experience、Databases、Developer Tools、End User Computing、Game Tech、Management Tools、Media Services、Migration & Modernization、Multicloud & Hybrid、Networking & Content Delivery、Operations、Security & Identity、Storage、Supply Chain。重点如下：

AI 与机器学习

  • Amazon Bedrock：生成式 AI 应用与智能体的端到端平台，聚合数百个基础模型（Anthropic、OpenAI、Google、Meta、Amazon Nova 等）
  • Amazon SageMaker AI：自定义模型训练、微调与部署平台
  • Amazon Nova：自研基础模型系列（经 Bedrock 分发）
  • AgentCore / Strands：智能体构建运行组件与开源 SDK，走开放标准路线
  • Trainium / Inferentia：自研 AI 训练/推理芯片，主打性价比（宣称高 30–40%）

应用层 AI 产品

  • Kiro：AI 编程/智能体工程工具（agentic engineering）
  • Amazon Quick：面向办公场景的 AI 助手（业务数据问答、自动化、无代码建应用）
  • Amazon Connect：AI 原生的客户联络中心解决方案

计算 / 存储 / 数据库（基本盘）

  • Amazon EC2：弹性计算，旗舰基础服务
  • Amazon S3：对象存储事实标准
  • Amazon Aurora：Serverless 关系数据库（兼容 PostgreSQL/MySQL/DSQL）
  • Amazon RDS：托管关系数据库
  • AWS Lambda 等 Serverless 与容器产品线（App Runner、App Mesh 等）

数据与分析

  • 收购 DuckLabs（DuckDB）后强化分析数据库布局；另有 Redshift 等分析产品（公开信息有限，本次未逐一核验）

三、服务分类

客户支持服务

  • AWS Support：分层技术支持体系
  • AWS Professional Services：专家咨询与打包实施服务，加速企业上云转型
  • AWS Training & Certification：云技能培训与认证体系

生态与市场服务

  • AWS Marketplace：第三方软件与 AI 智能体交易市场（官方称已有 4,000+ AI 智能体和解决方案可部署）
  • AWS Partner Network：合作伙伴网络
  • AWS Free Tier / Savings Plans / Offers：免费试用与灵活计费计划

开发者服务

  • SDKs & Tools：.NET / Python / Java / PHP / JavaScript 等多语言开发工具
  • Agent Toolkit：给 AI 编程智能体提供最新文档与 AWS 资源访问的工具包
  • Builder Center / re:Post：开发者社区与问答

四、解决方案分类

按用例（Solutions Library）

  • AI Solutions：生成式 AI 与智能体场景方案集
  • Analytics Solutions：数据分析场景方案集
  • Migration & Modernization Solutions：迁移与现代化改造方案集
  • Transformation Hubs：官方方法论主线"Migrate to modernize → Modernize to unlock data → unlock data to run AI"（迁移 → 数据 → AI 三步走）

按行业

  • 金融服务（FSI）：欺诈检测、风险建模、合规自动化
  • 公共部门：GovCloud / FedRAMP 合规的政务与国防 AI
  • 汽车与制造：预测性维护、供应链优化、自动驾驶系统
  • 媒体、娱乐与游戏：内容生成、个性化推荐、实时互动（案例：Bundesliga 实时赛事洞察）
  • 零售：零售分析、需求预测、库存管理（Solutions Library 中有零售智能平台类方案）

按组织类型

  • 初创公司到大型企业的分层方案（Startup / Enterprise / ISV 独立软件开发商专项）

六、总结

强势业务或产品推荐

  • Amazon Bedrock + AgentCore：多模型聚合 + 智能体生产化平台，是 AWS 对抗微软/谷歌垂直绑定的核心武器，企业采纳度值得持续跟踪
  • Trainium/Inferentia 自研芯片：30–40% 性价比宣称若兑现，是云 AI 成本曲线的关键变量
  • EC2/S3/Aurora 基本盘：份额第一的现金流业务，为 AI 资本开支供血
  • Amazon Connect / Quick / Kiro：AI 应用层三件套，直接对标微软 Copilot 体系

强势战略留意

  • 2200 亿美元级资本开支：需求超产能至少到 2027 年，押注规模空前，关注折旧对 AWS 利润率的侵蚀（Q2 2026 折旧已约占 AWS 收入 19%）
  • "中立模型超市"策略的边界：Bedrock 同时分发 OpenAI 与 Anthropic 模型，与微软关系微妙；自研 Nova 模型的竞争力存疑
  • 收购 DuckLabs（DuckDB）：分析型数据库与 AI 数据底座整合动作，可能冲击 Snowflake/Databricks 阵营
  • Agentic AI 叙事能否转化为收入：官方承认"88% 的智能体试点会停滞"，既推工具也暴露落地难度
