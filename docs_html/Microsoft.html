Microsoft

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：1. AI / 模型 / AI 平台 | 地区：国外 | 类型：龙头 | 成立：1975 护城河：Copilot 全线产品化，OpenAI 最大外部股东，企业分发渠道

一、公司概况

主营业务与产品服务

Microsoft 是全球软件与云双龙头，业务按财报分为三大板块（FY26 Q4，截至 2026-06-30 季度营收 $90.0B，+18%）： - Intelligent Cloud（$39.3B，+32%）：核心是 Azure，Azure 及其他云服务收入 +43%，FY26 全年 Azure 营收首次突破 $100B - Productivity and Business Processes（$37.8B，+14%）：Microsoft 365 商用云（+14%）与消费云（+24%）、LinkedIn（+12%）、Dynamics 365（+13%） - More Personal Computing（$12.9B，-4%）：Windows OEM 与设备（-7%）、Xbox 内容与服务（-10%）、搜索广告（除流量获取成本 +10%）

AI 层以 Copilot 品牌全线铺开：消费者端 Microsoft Copilot（copilot.microsoft.com 及移动 App，免费起步），企业端 Microsoft 365 Copilot（付费席位已超 3000 万），开发者端 GitHub Copilot，安全端 Microsoft Security Copilot，外加 Copilot Studio 智能体构建平台。

整体战略方向

  • 官方定调 FY26 为"从 AI 试验走向 Frontier Transformation（前沿转型）"，CEO Satya Nadella 提出"推进成本-成效曲线的前沿，把 token 变成业务结果"
  • Copilot 全线产品化：把 AI 助手嵌入 Windows、Microsoft 365、Teams、GitHub、安全等所有产品线，按席位/订阅变现
  • 云 + AI 基础设施双轮：Azure 独家承载 OpenAI 模型分发，同时大规模自建 AI 算力；Microsoft Cloud 季度收入 $59.3B（+27%），商业剩余履约义务（RPO）+84% 至 $678B
  • 模型投资组合对冲：既是 OpenAI 最大外部股东（非 GAAP 口径专门剔除 OpenAI 投资影响），又持有 Anthropic 投资（FY26 Q4 确认 $3.2B 投资收益）
  • FY27 起启用新的分部与投资者指标口径（2026-09-02 公布），反映 AI 业务在财报中的权重上升

二、产品分类

AI / Copilot 产品

  • Microsoft Copilot：消费者 AI 助手，Web（copilot.microsoft.com）+ 移动 App，免费起步
  • Microsoft 365 Copilot：嵌入 Word/Excel/PowerPoint/Outlook/Teams 的企业 AI 助手，付费席位超 3000 万
  • GitHub Copilot：开发者编程助手，提供商业版与企业版许可
  • Microsoft Security Copilot：安全运营场景的 AI 助手
  • Copilot Studio：低代码构建/测试/发布智能体（agent），可发布到 Microsoft 365 Copilot

生产力与协作

  • Microsoft 365：Office 应用订阅（个人/家庭/商业版），消费云收入 +24%
  • Microsoft Teams：会议、聊天与协作平台
  • LinkedIn：职业社交与招聘/营销/学习平台，收入 +12%
  • Dynamics 365：ERP/CRM 企业应用，收入 +13%

操作系统与硬件

  • Windows 11：面向消费者的 PC 操作系统及企业版（混合办公、安全）
  • Surface 系列：Surface Laptop 13 英寸（第 2 版）、Surface Pro 12 英寸（第 2 版）等自有硬件

游戏与消费

  • Xbox：主机 + 内容与服务（FY26 Q4 内容与服务收入 -10%，当季计提了 Xbox 相关遣散与减值费用）
  • Bing / 搜索广告：含 Image Creator 等 AI 功能，搜索广告收入（除 TAC）+10%
  • Microsoft Designer：AI 图像设计工具

三、服务分类

云服务（Azure，赛道 3 另有 "Microsoft Azure" 专档）

  • Azure 云计算：计算、存储、网络、数据库等全栈 IaaS/PaaS，FY26 全年营收首破 $100B
  • Azure AI / Microsoft Foundry：模型与智能应用开发平台，提供模型评估指标、RAG 等能力；Azure OpenAI Service 独家分发 OpenAI 模型

订阅服务

  • Microsoft 365 个人/家庭订阅（含 Copilot 能力分层）
  • Microsoft 365 Copilot 企业席位订阅（需叠加符合条件的 Microsoft 365 许可）
  • GitHub Copilot Business / Enterprise 许可

企业支持与采纳服务

  • Microsoft Adoption：帮助企业落地 Copilot/Microsoft 365 的采纳服务与资源
  • AI Learning Hub、企业培训与文档体系

四、解决方案分类

企业 AI 转型方案

  • "Frontier Transformation"：以 Copilot + Copilot Studio + Azure AI 组合，帮企业把 AI 从试验推进到生产环境
  • 行业落地：官网 IR 页展示的客户案例覆盖医疗（NHS England、Novo Nordisk）、零售（Grupo Bimbo）、金融（SimCorp）、制造（Stellantis）、咨询（EY）等行业

安全与合规方案

  • Microsoft Security Copilot + 企业级安全/合规体系（企业数据权限继承、隐私设置管理）

生态合作方案

  • 与 OpenAI：Azure 独家云 + 最大外部股东，模型-云-分发深度绑定
  • 与 Anthropic：财务投资关系（FY26 Q4 确认 $3.2B 投资收益）
  • Windows OEM / 硬件伙伴生态，Copilot 向 PC 终端下沉

六、总结

强势业务或产品推荐

  • Azure + Azure AI：+43% 的增速、全年破 $100B，是 AI 云最强的变现通道，值得持续跟踪增速与 RPO
  • Microsoft 365 Copilot：3000 万+ 付费席位，是企业 AI 按席位变现的标杆，渗透率和续费率是关键指标
  • GitHub Copilot：开发者入口的默认选项之一

强势战略留意

  • "Frontier Transformation"叙事能否兑现为企业大规模付费（关注 2026-10-28 FY27 Q1 财报及新分部口径首秀）
  • OpenAI 关系演变：既是最大外部股东又是竞合对象，非 GAAP 剔除 OpenAI 投资影响说明其波动已大到需要单列
  • Anthropic 投资浮盈 $3.2B：多模型对冲策略值得留意后续加码
  • More Personal Computing 板块（Windows OEM、Xbox）连续承压，关注是否会进一步向 AI/云集中资源
