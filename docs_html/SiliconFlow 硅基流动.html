SiliconFlow 硅基流动

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国内 | 类型：新型 | 成立：2022 护城河：第三方开源模型推理云，聚合模型 API

一、公司概况

主营业务与产品服务

硅基流动（北京硅基流动科技股份有限公司）是国内独立第三方大模型推理云（MaaS）厂商，自我定位为"Token 工厂"：以自研推理引擎为底座，把分散、异构的算力转化为标准化的大模型 API（Token）输出。核心产品 SiliconCloud 聚合 100+ 主流开源/商用模型（DeepSeek、Qwen、GLM、Kimi、混元等），官方口径为"中国最大的独立词元（Token）供应平台"，宣称超 1,000 万注册用户、1.3 万家企业客户。业务分层：开箱即用的大模型 API（按量计费）→ 预留实例（企业独占算力）→ 推理加速服务 → 私有化部署。创始人袁进辉（清华博士，曾创办一流科技 OneFlow，后被美团收购）。注：公司.json 记录成立时间为 2022，公开报道多记为 2023 年 8 月。

整体战略方向

  • 使命表述为"加速 AGI 普惠人类"，商业定位是独立中立的 Token 供应平台，不自研基座大模型，专注推理层
  • 资本市场路径明确：2026-06-30 已向港交所主板递表，冲刺"Token 工厂第一股"；2026 年内累计融资近 29 亿元（6 月 B 轮超 20 亿、投后估值 77.4 亿元；9 月 B+ 轮二期及 C 轮约 8–9 亿元），投资方含中国互联网投资基金、国新基金、中国移动链长基金等国家级/国资背景机构
  • 国产算力路线：自研推理引擎强调跨芯片、多模型适配，支持国产异构 GPU；与摩尔线程联合发布 PD 分离异构混部白皮书，宣称国产 GPU 可 2:1 等效对标国际高端 GPU
  • "Token 经济"生态打法：与算力方联合运营（如数家科技 × 算家计算"算力联合运营、共建 Token 工厂"），并深度参与华为全联接大会、运营商大会，推动算力资源向 Token 服务转化

二、产品分类

模型 API 产品（SiliconCloud）

  • 对话/语言模型 API：聚合 deepseek-ai、Qwen、Z.ai（GLM，含高速版 GLM-5.3）、Kimi、hunyuan、meituan-longcat、Stepfun-ai、ByteDance、inclusionAI、Baidu、ChinaTelecom、BAAI 等厂商模型，按输入/输出/缓存命中 Token 计价
  • 生图模型 API：Tongyi-MAI、Qwen 图像、Kolors 等，按张计价
  • 语音模型 API：ChinaTelecom、Qwen、openmoss、FunAudioLLM 等，按千字符计价
  • 视频模型 API：Wan 系列，按个计价
  • 兼容协议：兼容 OpenAI 与 Anthropic 协议，可无缝对接现有工具链

企业级产品

  • 预留实例（Dedicated Instances）：面向企业核心推理场景，提供独占算力、精度保障与成本优化
  • 私有化部署产品：企业级 MaaS 平台（本地部署）、私有化大模型服务网关（Private LLM Service Gateway）、AI 算力运营服务（AI Compute Operation Services）

三、服务分类

平台服务

  • 大模型 API 按量计费：覆盖语言、语音、图片、视频、Embedding 等模态，1 个 API 调用 100+ 模型
  • 预留实例服务：独占算力租赁，支撑关键业务稳定运行

技术服务

  • 高效能模型推理加速服务：基于自研推理引擎，支持主流模型及客户自有模型接入，提供模型适配到推理部署全流程服务；官方宣称推理延迟最高降 70%、吞吐提升 3–5 倍、动态量化降低推理算力需求 60%–80%
  • 私有化部署服务：一站式解决模型性能优化、部署与运维；支持 BYOC（Bring Your Own Cloud）、计算/网络/存储三重隔离、混合云部署

四、解决方案分类

行业解决方案

  • 互联网：内容生成与个性化推荐，快速切换模型、优化 GPU 算力效率
  • 教育 / 政务 / 智算中心 / AI 硬件：官网列为重点服务行业，公开细节有限
  • 工业制造：已披露电子制造企业 AI 落地客户案例（多样化推理服务）

场景解决方案

  • Agent & Coding：一键接入主流 Agent 与编程应用
  • AI 应用开发 / 内容创作：文本、图像、视频生成模型辅助创作
  • 企业智能化：私有化部署 + 预留实例满足核心推理需求
  • 算力联合运营：与算力持有方共建"Token 工厂"，硅基流动输出引擎与运营能力

六、总结

强势业务或产品推荐

  • SiliconCloud 聚合模型 API：国内独立第三方推理云的头部入口，DeepSeek/Qwen/GLM 新模型"高速版"上新速度快，是观察开源模型落地与 Token 价格走势的最佳样本
  • 预留实例 + 私有化部署：毛利结构优于纯 API 按量业务，是其从"亏本卖 Token"（公开报道其 2025 年毛利率为负）走向盈利的关键抓手，值得跟踪

强势战略留意

  • 港股 IPO 进程：2026-06 递表、9 月再融近 9 亿，上市成败与招股书披露的单位经济模型（每 Token 成本曲线）是该赛道的风向标
  • 国产算力绑定：与摩尔线程等国产 GPU 的 PD 分离混部方案若规模化验证，将重塑推理成本结构并强化其政策/国资资源位
  • "Token 工厂"联合运营模式：与算力方分成运营，轻资产扩张算力供给，需留意该模式的稳定性与利益分配
