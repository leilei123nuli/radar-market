一、公司概况

主营业务与产品服务

中科寒武纪科技股份有限公司（688256.SH，2020-07 科创板上市），2016 年成立，创始团队出自中科院计算所（陈天石/陈云霁兄弟）。专注人工智能核心芯片的研发、设计与销售，官方口径为"云边端一体、软硬件协同、训练推理融合、统一生态"的系列化智能芯片 + 平台化基础系统软件。

业务分三条产品线：云端产品线（思元系列训练/推理芯片及加速卡，当前绝对主力）、边缘产品线（思元220 模组/加速卡）、IP 授权及软件（终端处理器 IP + NeuWare 软件平台）。收入结构已高度集中：2025 年营收 64.97 亿元（+453%），云端产品线占 99.69%，归母净利 20.59 亿元，上市以来首次年度盈利；2026 上半年营收 59.96 亿元（+108%）、归母净利 23.11 亿元（+123%），云端占比升至 99.98%，边缘仅 87.7 万元，IP 授权及软件已不再单列。

整体战略方向

  • 全面押注云端大算力：以大模型训练/推理芯片（当前旗舰思元590）承接国产算力替代需求，客户集中于互联网、金融、通信等领域头部厂商（媒体披露含字节跳动、百度、阿里、中国移动等）
  • 软硬件一体生态：以 NeuWare 软件平台 + MagicMind 推理引擎降低从 GPU 迁移的成本，对标 CUDA 生态短板补课
  • 供应链安全导向的国产替代受益者：美国对华 AI 芯片出口管制升级直接推动其订单与备货（2026 中报存货约 82 亿元）
  • 边缘与终端 IP 业务战略收缩，资源向云端集中

二、产品分类

云端智能芯片及加速卡（核心）

  • 思元590 系列（MLU590）：当前旗舰训练芯片，7nm + chiplet，MLUarch 架构，媒体实测综合性能对标 NVIDIA A100 的 80–90%；已进入批量交付，支撑千卡级大模型训练集群（注：官网产品页未列出该型号，信息来自财报及公开报道，官方未公开详细参数）
  • 思元370 系列（MLU370）：第三代云端芯片、首款 chiplet 产品，7nm、390 亿晶体管、256 TOPS(INT8)，MLUarch03 架构 + MLU-Link 多芯互联，推训一体；加速卡型号：
  • MLU370-S4/S8：高密度云端推理加速卡（S4 半高半长、S8 全高双宽）
  • MLU370-X4：推训一体云端加速卡
  • MLU370-X8：双芯思元370 + MLU-Link，面向中高端训练场景
  • 思元270 系列（MLU270）：上一代云端产品，型号 MLU270-S4 / MLU270-F4（存量市场）

边缘智能产品

  • 思元220 系列（MLU220）：边缘端 AI 芯片，形态为 MLU220-SOM 智能模组 与 MLU220-M.2 边缘加速卡；当前收入贡献已可忽略（2026H1 边缘线收入 87.7 万元）

终端智能处理器 IP

  • Cambricon-1M / Cambricon-1H：终端 NPU IP 授权（起家业务，2017 年曾用于华为麒麟970）；IP 授权收入在 2026 半年报中已消失，业务实质淡出

基础系统软件平台

  • Cambricon NeuWare：软件开发平台，含训练软件平台（支持主流框架原生分布式 + Horovod，底层算子库 CNNL、通信库 CNCL，提供模型快速迁移工具）
  • MagicMind：推理加速引擎，号称业界首个基于 MLIR 图编译技术实现商业化部署的推理引擎，支持 FP32/FP16/INT16/INT8、动态张量、与 TensorFlow/PyTorch 深度融合，可部署至寒武纪全系列产品

六、总结

强势业务或产品推荐

  • 云端思元590 系列：国产大模型训练算力的核心供给之一，2025–2026 年放量的唯一引擎，收入占比 >99.9%，值得跟踪交付/存货转化节奏
  • NeuWare + MagicMind 软件栈：决定客户迁移成本与复购的护城河变量，生态成熟度是其与华为昇腾竞争的关键

强势战略留意

  • 收入极端集中于云端单线 + 头部大客户，客户结构与中移动/互联网大厂资本开支强绑定，波动风险高
  • 美国出口管制与国产替代政策是其需求的最大外生变量；先进制程（7nm）代工与 HBM 供应的可持续性需持续跟踪
  • 边缘与 IP 业务已实质退出，观察是否彻底剥离；下一代产品（媒体称思元690 路线）能否跟上 NVIDIA/昇腾迭代节奏
  • 2026 中报 82 亿存货备货能否如期转化为收入，是短期业绩的核心观察点
