一、公司概况

主营业务与产品服务

无问芯穹（Infinigence AI / 上海无问芯穹智能科技股份有限公司）是清华电子系背景（2023 年 5 月在清华电子系推动下成立）的 AI 原生基础设施服务商，自我定位为"通用人工智能基础设施服务商（AGI Infrastructure Service Provider）"。核心是连接"M 种模型"与"N 种芯片"的 M×N 技术范式，以多元异构、软硬协同、自主式 AI 三大核心技术实现多种模型算法与多种芯片硬件间的效率与成本优化。两大核心产品为 Agentic Infra 自主式基础设施平台（大规模模型训练推理一体化平台）与 Agentic MaaS 大模型服务平台（输出大规模 AI 智力的"Token 工厂"），官方宣称可支持十万卡级超大规模训练/推理/强化学习任务，正以万亿级日均 Token 调用量服务头部 AI 企业与科研机构，客户百余家行业头部。公司总部在上海徐汇模速空间，北京设有办公点；CEO 夏立雪、首席科学家戴国浩，清华汪玉教授深度参与。

整体战略方向

  • 使命"释放无穹智能，让 AGI 触手可及"：用系统级创新让人工智能成本万倍下降，让智能从数字世界走向物理世界
  • 2026-07 发布"前店后厂一中心"Agentic Infra 战略布局：以智能体蜂群（Agent 运维/运营/协同）重构基础设施，让基础设施具备环境感知、决策行动与自进化能力
  • 卡位"Token 经济枢纽"：MaaS 层做 Token 生产与分发（与上海移动共建"天问计划"生态联盟），2026-05 再获超 7 亿融资
  • 多元异构绑定国产算力生态：一套基座纳管 16 种主流芯片（NVIDIA、AMD、华为昇腾、天数、沐曦、寒武纪、壁仞等），与 AMD 共建云边端全链路开源生态，承建多地公共算力平台（北京人工智能公共算力平台、杭州市算力资源调度服务平台、模速空间"算力生态超市"）
  • 向具身智能基础设施扩张：与清华等联合开源 RLinf（强化学习框架）、RLark（具身云原生平台）、APXInf（具身端侧推理引擎）、RPent（具身智能体基础设施）
  • 模型方协同：2026-08 与 MiniMax 达成战略合作，推动基础设施与模型能力协同创新

二、产品分类

Agentic Infra 自主式基础设施平台（训推一体化）

  • 多元异构基座：16 种主流 AI 芯片统一纳管、池化与智能调度，百卡到万卡线性扩展，新芯片接入适配缩短至天级
  • 大模型训练：万卡级预训练/后训练/强化学习全场景，通信加速、异步 Checkpoint 分钟级容错恢复、可视化监控
  • 大模型推理：生产级推理全链路优化，支持 1T+ 参数超大 MoE 分布式推理、Prefill-Decode 分离架构、ComfyUI 等 AIGC 工作流托管、分钟级百实例弹性扩缩
  • 企业级智能体：面向 AI Native 企业的智能体运行与协同平台，含平台运维 Agent、运营决策 Agent、A2A 协作蜂群与安全沙箱底座
  • 具身智能工具链 RLinf：面向具身智能"渲训推一体化"的大规模强化学习框架（2025-09 开源，Apache-2.0，4000+ Star，支持 PPO/GRPO 等 10+ 算法）

Agentic MaaS 大模型服务平台（Token 工厂）

  • 多模态模型全覆盖，对 DeepSeek、GLM、Kimi、MiniMax、Qwen 等主流开源模型深度优化，新模型 Day0 上新
  • 兼容 OpenAI / Anthropic API 格式，零成本迁移；支持 Function Calling、结构化输出、流式返回
  • 统一接入与流量治理（Cache-aware 路由、秒级流量切换、灰度回滚）、推理执行性能优化、智能服务运维（85% 故障自愈）

智能硬件产品（以 InfiniMizar 推理加速引擎为核心）

  • 智能模组：面向 Agent 应用与硬件开发者的开发套件，用于 AI 玩具、AI 网关、AI 智慧屏、AI BOX 等终端
  • 桌面 AI BOX：面向 Agent 生态的桌面硬件，主打隐私保护与大小模型路由降本，分千元级/万元级配置
  • 机架式一体机：兼容英伟达/华为/国产化平台，搭载 Mizar 引擎与可视化平台，面向政务、金融、教育、医疗私有化部署
  • FPGA 定制版："CPU + 分发 GPU + 计算 FPGA"三层架构，支持 DeepSeek-R1 671B 等超大模型全量推理（承自 FlightLLM 技术线）

开源与研究项目（技术外溢，非直接售品）

  • Megrez-3B-Omni：全球首款端侧全模态理解模型（2024-12 开源）
  • FlashDecoding++：GPU 推理提速 2-4 倍（2023-10 发布）
  • RLark：联合清华大学开源的具身智能云原生平台（2026-09）
  • APXInf：联合清华、上交开源的具身端侧推理引擎（2026-09，Pi 0.5 性能 SOTA）
  • RPent：联合清华、正行创新开源的具身智能体基础设施（2026-09）

算力平台与调度服务

模型服务（MaaS）

  • 模型 API 按 Token 计费、按并发包月、Coding Plan 订阅等多种计费
  • 模型定制优化、推理加速、精度对齐（官方称精度对齐率 >99.9%）与全托管运维

工程技术与托管服务

  • 定制化 AI 基础设施解决方案咨询与交付（训练/推理集群建设、迁移适配）
  • 全托管运维：集群部署、系统配置、日常巡检、7×24 监控响应
  • 企业级智能体服务（2025-12 发布智能体服务平台）：智能体定制优化、部署托管到商业化变现的全链路陪伴式落地

四、解决方案分类
