一、公司概况

主营业务与产品服务

字节跳动以"激发创造，丰富生活"为使命，业务呈双层结构：底层是内容分发与广告基本盘（抖音、今日头条、TikTok 等，承担流量与营收），上层是快速扩张的 AI 业务——自研 Seed / 豆包大模型系列，向上分为消费者 AI 产品（豆包、即梦 AI、剪映）与企业级 AI 云服务（火山引擎、火山方舟）两层结构。AI 实验室品牌为"字节跳动 Seed"，覆盖语言、视觉、语音、多模态与前沿研究。

整体战略方向

  • 模型高频迭代：Seed 系列快速跟进前沿（2026-07 至 08 密集发布 Seedream 5.0 Pro、Seed Audio 1.0、Seedance 2.5、SeedRealtime、Seed 2.1 智能体模型），聚焦 Coding 与 Agent 生产力场景
  • C 端超级入口：豆包 App 作为 AI 助手主入口，复用抖音系分发能力
  • B 端 AI 云：火山引擎定位"你的 AI 云"，从模型、工具、应用到云底座一站交付，方舟 Agent 平台低价获客（Agent Plan 首月 9.9 元起），正面争夺企业 AI 预算
  • 内容生态联动：Seedance 与经典影视 IP 合作（如周星驰电影 IP），AI 生成能力反哺内容生态
  • 公益与治理：承诺 2030 年实现运营碳中和

二、产品分类

消费级 AI 产品

  • 豆包：核心 AI 智能助手 App（doubao.com，需登录使用），C 端主入口
  • 豆包工作：面向办公场景的豆包衍生产品
  • 即梦 AI：AI 图像/视频创作产品
  • 剪映：视频剪辑工具，已接入 Seed 模型能力（海外版 CapCut）

模型产品（Seed / 豆包大模型系列）

  • Seed 2.1：面向真实生产力场景的全新智能体模型
  • 豆包大模型 Evolving：高频迭代主线模型，聚焦 Coding & Agent 场景（火山引擎 API：输入 6 元/百万 tokens，输出 30 元/百万 tokens）
  • Seedance 2.5 / 豆包视频生成模型 2.5：视频生成，支持 30 秒超长叙事与全模态参考（2026-07-31 发布）
  • Seedream 5.0 Pro / 豆包图像创作模型 5.0：图像创作，搭载联网检索（2026-07-08 发布）
  • Seed Audio 1.0：音频创作模型（2026-07-20 发布）
  • SeedRealtime：音视频全双工大模型，走向全模态自然交互（2026-08-05 发布）
  • 豆包语音识别模型 2.0：混合语言识别与音频深度解析

内容与其他消费产品

  • 抖音 / TikTok：短视频双引擎（国内/海外），公司流量与广告基本盘
  • 今日头条、西瓜视频：图文与长视频内容平台
  • 飞书（Lark）：企业协作办公套件

三、服务分类

模型平台服务

  • 火山方舟：一站式大模型服务平台，提供模型广场、推理/训练 API，支持方舟 CLI（@volcengine/ark-cli）终端接入
  • API 按量计费：豆包系列模型按 tokens / 张图 / 小时计价（如图像创作 0.22 元/张，语音识别 0.8-1.0 元/小时）

企业与开发者服务

  • TRAE CN：AI 编程工具（"The Real AI Engineer"），支持 Vibe Coding 全流程
  • HiAgent："1+N+X"一站式智能体工作站
  • AgentKit / Managed Agents：企业级 Agent 平台与全托管 Agent 服务
  • 机器学习平台：企业级云原生机器学习平台
  • 基础云服务：云服务器、对象存储（10EB 级规模）、云数据库 MySQL 版等
