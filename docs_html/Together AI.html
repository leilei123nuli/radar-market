一、公司概况

主营业务与产品服务

Together AI 自我定位为 "The AI Native Cloud"：以开源模型推理云起家，现已扩展为覆盖 AI 开发全流程（experimentation → massive scale）的全栈云平台。核心业务分三层：推理服务（Serverless / Batch / Dedicated Inference）、训练与算力（GPU Clusters / Accelerated Compute、Fine-tuning）、以及 AI 原生平台组件（Code Sandbox、Storage）。底层差异化来自 Together Research 的系统研究能力（FlashAttention 系列、ThunderKittens、Together Kernel Collection 等），把研究成果直接转化为推理/训练性能与成本优势。

整体战略方向

  • 从"开源模型推理 API"升级为"AI Native Cloud"全栈平台：推理 + 训练算力 + 存储 + 开发环境一体化
  • 研究驱动性能：以 FlashAttention、ThunderKittens、推理加速（推测解码、CPD、ATLAS 等）等自研成果压低单位成本、抬高速度，作为核心竞争力
  • 绑定开源模型生态：第一时间上架 Llama、DeepSeek、Mixtral 等开源模型，吃开源模型采用率红利
  • 向生成式媒体（视频/音频/图像）负载与 Agent 开发基础设施（Code Sandbox）扩展，拓宽 TAM

二、产品分类

推理产品（Inference）

  • Serverless Inference：按需调用 100+ 开源模型的 API，无需管理基础设施，按量计费
  • Batch Inference：异步大批量处理，单模型可扩展至 300 亿 token，主打低成本离线负载
  • Dedicated Model Inference：专属基础设施部署模型，面向要高速度、强控制与最优经济性的团队；含承诺用量档位（token 计费 + 预留吞吐 + 99% uptime SLA）
  • Dedicated Container Inference：面向生成式媒体（视频/音频/图像模型）的 GPU 推理基础设施，由 Together Research 提供性能加速

算力产品（Compute）

  • Accelerated Compute / GPU Clusters：从自助即时集群扩展到数千张 GPU，配 Together Kernel Collection 优化训练性能（客户案例：Pika Labs 从零训练视频模型）

平台组件

  • Code Sandbox：面向 AI 应用与 Agent 的大规模安全代码沙箱（整合 CodeSandbox SDK，支持快照/秒级恢复）
  • Storage：AI 原生负载的高性能托管存储（对象存储 + 并行文件系统，零出口流量费）

三、服务分类

模型服务

  • 开源模型托管推理 API：100+ 模型，新模型上架速度快（Llama 3 发布当天即可用）
  • Fine-tuning：开源模型托管微调服务，支持全参数微调，私有数据不出域（Together Cloud 或客户 VPC 内）

企业级服务

  • 企业部署：专属实例 / VPC 内私有部署，强调隐私（私有数据不用于改进他人模型）
  • 专家支持：数据准备、模型训练、上线部署的伴随式服务；自定义模型接入（如 Cartesia 自研 SSM 模型 Sonic 两周内上线）

研究转化服务

  • Together Research 产出（FlashAttention-3/4、ThunderKittens、推测解码、CPD、量化 QTIP/YAQA 等）持续下沉为平台性能能力

六、总结

强势业务或产品推荐

  • Serverless / Dedicated Inference：开源模型推理的头部第三方平台，新模型上架速度和推理性能是核心卖点，值得跟踪其模型目录与定价变化
  • GPU Clusters + Fine-tuning：从推理向训练算力延伸的部分，决定其能否吃到模型厂商（而非仅是应用方）的预算
  • Together Research：FlashAttention、ThunderKittens 等成果是全行业基础设施，研究→产品的转化效率是其长期护城河

强势战略留意

  • "AI Native Cloud" 全栈化：推理云 → 训练算力 + 存储 + Code Sandbox 的平台扩张，正面对标 CoreWeave（算力）与云厂商 AI 平台，需留意资本开支与毛利压力
  • 生成式媒体专用推理（Dedicated Container Inference）：视频/音频生成负载增长快，是差异化卡位
  • Agent 基础设施（Code Sandbox）方向的投入：对应 Agent 负载爆发的提前布局
  • 开源模型生态依赖度：若开源模型与闭源前沿差距拉大，平台价值会受挤压——这是其商业模式的结构性风险
