一、公司概况

主营业务与产品服务

Perplexity 是 2022 年 8 月成立于旧金山的 AI 搜索公司（创始团队来自 OpenAI、Meta AI、Quora、Databricks），核心产品是"答案引擎"（Answer Engine）：用大模型直接给出带引用来源的答案，而非链接列表。截至 2026 年，已从单一搜索框扩展为覆盖消费搜索、AI 浏览器（Comet）、AI 智能体（Perplexity Computer）、开发者 API（Sonar API）与企业版的完整平台。商业化全押订阅 + API：2026 年 2 月正式宣布全面退出广告业务。据公开报道，2026 年中年化收入（ARR）已从年初不足 2.5 亿美元升至超 7.5 亿美元，月活用户约 3000 万级；2026 年 8 月报道英伟达正洽谈参与其新一轮融资，估值将超 300 亿美元。

整体战略方向

  • 定位"答案引擎"独立品类：与 Google 广告模式彻底切割（2026-02 放弃广告），收入全押订阅 + API
  • 模型层"混合路由"策略：不自建顶级基础模型，约 80% 免费/简单查询由自研 Sonar 系列（基于 Meta Llama 微调、注入实时检索）承接以压低边际成本，高阶查询路由至 GPT、Claude、Gemini、Grok 等第三方顶级模型；判断"基础模型会商品化，差异化在产品层"
  • 入口扩张：以 Comet AI 浏览器（2026-03 起全平台免费）+ Perplexity Computer 智能体争夺下一代用户入口，从"搜索网站"转向"浏览器 + 代理操作系统"
  • 企业与开发者市场：Enterprise 版、Sonar API、政府渠道（2025-11 与美国 GSA 签 OneGov 合约）拓展 B 端收入
  • 生态绑定：引入英伟达（GPU 供应）、Jeff Bezos、Databricks、软银等战略投资人；2026-01 与微软 Azure 签三年 7.5 亿美元 GPU 算力承诺

二、产品分类

消费级产品

  • Perplexity Search：基础 AI 答案引擎（2022-12 上线），回答附引用来源，免费
  • Comet：基于 Chromium 的 AI 原生浏览器（2025-07 首发，2026-03 起 Mac/Windows/Android/iOS 全球免费），内置 Comet Assistant 可跨页面执行多步操作
  • Perplexity Computer：云端 AI 智能体（2026-02 推出），面向专业用户自动执行电脑端复杂工作流，为当前营收增长核心引擎（Max 订阅限定）

研究/生产力功能

  • Deep Research：多步骤深度研究报告生成
  • Model Council：（2026-02 推出）同一问题并行送多个顶级模型，整合共识与分歧
  • Spaces / 文件分析：协作空间与文档问答（公开细节有限）

模型与开发者产品

  • Sonar 系列模型：自研搜索增强模型，承接大部分免费查询
  • Sonar API：开发者 API（2024 推出），搜索 + LLM 一体化、返回带引用答案，按 token 计费（约 $1–15/M tokens），附 SDK 与开源评估框架 search_evals

三、服务分类

个人订阅

  • Free：基础搜索免费
  • Perplexity Pro（$20/月）：多模型切换、Deep Research、文件分析
  • Perplexity Max（$200/月）：最高个人档，含 Perplexity Computer 代理积分（每月 10,000 积分）
  • Comet Plus（约 $5/月）：Comet 浏览器附加方案

企业与开发者服务

  • Enterprise Pro（$40/座/月）：企业协作、SSO、SOC 2 合规
  • Enterprise Max（$325/座/月）：顶级企业版
  • Sonar API 按量计费：搜索增强推理调用，不支持微调（公开信息：此为已知短板）

四、解决方案分类

企业解决方案

  • 企业知识搜索与研究：Enterprise Pro/Max，主打带引用的可信答案 + 企业权限管理
  • 行业场景：金融、法律、咨询等高频研究场景的专业工作流（Computer + Deep Research）；细分行业定制方案的公开信息有限

政府与生态合作方案

  • 政府采购：2025-11 与美国总务管理局（GSA）签署 OneGov 合约，开放联邦机关采购
  • 终端预装合作：与三星洽谈 Galaxy 设备预装及浏览器集成（2025 年报道）；曾探索与苹果的搜索/AI 合作
  • 出版商关系：因内容抓取面临 NYT、Dow Jones 等版权诉讼，未来可能转向付费授权模式

六、总结

强势业务或产品推荐

  • Perplexity Pro 订阅 + Search：答案引擎品类的事实领导者，引用透明是真实差异化，订阅收入增长曲线极陡（ARR 15 个月数倍增长）
  • Perplexity Computer：2026 年增长核心引擎，Agent 化的生产力场景付费意愿强，值得重点跟踪
  • Sonar API：搜索 + LLM 一体化、TCO 低，开发者侧差异化清晰（短板：不支持微调）
  • Comet 浏览器：免费策略后快速起量，是争夺下一代入口的期权，但目前是 option value 而非护城河

强势战略留意

  • 放弃广告、全押订阅 + API：品牌差异化清晰但无退路，成败取决于 Enterprise 与 Pro/Max 扩张
  • 上游依赖的结构性脆弱：高阶体验依赖 OpenAI/Anthropic/Google 模型，而三家同时是竞争对手；断供、涨价或条款收紧都会直接冲击毛利与体验
  • 入口战：Comet + Computer 能否在 Google AI Overviews 与 ChatGPT 的夹击下成为独立入口；与三星等终端厂商的预装合作进展
  • 版权诉讼与出版商授权谈判：可能重塑其内容成本结构；英伟达领投的新一轮融资（估值超 300 亿美元）落地情况
