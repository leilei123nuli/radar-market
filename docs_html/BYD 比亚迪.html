一、公司概况

主营业务与产品服务

比亚迪业务横跨汽车、电子、新能源、轨道交通四大产业，定位为"从能源的获取、存储到应用"的零排放新能源整体解决方案商（官方表述）。汽车是绝对核心：同时掌握电池、电机、电控等新能源汽车全产业链核心技术，覆盖乘用车、商用车，为全球新能源汽车销量冠军；乘用车由比亚迪王朝、比亚迪海洋、方程豹、腾势、仰望组成多品牌矩阵。电子业务（比亚迪电子，0285.HK）覆盖智能手机、电脑、新能源汽车电子、AI 算力基础设施、智能家居、机器人等领域，为全球客户提供一站式产品解决方案。新能源业务涵盖电池、太阳能、储能。轨道交通业务为云轨/云巴。2025 年营业收入 8,039.6 亿元，归母净利润 326.2 亿元（官方投资者关系页财务摘要）。

整体战略方向

  • 整车垂直整合：电池（刀片电池）、电机、电控、半导体（IGBT）、整车全链自研，以规模效应压成本
  • 智能化下半场：2024 年发布整车智能战略及璇玑架构，2025 年发布智能化战略，以"天神之眼"辅助驾驶系统全价位下放打"智驾平权"；2026 年发布自研 4nm 智驾芯片璇玑 A3，并率先承诺"城市领航 + 智能泊车"双安全兜底，为全球唯一双兜底车企
  • 电动化技术持续迭代：2025 年发布超级 e 平台，2026 年发布第二代刀片电池及闪充技术
  • 全球化：业务遍及全球六大洲，海外建厂与出口并进
  • 多品牌向上：仰望/方程豹/腾势覆盖高端与个性化市场，王朝/海洋守主流基本盘

二、产品分类

乘用车（多品牌矩阵）

  • 比亚迪王朝：主流家庭市场，代表车型秦、汉、唐、宋、元、夏系列（DM-i 混动 + 纯电双线）
  • 比亚迪海洋：年轻化主流市场，代表车型海鸥、海豚、海豹、海狮及军舰系列
  • 方程豹：个性化越野品牌，代表车型豹5、豹8、钛系列，基于 DMO 超级混动越野平台
  • 腾势（DENZA）：豪华品牌，代表车型 D9（MPV）、Z9GT、N 系列
  • 仰望（YANGWANG）：百万级高端品牌，代表车型 U8（越野）、U9（超跑）系列，基于易四方平台

商用车

  • 纯电动大巴（K9 等，2010 年起商业化运营）、纯电动卡车、电动叉车等，覆盖公交、物流、环卫场景

电池与新能源产品

  • 刀片电池 / 第二代刀片电池（含闪充技术）：磷酸铁锂结构创新，自供 + 外供
  • 储能系统：电网级、工商业及家庭储能
  • 太阳能产品：光伏组件及电站

轨道交通产品

  • 云轨 / 云巴：跨座式单轨与胶轮有轨电车系统，2017 年银川首条商业化云轨、2021 年重庆首条无人驾驶云巴

核心技术平台（产品力载体）

  • e 平台 3.0 / 超级 e 平台：纯电专属平台
  • 第五代 DM 技术 / DM-i 超级混动：插混系统
  • 璇玑架构 + 天神之眼：整车智能与辅助驾驶系统
  • DiLink 智能座舱
  • 云辇：智能车身控制系统
  • 易四方 / 易三方 / DMO：高端电驱与越野平台
  • 灵鸢：智能车载无人机系统（2025 年发布）

四、解决方案分类

零排放交通解决方案

  • 城市公交电动化整体方案（电动大巴 + 充电设施，2010 年率先发布"公交电动化"战略）
  • 城市轨道交通方案：云轨/云巴"治污+治堵"（2016 年战略）

能源整体解决方案

  • "太阳能 + 储能 + 电动汽车"新能源闭环（2008 年完成布局）
  • 发电侧/电网侧/用户侧储能解决方案

智能化解决方案

  • 天神之眼辅助驾驶系统（分档配置下放全系车型）
  • 璇玑架构整车智能 + DiLink 座舱 + 智能生态的全场景智能出行方案
  • 智能泊车/城市领航安全兜底承诺（全球唯一双兜底车企）

六、总结

强势业务或产品推荐

  • 王朝/海洋主流车型 + 第五代 DM / 超级 e 平台：规模效应最集中的基本盘，值得跟踪其量价结构
  • 天神之眼智驾下放：把高阶辅助驾驶打入 10 万级市场，是行业"智驾平权"的定价权动作
  • 储能业务：电池产能外溢的第二增长曲线，全球储能需求高景气

强势战略留意

  • 自研 4nm 智驾芯片璇玑 A3：垂直整合从三电延伸到智驾芯片，若成将改写车载芯片供应格局
  • "城市领航 + 智能泊车"双兜底承诺：以责任承诺换智驾信任，观察是否倒逼行业跟进
  • 高端化（仰望/方程豹/腾势）与全球化建厂：决定其毛利结构能否脱离国内价格战
  • 第二代刀片电池与闪充：补能体验对标换电/超充阵营的关键一战
