一、公司概况

主营业务与产品服务

Meta 是"社交广告现金牛 + AI 全线转型"的双层结构：基本盘是 Facebook、Instagram、WhatsApp、Threads 四大社交应用的广告变现（Q2 2026 营收 $60.8B，同比 +28%，其中广告 $59.4B）；第二曲线是 AI——消费者端有 Meta AI 助手与新发布的 Muse 个人智能体，开发者端有 Meta Model API（dev.meta.ai）与 Muse Code，模型层由 Meta Superintelligence Labs（MSL）的 Muse 系列接棒 Llama 成为前沿主力；另有 Reality Labs 硬件业务（Quest 头显、Ray-Ban Meta AI 眼镜、Muse Charm，Q2 2026 收入 $431M、经营亏损 -$4.62B，眼镜为主要增长点）。

整体战略方向

  • 使命表述为"building the future of human connection"，AI 上由 Zuckerberg 定调"personal superintelligence for everyone"
  • 组织上：2025 年 6 月斥资约 $14B 引入 Alexandr Wang 组建 Meta Superintelligence Labs，首席科学家 Yann LeCun 离任，前沿模型研发收拢至 MSL
  • 模型策略转向"双轨"：前沿旗舰 Muse Spark 闭源、API 化收费（2026-04-08 发布，为五年来首个不开源的 Meta 前沿模型）；开源梯队保留 Llama 系列，并以 Muse Glimmer（30B，Apache 2.0）维持开源生态存在
  • 入口策略：Muse/Meta AI 铺满自有触点——独立 App、网页、WhatsApp、AI 眼镜及口袋设备 Muse Charm，正面争夺个人智能体入口
  • 基础设施：2026 年资本开支指引 $130–145B，巨额投入 AI 算力（Q2 2026 自由现金流已降至约 $784M）

二、产品分类

AI 助手与智能体

  • Meta AI：免费个人助手，覆盖 App、网页、AI 眼镜及 Meta 系应用内，支持问答、研究、购物与任务执行（2026 年内月活约 6 亿量级）
  • Muse：个人 AI 智能体（2026-09-08 发布），"不只回答问题，而是替你办事"，iOS/Android/Web/WhatsApp 多端可用，需绑卡且 18+，美国先行
  • Vibes：AI 视频生成与创作分享产品
  • Meta AI 媒体生成：图像生成/编辑（生成前先规划、可精修），免费，分布于 IG、WhatsApp、Meta AI App 与 meta.ai

模型产品（Meta Model API 在售）

  • Muse Spark 1.3：旗舰闭源模型，主打长时程编码与智能体任务
  • Muse Glimmer 1.2：30B 开源权重模型（Apache 2.0），面向常开本地智能体，经 Hugging Face 分发
  • Muse Image：智能体式图像模型，生成前规划、自我修正
  • Muse Voice Transcribe：语音转文字，支持说话人分离与话轮检测
  • SAM 3.1：文本提示的物体检测、分割与跟踪，覆盖图像与视频
  • Llama 系列：开源模型家族（2026 年 4 月发布 Llama 5），仍列于官方开源模型目录，但前沿梯队已移交 Muse

消费硬件

  • Meta Quest 3S：混合现实头显
  • Ray-Ban Meta AI 眼镜：AI 眼镜，Reality Labs 收入增长主引擎
  • Muse Charm：口袋大小的 Muse 专用交互设备（Connect 2026 发布，2026-09-30）

社交应用

  • Facebook / Instagram / WhatsApp / Threads：广告变现基本盘与 AI 产品分发渠道

三、服务分类

订阅服务

  • Muse Free / $20 / $100 三档：个人智能体订阅分层（免费档亦需绑卡验证）

开发者/平台服务

  • Meta Model API（dev.meta.ai）：Muse 系列及 SAM 等模型的按量调用平台，附 Docs / API References / Cookbooks / Playground
  • Muse Code：终端多智能体编码工具，由 Muse Spark 驱动，支持 macOS / Windows / Linux
  • 开源分发：Llama 开放平台 + Muse Glimmer 等经 Hugging Face / GitHub 开放权重与代码

广告服务

  • Meta 系应用广告投放与变现（AI 驱动，Q2 2026 广告收入 $59.4B，同比 +27%）

六、总结

强势业务或产品推荐

  • 广告现金牛 + AI 提效：Q2 2026 广告 +27%，AI 对广告系统的增益是当前利润引擎，值得跟踪其增速与 FCF 的剪刀差
  • Muse 智能体：发布节奏极快（4 月模型→7 月 API 收费→8 月 Muse Code→9 月智能体 App→Connect 硬件），移动端增长被报道超过 ChatGPT 早期速度，是个人智能体入口的头号变量
  • Ray-Ban Meta AI 眼镜：Reality Labs 中唯一验证增长的品类（带动 RL 收入 +16%）

强势战略留意

  • "开源护城河"正在重定义：公司.json 中的护城河表述为"Llama 开源生态"，但 2026 年 Meta 已将前沿旗舰 Muse Spark 闭源、API 化，Llama 退居开源梯队、MSL 主导闭源前沿——护城河实际正从"开源换标准"转向"触点分发 + 资本密度"，需持续观察 Muse Glimmer 等开源释放是否足以维持生态忠诚度
  • 资本开支悬崖：2026 capex 指引 $130–145B，Q2 FCF 同比约 -91% 至 $784M，EPS -13%，市场对开支的容忍度是股价核心变量
  • Muse 变现设计：强制绑卡、18+、$20/$100 分层、美国先行——比 ChatGPT 更激进的付费墙策略，其转化与留存数据值得盯紧
  • 组织风险：Alexandr Wang 主导的 MSL 与原有研究体系（FAIR 系）的整合，LeCun 离任后的研究路线走向
