一、公司概况

主营业务与产品服务

Databricks 是湖仓一体（Lakehouse）架构的主要推动者，由 Apache Spark 创始团队创立。核心产品 Data Intelligence Platform 把数据工程、数据分析、机器学习和生成式 AI 统一在同一套数据底座上，底层基于 Delta Lake 开放表格式，向上提供 Unity Catalog 治理、Databricks SQL、Delta Live Tables、Workflows 和 Mosaic AI。公司以多云 SaaS 方式交付（AWS / Azure / GCP），同时提供自托管方案。

整体战略方向

  • 从“数据湖 + 数据仓库”双栈走向湖仓一体，强调开放格式（Delta Lake / Iceberg）避免厂商锁定
  • 以 Unity Catalog 做跨数据与 AI 资产的统一治理，争夺企业数据目录与权限入口
  • Mosaic AI 把模型训练、微调、评估、部署和 Agent 编排放进数据平台，走“数据旁边做 AI”的路线
  • 通过 Marketplace 和合作伙伴生态扩展行业解决方案

二、产品分类

湖仓平台

  • Databricks Data Intelligence Platform：基于湖仓一体的企业数据与 AI 平台，统一数据工程、分析、机器学习和生成式 AI 工作负载
  • Delta Lake：开源事务型数据湖存储格式，支持 ACID、时间旅行、schema 演进和增量处理
  • Databricks SQL：Serverless SQL 数仓引擎，面向 BI 报表和交互式分析
  • Delta Live Tables：声明式数据管道，支持流批一体的 ETL 与数据质量约束

数据治理

  • Unity Catalog：跨工作区、跨云的数据与 AI 资产统一目录，提供权限、血缘、审计和发现能力
  • Databricks Marketplace：数据、模型、应用和解决方案的交换市场

数据工程与 AI

  • Databricks Workflows：作业编排、调度与可观测的数据工程工作流
  • Mosaic AI：企业级模型训练、微调、评估、部署与 Agent 构建平台
  • Mosaic AI Model Serving：统一模型推理与 Agent 服务托管
  • MLflow：开源机器学习生命周期管理，覆盖实验跟踪、模型注册和部署

三、服务分类

平台与云服务

  • 多云托管服务：AWS / Azure / GCP 上的全托管 Databricks 工作区
  • 自托管与混合部署：面向数据主权和合规要求的企业部署选项
  • 专业服务与培训：数据工程、湖仓迁移、AI 平台建设的实施与认证

四、解决方案分类

行业解决方案

  • 金融、零售、制造、生命科学、公共部门的数据平台与 AI 落地

场景解决方案

  • 数据工程与 ETL、BI 与自助分析、机器学习与生成式 AI、实时数据管道、数据治理与合规

六、总结

强势业务或产品推荐

  • Data Intelligence Platform：湖仓一体的事实标准之一，数据与 AI 工作负载在同一底座上闭环
  • Unity Catalog：治理能力是大型企业选型的核心差异点，也是数据资产入口
  • Mosaic AI：把模型训练/评估/部署放进数据平台，直接承接企业生成式 AI 需求

强势战略留意

  • 与 Snowflake 在湖仓/数据云正面竞争，同时面临 AWS、Azure、GCP 原生数据服务的挤压
  • 开放格式（Delta Lake / Iceberg）既是差异化，也要平衡商业化与生态控制力
  • Mosaic AI 能否把数据客户转化为 AI 平台客户，是下一阶段增长的关键
