一、公司概况

主营业务与产品服务

小马智行 2016 年创立于硅谷，是全球自动驾驶头部公司，已于纳斯达克（NASDAQ: PONY）与港交所（HKEX: 2026）双重上市。技术底座为"虚拟司机"（Virtual Driver）与自研世界模型 PonyWorld，向下复用至三大业务单元：Robotaxi（自动驾驶出行）、Robotruck（小马智卡 PonyTron）、乘用车智能驾驶（POV）。2026Q2 总收入 3,620 万美元（同比 +69%），其中 Robotaxi 收入 1,210 万美元（同比 +690% 以上），Robotaxi 车队规模约 2,000 辆（截至 2026-06-30），是全球少数实现全无人驾驶商业化运营的公司之一。

整体战略方向

  • 愿景 "Autonomous Mobility Everywhere"：以虚拟司机为统一技术栈，一套技术支撑出行、物流、乘用车三条线
  • 规模化量产商业化：与丰田中国、广汽丰田成立合资公司骓丰智能（投资超 10 亿元），规划千台级铂智4X Robotaxi 投放，搭载第七代自动驾驶乘用车系统
  • 生态"黄金三角"：技术方 + 车辆方 + 场景方深度合作（丰田、广汽、三一重卡、中国外运等），不独自造车、不独自做物流
  • 全球化扩张：业务覆盖中国、欧洲、东亚、中东，2026 年推进多哈 Robotaxi 商业化运营、与 Verne 在萨格勒布开展全无人测试

二、产品分类

自动驾驶出行（Robotaxi）

  • 小马智行 App / Robotaxi 服务：在北京、上海、广州、深圳开展全无人驾驶商业化收费，并接入支付宝、高德地图、如祺出行、随申行、锦江荟等第三方入口
  • 第六代 Robotaxi：2022 年 1 月发布，基于丰田赛那平台，车规级量产设计（车顶固态激光雷达 ×4、补盲激光雷达 ×3、远距毫米波雷达 ×3、摄像头 ×11）
  • 铂智4X Robotaxi：与丰田中国、广汽丰田联合研发的首款量产 Robotaxi 车型，搭载第七代系统，一期规划千台规模投放国内一线城市

自动驾驶卡车（Robotruck / 小马智卡 PonyTron）

  • 第三代自动驾驶卡车系统：2022 年 11 月推出，与三一重卡合作打造自动驾驶重卡，批量交付青骓物流，面向干线物流正向设计（一体式 Sensor Arc）
  • 第四代 Robotruck：2026 年 9 月与广汽商用车合作发布
  • "驼灵"编队方案："1+N"编队自动驾驶（1 辆领航车 + N 辆跟随车，仅领航车配安全员），已在北京、广州获准编队测试

乘用车智能驾驶（POV，2023 年 1 月发布三条产品线）

  • 小马识途：智能驾驶解决方案，分 PonyClassic / PonyPro / PonyUltra 三档差异化配置，基于 BEV 感知 + 导航地图实现高速/城市 NOA，均已取得定点并量产交付
  • 方载：车规级自动驾驶域控制器，基于 NVIDIA DRIVE Orin（单 Orin 风冷 / 双 Orin 风冷 / 双 Orin 液冷），通过 ASIL-D 开发流程认证
  • 苍穹：自动驾驶数据闭环工具链，覆盖研发测试全量数据闭环与量产影子模式数据闭环（大数据平台 + 云端大规模仿真平台）

三、服务分类

出行服务

  • Robotaxi 商业化收费运营（北上广深全无人），配套无人化远程协助平台与自动驾驶车队管理平台

货运物流服务

  • Robotruck 干线物流商业运营：持有国内首个面向自动驾驶的货运道路运输经营许可证、首张自动驾驶卡车高速编队测试许可；货运网络覆盖京津冀、珠三角、长三角并开启跨省货运

技术服务（面向车企 / Tier1）

  • 智驾软件方案、域控制器、数据闭环工具链的定点量产交付，可定制化高性能低成本方案

四、解决方案分类

Robotaxi 城市级落地

  • 与整车厂合资/合作的规模化量产方案（丰田模式：合资公司 + 车辆平台 + 全无人技术注入），目标千台级城市投放

智慧物流"黄金三角"

  • 技术（小马智卡）+ 车辆（三一重卡 / 广汽商用车）+ 场景（中国外运 / 青骓物流）闭环，含"驼灵"编队降本方案；官方口径可节省司机人力成本至少 40%

乘用车量产智驾

  • 软件方案（小马识途）+ 域控制器（方载）+ 工具链（苍穹）打包交付；方载亦适配城市配送、环卫、港口、矿区等低速无人驾驶场景

六、总结

强势业务或产品推荐

  • Robotaxi：核心增长引擎，收入同比 +690% 以上，车队约 2,000 辆，国内少数跑通全无人商业化收费的公司，值得持续跟踪其单车经济性与城市复制速度
  • 与丰田的合资量产线（铂智4X Robotaxi）：千台级规划若兑现，是 L4 车规级量产的标志性事件

强势战略留意

  • 海外第二曲线：中东（多哈商业化）、欧洲（与 Verne 合作萨格勒布全无人测试）落地节奏
  • Robotruck 四代车型与"驼灵"编队能否把干线物流做成盈利业务
  • POV 量产定点业务的收入兑现，与 Momenta 等方案商的正面竞争
  • 双重上市（NASDAQ + HKEX）后的融资与流动性结构变化
