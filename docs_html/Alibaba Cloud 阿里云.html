版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国内 | 类型：龙头 | 成立：2009 护城河：国内云份额第一 + Qwen 模型一体

一、公司概况

主营业务与产品服务

阿里云是阿里巴巴集团旗下云计算与 AI 平台，国内云市场份额第一（官网宣称"AI 云市场份额超过 2-4 名总和"）。业务分两层：底层是全栈云计算产品（弹性计算、存储、网络、数据库、大数据、安全、中间件、容器、Serverless、专有云），上层是 AI 栈——千问 Qwen 大模型矩阵 + 百炼 MaaS 平台 + 人工智能平台 PAI，形成"模型 → 平台 → 云基础设施"一体结构。基础设施覆盖 31 个全球公共云地域、107 个可用区、3200+ 边缘节点。

整体战略方向

  • "云 + AI"一体化：以 Qwen 开源模型建立全球影响力，再通过百炼 MaaS 和千问 AI 平台（Token Plan 订阅/按量）把模型调用变现，带动云资源消耗
  • 全模态模型矩阵：语言、视觉理解、图片生成、视频生成（万相）、全模态 Omni、语音识别全线铺开，旗舰 Qwen3.8 系列迭代节奏以"天"计，走开源 + 商业 API 双轨
  • Agent 化产品改造：编程（Qoder）、建站（万小智）、运维（STAROps）、分析（智能小Q）等云产品全面改为 AI Agent 形态
  • 全球化与合规：持续扩张海外地域与边缘节点，主打安全合规认证体系（ISO、SOC、等保、PCI DSS）

二、产品分类

大模型产品（千问 Qwen 矩阵）

  • Qwen3.8-Max：旗舰视觉语言大模型，0902 快照重点提升 Coding、Cowork 与视觉理解能力
  • Qwen3-VL-Plus：视觉理解模型，支持思考/非思考模式融合与超长视频理解
  • Qwen-Image-3.0-Pro：图片生成模型，支持 12 国语言多字体复杂图文生成
  • Wan3.0-Video（万相 3.0）：视频生成模型（邀测中），30 秒成片，支持参考/编辑/复刻/驱动
  • Qwen3.5-Omni-Flash：全模态模型，支持文本/图片/音视频理解交互，10 小时长音频
  • Fun-ASR：端到端语音识别模型实时版

AI 平台与工具

  • 百炼大模型服务平台：一站式大模型服务与应用开发平台（MaaS）
  • 人工智能平台 PAI：AI 开发、训练、推理一站式平台
  • Qoder / Qoder CN：基于千问大模型的智能体编程平台
  • 智能开放搜索 OpenSearch：内置 LLM 的一站式 AI 搜索云服务
  • 智能对话机器人 / 智能外呼机器人：基于千问的对话与外呼系统
  • 视觉智能开放平台：一站式视觉 AI 服务

云计算基础产品

  • 弹性计算：云服务器 ECS 等，自研 CIPU 架构
  • 容器：容器服务 ACK 等 Kubernetes 全生命周期管理
  • 存储 / 网络与 CDN / 安全 / 中间件：全栈 IaaS/PaaS 基础件
  • 数据库：关系型、非关系型、数据仓库与生态工具四大版块
  • 大数据计算：云原生大数据服务，提供大数据 AI 一体化方案
  • 媒体服务（视频云）：直播、点播、智能媒体服务
  • Serverless：函数计算 FC、Serverless 应用引擎等
  • 专有云：本地部署、与公共云同架构的企业级云平台

六、总结

强势业务或产品推荐

  • 千问 Qwen 模型矩阵 + 百炼 MaaS：国内"模型-云一体"最完整的全栈组合，Qwen 开源引流 → Token Plan/API 变现的链路已跑通，值得持续跟踪其模型迭代与定价动作
  • AI 云基础设施基本盘：国内云份额第一 + 奥运级大型项目背书，IaaS 基本盘为 AI 业务提供成本与渠道优势

强势战略留意

  • Qwen3.8 正式版与开源节奏：开发者社区披露 Qwen3.8 参数达 2.4T、即将开源，是其巩固开源生态领导地位的关键节点
  • Token Plan 价格战：个人版上线、团队版降价、夜间 1 折错峰，明显在以低价换开发者份额，挤压中小模型 API 厂商
  • 云产品全面 Agent 化：建站/运维/分析/客服全部改为 Agent 形态，是传统云厂商中产品改造最激进的之一
