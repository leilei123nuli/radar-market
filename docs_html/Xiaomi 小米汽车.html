Xiaomi 小米汽车

一、公司概况

主营业务与产品服务

小米汽车（小米汽车科技有限公司）是小米集团（1810.HK）旗下的智能电动汽车业务，2021 年立项，自建小米汽车工厂生产。当前产品线覆盖纯电轿车（SU7 系列）、纯电 SUV（YU7 系列）和增程 SUV（N 系列）三条线，并以智能座舱、辅助驾驶和小米"人车家"生态协同为核心卖点。集团层面，小米是以智能手机和 IoT 平台为核心的消费电子与智能制造公司，汽车是其最新增长曲线（2026 Q2 业绩已于 2026-08-18 发布）。

整体战略方向

  • "人车家全生态"：汽车作为小米生态的第三极，与手机、AIoT 设备互联，靠生态和流量转化获客
  • 爆品策略：以 SU7/YU7 单品爆款打规模，再向增程大 SUV（N 系列）扩品类，覆盖家庭市场
  • 技术自研：电子电气架构、超级电机、高压平台、超级大压铸等底层技术全部自建叙事，增程线以"小米昆仑技术架构"为载体
  • 制造自控：自建小米汽车工厂，超级大压铸等工艺内化，垂直整合控成本

二、产品分类

纯电轿车

  • SU7：首款量产车，中大型纯电轿车，主打设计、驾控与安全（"新一代驾驶者之车"）
  • SU7 Ultra：SU7 高性能旗舰版本

纯电 SUV

  • YU7 / YU7 GT：中大型纯电 SUV（23.35 万起），定位"适合长途旅行的跑车级 SUV"，主打高性能、豪华舒适与长续航

增程 SUV（小米昆仑技术架构）

  • N90 Max / N90 Max 探索版：大七座旗舰增程 SUV
  • N70：中大型五座增程 SUV

软件与生态产品

  • 小米汽车 App：配置定购、车辆控制、最新资讯、车友社区一体化入口
  • 智能座舱：与 HyperOS 生态协同的车载系统
  • 辅助驾驶：自研辅助驾驶系统（官网列为核心技术板块，公开细节有限）

六、总结

强势业务或产品推荐

  • YU7：当前主力走量 SUV，23.35 万起的定价直击主流市场，延续 SU7 的爆款打法
  • N 系列增程 SUV：新开辟的第二增长线，大七座 N90 Max 瞄准家庭旗舰市场，是观察小米品类扩张能力的关键
  • 小米汽车 App + 人车家生态：生态转化的核心载体，友商难以复制的流量入口

强势战略留意

  • 增程技术架构（昆仑平台/超级增程）的落地节奏：标志小米从纯电单腿走路转向双线并行
  • 自建工厂产能爬坡与超级大压铸工艺：决定交付能力与成本曲线的关键变量
  • 辅助驾驶自研进展：相对华为、小鹏声量较小，需跟踪其真实能力与大模型上车进度
