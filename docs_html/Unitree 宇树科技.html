一、公司概况

主营业务与产品服务

Unitree（宇树科技，杭州）是全球知名的民用机器人公司，专注消费级与行业级高性能通用足式/人形机器人、六轴机械臂及灵巧手的研发、生产与销售。是全球首家公开零售高性能四足机器人并率先实现行业落地的公司，四足机器人全球出货量多年领先。核心零部件（电机、减速器、控制器、激光雷达）与感知/运动控制算法全栈自研，累计申请国内外专利 200 余项（授权 180 余项），借此形成显著的成本与性能优势（G1 人形 1.35 万美元起、R1 4900 美元起，远低于同业）。

整体战略方向

  • 全栈自研 + 全产业链整合：从关节电机、减速器到 LiDAR 全部自制，以成本碾压推动足式/人形机器人规模化
  • ToB + ToC 双轮：四足机器人深耕消费/教育与行业（电力巡检、消防救援等），人形机器人以低价硬件快速铺开开发者生态（EDU 版本 + 二次开发）
  • 押注具身智能大模型：自研 UnifoLM 系列模型并采取开源策略（UnifoLM-WLA-1.0 完全开源），同时开放真实世界遥操作数据集（UnifoLM-WBT-Dataset），抢占具身数据与模型生态位
  • "机器人制造机器人"：UnifoLM-X1-0 已部署于自有工厂试点机器人组装机器人，指向制造降本闭环
  • 高曝光品牌建设：连续登陆央视春晚（2021/2025/2026）、冬奥会开幕式、Super Bowl、亚运会等，创始人王兴兴登上《时代》杂志封面（2026-08）

二、产品分类

人形机器人（Human）

  • H2 / H2 EDU：新一代全尺寸人形（180cm/约 70kg，31 自由度，360N·m 关节扭矩，2070 TOPS 算力），售价 2.99 万美元起；另有 H2 Plus（全栈自研制造）
  • R1：超轻量人形（≤123cm/约 29kg，20-26 自由度），集成多模态大模型语音交互，4900 美元起，主打极致低价普及
  • G1 / G1 EDU：主力开发者人形（132cm/约 35kg，23-43 自由度，可选 Dex3-1 三指灵巧手），1.35 万美元起，二次开发生态最成熟
  • H1 / H1-2：首款通用人形，曾创 3.3m/s 行走世界纪录；2026-04 奔跑速度突破 10m/s 再刷纪录
  • 应用形态变体（Application Plan）：H2-D、R1-A / R1-A-D、G1-D、G1-Comp（竞技）、G1-Boxing（搏击）等场景化版本
  • GD01：全球首款量产可骑乘机甲（约 500kg，双足/四足形态切换，2026-05 发布）

四足机器人 —— 消费/教育（Robot - Consumer/Education）

  • As2：小型高性能新平台（约 20kg，峰值扭矩约 95N·m，ISS 3.0 跟随，IP54），分 AIR / PRO / X / EDU，2026-02 发布
  • Go2：消费级主力机器狗（约 15kg，标配自研 4D LiDAR L2，ISS 2.0 侧跟随），1600 美元起，分 AIR / PRO / X / EDU
  • Go1、A1：上一代消费级四足产品

四足机器人 —— 行业级（Robot - Industry）

  • A2 / A2-W：行业级平台（含轮足版 A2-W）
  • B2 / B2-W：旗舰行业四足（约 60kg，360N·m 扭矩，站立负载 ≥120kg，空载续航 >5h/20km，IP67，可选轮足形态与自主充电）
  • B1、AlienGo：上一代行业四足产品

灵巧手与机械臂

  • Dexterous Hand 灵巧手系列：Dex5-S、Dex2/5、Dex1-1、Dex5-1、Dex3-1（三指，可配触觉传感器阵列）
  • Robotic Arms：六轴机械臂产品线（公开信息有限，官网未列具体型号细节）

感知与核心零部件

  • 4D LiDAR：自研 L1 / L2 超广角 4D 激光雷达（360°×96°），标配于 Go2 等机型并单独销售
  • Components：关节电机（如 M107）、减速器等核心部件，支撑全栈自研与对外供应

技术支持与文档服务

生态与赛事

  • UniBot World Challenge：官方机器人赛事
  • 央视春晚等表演合作与媒体曝光（2026 马年春晚 24 台 G1 + 1 台 H2 完成全球首次人形机器人全自主集群武术表演《武 Bot》）

四、解决方案分类

行业巡检方案

  • 电力智能巡检方案：四足机器人面向电力系统建设、运维中的危险、紧急、重复性任务
  • 工业巡检方案：红外扫描 + 3D 建图的环境感知巡检

应急救援方案

  • 消防救援方案：全地形（长楼梯、碎石堆、陡坡）进入能力，面向危险场景作业
  • 农业、勘测勘探、公共救援等足式机器人行业落地场景

具身智能模型方案（UnifoLM 体系）

  • UnifoLM-X1-0：具身智能模型（2026-02 发布），已部署自有工厂试点"机器人制造机器人"
  • UnifoLM-WLA-1.0：完全开源的通用人形机器人基座模型（2026-09 发布，约 6B，基于约 2500 小时真机数据，单模型统筹 64 项桌面/全身移动操作任务，多项开源评测 SOTA）
  • UnifoLM-X2-1.0：实现人形机器人全自主搏击（2026-09）
  • WVLA 2.0：抗强干扰的整理场景模型（2026-05）
  • UnifoLM-WBT-Dataset：开源真实世界全身遥操作数据集，滚动更新

六、总结

强势业务或产品推荐

  • 四足机器人（Go2/B2/As2）：全球出货第一的基本盘，消费级 Go2（1600 美元起）与行业级 B2 覆盖两端，值得持续跟踪其行业落地节奏
  • G1 + EDU 开发者生态：1.35 万美元的人形价格锚点 + 成熟二次开发体系，是全球高校/实验室人形研究的事实标准平台
  • UnifoLM 开源模型线：WLA-1.0 开源 + 真机数据集开放，是其从硬件公司转向"硬件 + 模型"双轮的关键看点

强势战略留意

  • 成本碾压策略的持续性：核心部件全自研带来的价格优势能否在人形放量期继续维持
  • "机器人制造机器人"（UnifoLM-X1-0 进厂）：若跑通将重构自身制造成本曲线
  • 开源模型 + 数据集生态：与特斯拉 Optimus、Figure 等闭源路线形成路线对赌，关注开发者采用率
  • 消费级人形 R1（4900 美元）的市场教育效果与安全问题（官网多次警示人形机器人使用风险）
