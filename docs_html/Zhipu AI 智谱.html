Zhipu AI 智谱

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：1. AI / 模型 / AI 平台 | 地区：国内 | 类型：新型 | 成立：2019 护城河：GLM 系列，清华系背景，B/G 端落地多

一、公司概况

主营业务与产品服务

智谱（北京智谱华章科技股份有限公司）是国内大模型第一梯队公司，清华系背景，业务呈"模型 → 平台 → 应用"三层结构：底层为 GLM 系列基础模型（当前旗舰 GLM-5.3，支持 1M 上下文，主打复杂软件工程与长程 Agent 任务），中层为 MaaS 开放平台（国内 bigmodel.cn、国际 z.ai，提供全模态模型 API），上层为消费级与开发者产品（Z.ai / 智谱清言、AutoGLM 智能体、GLM Coding Plan 编程订阅等）。同时坚持开源权重路线，GLM 旗舰模型发布即开源。

整体战略方向

  • 使命口号"Inspiring AGI to Benefit Humanity"，官方定位"不止模型，构建可信智能"
  • 主线押注 Coding 与 Agentic Engineering：旗舰模型以复杂软件工程、终端操作、长程 Agent 任务为核心卖点，并以 GLM Coding Plan 订阅深度适配主流编程工具
  • 开源 + 极致低价抢开发者生态：GLM-5.3-Flash 定价为旗舰的 1/10（限时折扣 1/20），对标国际前沿模型价格约 1/40
  • 国产算力自主可控：已在国产芯片集群上大规模承载 GLM 推理流量（自研推理引擎基于 SGLang，EPD 分离式架构），宣称单 token 成本与主流 NVIDIA GPU 相当
  • B/G 端落地：以 MaaS + 行业/城市合作的商业生态模式推进政企市场

二、产品分类

模型产品（GLM 旗舰家族）

  • GLM-5.3：旗舰模型，1M 上下文 / 128K 输出，编程与 Agent 能力对标国际前沿，并涌现网络安全能力
  • GLM-5.3-Flash / GLM-5.3-FlashX：原生多模态基座（320B 总参 / 18B 激活，线性注意力 + 稀疏注意力混合架构），FlashX 推理速度达 200 tokens/s
  • GLM-5.2：上一代旗舰，支撑复杂长程任务，开源
  • GLM-5V-Turbo：多模态 Coding 模型，原生融合视觉与文本，针对视觉编程与 Agent 任务优化

多模态与专用模型

  • GLM-Image：旗舰图像生成模型，文字渲染开源 SOTA
  • CogVideoX-3：旗舰视频生成模型，支持首尾帧生成
  • GLM-OCR：轻量文档解析模型（PDF 最大 100 页）
  • GLM-ASR-2512 / GLM-TTS：语音识别与超拟人语音合成
  • Embedding-3 / Embedding-2、Rerank：向量检索与重排序
  • CodeGeeX-4：代码补全模型

消费级与智能体产品

  • Z.ai（chat.z.ai）：面向国际的 Agent 对话产品，可直接生成文档/PPT/网页等成品
  • 智谱清言：国内 C 端 App / 网页版（chatglm.cn）
  • AutoGLM：手机/电脑操作智能体，整合进 GLM-OS 概念体系
  • ZCode：编程工具，原生支持 GLM Coding Plan 接入
  • 精选智能体应用：通用翻译、GLM PPT/海报等数十个应用级 API

三、服务分类

MaaS 平台服务

  • BigModel 开放平台（bigmodel.cn）：国内全模态模型 API 服务，含模型调用、模型微调、知识库、AI 搜索工具、MCP
  • z.ai 开放平台（api.z.ai）：国际站，提供 OpenAI/Anthropic 兼容接口与官方 SDK

订阅服务

  • GLM Coding Plan：编程订阅套餐（个人版/团队版），积分制配额，适配 Claude Code、Cline、OpenCode 等主流编程工具
  • 龙虾套餐：官网提及的模型接入套餐（公开信息有限，具体档位未详）

全流程开发套件

  • 模型微调（语言/多模态，官方称低至十分钟完成）
  • AI 搜索工具（集成多家搜索引擎，为大模型优化）
  • 智能体市场与一键接入生产环境的 API

四、解决方案分类

企业/行业解决方案

  • 企业级 MaaS 定制：全流程开发套件保障企业级 AI 应用落地
  • 商业生态合作：与行业合作伙伴及各城市共建大模型应用（B/G 端为主要落地方向）
  • 金融、法律、Office 文档等专业工作流：GLM-5.3-Flash 官方主打场景（金融研究/研报生成、合同审查批注、PPTX/PDF/DOCX/XLSX 成品交付）

国产算力解决方案

  • 国产芯片集群推理：自研高带宽互联 + 基于 SGLang 的专用推理引擎 + EPD 分离式架构，端到端性能较基线提升 3 倍

六、总结

强势业务或产品推荐

  • GLM-5.3 + GLM Coding Plan：Coding/Agent 能力进入全球前沿区间（官方称 Flash 版与 Claude Opus 4.8 得分持平），订阅制编程套餐是其开发者生态粘性最强的一环
  • 开源 + 低价模型策略：GLM-5.3-Flash 以约 1/40 对标价提供前沿级智能，是抢全球开发者份额的利器
  • B/G 端 MaaS 落地：清华系背景 + 政企/城市生态合作，国内大模型 To B/To G 市场卡位深

强势战略留意

  • Coding → Agentic Engineering 主线：模型发布节奏与产品（ZCode、Coding Plan）全部围绕编程与长程任务，与 OpenAI/Anthropic 正面竞争同一预算
  • 国产芯片推理闭环：若"单 token 成本与 NVIDIA GPU 相当"可持续，将显著改变其成本曲线与供应链安全
  • GLM Coding Plan 配额制与调价动作：积分制、错峰半价等设计反映算力供需紧张，是观察其商业化质量的窗口
  • 国际化双线（z.ai / bigmodel.cn）：同一模型家族双站分发，关注海外开发者采用度
