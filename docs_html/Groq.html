一、公司概况

主营业务与产品服务

Groq 是专注 AI 推理（inference）的芯片与云计算公司，2016 年成立之初即自研 LPU（Language Processing Unit）推理芯片，现已转型为"面向快速推理的 neocloud"：底层是 LPU 硬件（单机架 256 颗 LPU、FP8 算力 315 PFLOPS、单用户可达 1,000 tokens/秒），向上是 GroqCloud 推理云平台（托管主流开源模型并提供 API），并提供 GroqRack 本地部署形态。目前已在全球四大洲运营 13 个数据中心，并持续建设数百兆瓦级算力。

整体战略方向

  • 定位为推理而生："训练创造可能，推理创造价值"，不做训练芯片，全部资源押注推理侧瓶颈
  • 从芯片公司升级为 AI 推理云（neocloud）：平台分层为 GroqMetal（裸金属基础设施）→ GroqCore（推理栈）→ GroqAssured（企业管控）
  • 与 NVIDIA 深度绑定：2025-12 达成非独占推理技术授权协议，2026-08 成为 NVIDIA Cloud Partner，新一代 NVIDIA Groq 3 LPX 机架与 NVIDIA Vera Rubin NVL72 协同交付低延迟大上下文推理
  • 全球化算力扩张：沙特（Aramco/HUMAIN，2025-02 宣布 15 亿美元扩建）、芬兰赫尔辛基（欧洲）、澳大利亚悉尼（亚太）、加拿大（Bell AI Network 独家推理供应商）
  • 资本动作频繁：官方博客披露 2026-06 完成 6.5 亿美元融资、2026-08 完成 3.5 亿美元 Series A，用于扩建推理云

二、产品分类

芯片与硬件

  • LPU（Language Processing Unit）：自研确定性架构推理芯片，主打低延迟、高吞吐，单机架 128 GB 片上 SRAM、40 PB/s SRAM 带宽
  • NVIDIA Groq 3 LPX：新一代机架级产品，256 颗 LPU 与 NVIDIA Vera Rubin 平台互联（2026-08 宣布首批上市）
  • GroqRack：本地/私有化部署形态，面向受监管行业与物理隔离（air-gapped）环境，可与云端无缝切换

云平台产品

  • GroqCloud：开发者推理云平台，托管 Llama、GPT-OSS、Whisper 等模型，支持 LLM、STT、TTS、图像理解等模态
  • GroqPlatform 分层：GroqMetal（专属裸金属基础设施）、GroqCore（托管推理栈）、GroqAssured（企业级治理、审计与管控）

托管模型服务（GroqCloud 上）

  • Llama 3.1 8B / 3.3 70B Enterprise：Meta 开源模型的高速推理托管
  • GPT-OSS 120B / 20B：OpenAI 开放权重模型，内置浏览器搜索与代码执行能力
  • Whisper large-v3 / large-v3-turbo：语音转文字
  • Orpheus TTS（Canopy Labs）：文字转语音
  • Llama Prompt Guard 2：提示安全护栏模型

三、服务分类

订阅/套餐服务

  • Free：免费入门档，含社区支持与可选零数据保留
  • Developer：按量付费，更高 token 限额、Flex 服务等级、批处理、Prompt Caching、支出限额
  • Enterprise：定制模型、区域端点选择、Performance 服务等级、专属支持、LoRA 微调

API 推理服务

  • 文本生成、语音转文字（STT）、文字转语音（TTS）、OCR 与图像识别、推理（Reasoning）、内容审核、结构化输出
  • 工具调用生态：代码执行、浏览器搜索（GPT-OSS 模型）、MCP 连接器、本地工具调用
  • 服务等级：Performance / Flex / Batch（批处理）三档，兼容 OpenAI API 与 Responses API

部署服务

  • 公有云（GroqCloud 共享实例）、私有云、co-cloud 实例三种形态
  • GroqRack 本地部署，面向合规与隔离场景

六、总结

强势业务或产品推荐

  • GroqCloud 推理 API：速度是最锋利的卖点（GPT-OSS 120B 约 500 tps、20B 约 1,000 tps），开发者规模已破百万（2025-03），是开源模型推理的首选之一
  • LPU + LPX 硬件线：确定性架构在延迟敏感场景（语音 Agent、实时支付）有差异化优势，GroqRack 打开受监管行业市场

强势战略留意

  • 与 NVIDIA 的关系演变：从潜在对手变成授权伙伴 + Cloud Partner + 联合机架（LPX × Vera Rubin），既降低生存风险也可能压缩独立性，值得持续跟踪
  • 推理云重资产扩张（数百兆瓦、13 数据中心、沙特 15 亿美元）的资本开支与利用率匹配度
  • 主权 AI 订单（沙特 HUMAIN、Bell、DOE）是其区别于其他推理云的关键收入结构
