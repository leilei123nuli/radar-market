一、公司概况

主营业务与产品服务

Mobileye（Nasdaq: MBLY，总部耶路撒冷）是 ADAS 与自动驾驶系统龙头：底层是自研 EyeQ 系列车规 SoC（EyeQ4/5/6），向上提供从基础辅助驾驶到无人驾驶的六级产品谱系（Base ADAS → Cloud-Enhanced ADAS → Surround ADAS → SuperVision → Chauffeur → Drive），核心技术包括 REM™ 众包地图、RSS™ 责任敏感安全模型、True Redundancy™ 传感冗余。截至 2025 年，全球超过 2.3 亿辆车搭载 EyeQ 芯片。2022 年从英特尔分拆独立上市，英特尔仍持有多数股权。2026Q2 营收 5.08 亿美元，同比基本持平。

整体战略方向

  • 基本盘：以 EyeQ + 软件方案守住 ADAS 存量份额，借法规（各国 ADAS 强制配置）放量
  • 上探高阶：SuperVision（hands-off/eyes-on）作为通往消费级自动驾驶的"桥梁"，Chauffeur（eyes-off）跟进
  • 无人驾驶：Mobileye Drive 面向 robotaxi/接驳/货运；2026-06 宣布建立垂直整合的 robotaxi 业务，从系统供应商延伸到运营侧
  • 数据闭环：REM 众包地图持续变现（2026-07 起为 Stellantis 部分车型提供 Cloud-Enhanced ADAS）；舱内感知 DMS 拿下美国头部车企量产项目（2026-03）
  • 外延拓展：以"Physical AI"叙事把车端 AI 经验延伸至人形机器人（Mentee）
  • 领导层变动：2026-07 宣布创始人 Amnon Shashua 拟卸任 CEO，转任董事长（继任者遴选进行中）

二、产品分类

芯片（SoC）

  • EyeQ4 / EyeQ5（Mid/High）：存量主力车规视觉处理芯片，支撑 Base ADAS 与 SuperVision
  • EyeQ6 Lite / EyeQ6 High：最新一代 SoC，EyeQ6H 为公司迄今最强芯片，支撑 Surround ADAS / SuperVision / Chauffeur / Drive

驾驶辅助与自动驾驶系统（由低到高六级）

  • Mobileye Base ADAS：单前视摄像头 + EyeQ，满足法规合规与基础安全功能，已装车数百万辆
  • Mobileye Cloud-Enhanced ADAS™：基于 REM 众包数据提供厘米级定位与持续更新的路况信息（2027 起搭载部分 Stellantis 车型）
  • Mobileye Surround ADAS™：环视摄像头 + 雷达多传感器融合，EyeQ6H 驱动，hands-on/off
  • Mobileye SuperVision™：最先进的量产驾驶辅助系统，360° 视觉 + REM + RSS，可脱手（hands-off/eyes-on）
  • Mobileye Chauffeur™：消费级 hands-off/eyes-off 方案，增加环视成像雷达与前向激光雷达
  • Mobileye Drive™：端到端无人驾驶系统（无驾驶员），面向 robotaxi、拼车、公共交通与货物运输

机器人

  • Mentee：AI-first 人形机器人，垂直整合 AI、传感、计算、控制与机械设计，处于早期拓展方向

三、服务分类

数据与地图服务

  • REM™（Road Experience Management）：众包地图服务，向车企输出持续更新的道路场景数据与定位能力

软件/算法授权

  • EyeQ 芯片捆绑感知算法与驾驶策略软件的整体方案授权（软硬一体出货模式）

出行运营（新拓展）

  • 垂直整合 robotaxi 业务（2026-06 宣布）：在既有的车企/出行伙伴供货模式之外，直接参与运营

四、解决方案分类

车企量产方案

  • ADAS 合规与安全方案：Base/Cloud-Enhanced/Surround ADAS，对接各国 ADAS 法规要求
  • 高阶智驾方案：SuperVision（量产中，如极氪等）、Chauffeur（面向消费级 eyes-off）
  • 舱内感知：DMS（驾驶员监测）量产项目，已获美国头部车企定点

无人驾驶出行方案

  • Mobileye Drive 供给车企与运输运营商，覆盖 robotaxi、ride-pooling、公交与配送
  • 自营/垂直整合 robotaxi 业务（规划中，与伙伴项目并行）

六、总结

强势业务或产品推荐

  • EyeQ + Base/Cloud-Enhanced ADAS：2.3 亿辆装机的存量基本盘，法规驱动下仍是现金流核心
  • SuperVision：量产 hands-off 系统的稀缺标的，是观察其能否上探高阶智驾的关键产品

强势战略留意

  • 垂直整合 robotaxi 业务：从供应商转运营，资本与执行风险并存，与 Waymo/Zoox 正面竞争
  • 创始人交棒：Shashua 卸任 CEO 后的技术路线连续性
  • Physical AI / 人形机器人（Mentee）叙事：目前体量极小，留意是否获得实质投入
  • 增长压力：2026Q2 营收同比持平，中国智驾价格战与车企自研（如特斯拉/华为）对其份额的挤压值得持续跟踪
