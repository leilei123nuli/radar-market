ASML

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：2. 芯片 / AI 基础设施 | 地区：国外 | 类型：龙头 | 成立：1984 护城河：EUV 光刻机唯一供应商，制造环节终极卡点

一、公司概况

主营业务与产品服务

ASML（总部荷兰 Veldhoven，员工超 44,000 人，全球 60+ 据点）是半导体光刻设备绝对龙头，为芯片制造商提供量产微芯片所需的硬件、软件与服务。核心壁垒：全球唯一 EUV（极紫外，13.5 nm 波长）光刻系统供应商，先进制程（7 nm 及以下）绕不开的终极卡点。产品体系为"整体光刻（Holistic Lithography）"：光刻机（EUV/DUV）+ 计量检测（YieldStar / HMI e-beam）+ 计算光刻软件三层整合。2025 财年净销售额 €327 亿、净利润 €96 亿、毛利率 52.8%；2026 年指引净销售额 €340–390 亿。

整体战略方向

  • 吃定 AI 驱动的半导体结构性需求：先进 Logic（2 nm 及以下）与先进 DRAM 节点的 EUV/High-NA 放量
  • 技术路线：EXE（High NA，0.55 NA）平台 2025–2026 年进入量产，支撑下一个十年的几何微缩；NXE（0.33 NA）与 DUV 长期并行
  • 客户深度绑定：与 Intel Foundry 合作加速 High-NA 产业就绪，与三星电子扩大下一代制造战略合作（2026-09）
  • 产能扩张：2026-09 动工埃因霍温新园区，强化 Brainport 地区布局
  • 资本配置：均衡策略，超额现金通过分红与回购返还股东

二、产品分类

EUV 光刻系统（ASML 独有）

  • TWINSCAN EXE 系列：最新一代 High-NA（0.55 NA）EUV 平台，分辨率 8 nm，面向 2 nm Logic 节点及同密度 Memory 节点，2025–2026 年支持量产
  • TWINSCAN NXE 系列：0.33 NA EUV 主力机型，分辨率 13 nm，用于 7/5/3 nm 节点复杂底层图形量产；最新型号 NXE:3800E（NXE:3600D 继任者），与 EXE 共用晶圆台/光源模块，面向 2 nm Logic 与领先 DRAM 的高性价比量产

DUV 光刻系统

  • 浸没式（TWINSCAN NXT 系列，ArF immersion）：行业主力机型，日产能超 6,000 片晶圆，服务最先进 Logic/Memory 量产；可通过 System Node Enhancement Package 升级至最新技术
  • 干式（TWINSCAN XT 系列，ArF / KrF / i-line）：覆盖 200 mm 与 300 mm 晶圆，成本更低，针对 3D NAND 高地形堆叠与晶圆翘曲有专门选项；2016 年起提供 200 mm 版本服务 IoT/汽车/工业市场

计量与检测系统

  • YieldStar 光学计量：快速高精度量测晶圆图形质量，型号含 YieldStar 1385（器件内 overlay、刻蚀后监控）、YieldStar 1390（独立式高通量刻蚀后监控）、YieldStar 500（刻蚀前 overlay）
  • HMI 电子束检测/计量：HMI eScan 1100（第一代多电子束量产在线缺陷检测）、HMI eScan 600（单系统检测多种缺陷类型）

计算光刻（Computational Lithography）

  • 基于制造工艺算法模型的掩模优化软件：通过预畸变补偿光刻中的衍射与物理化学效应，是先进节点量产的必需品；正向光学计量、电子束检测与机器学习应用扩展

翻新系统（Refurbished）

  • PAS 5500 / TWINSCAN 翻新机：历史上售出的光刻机几乎全在役，官方翻新"经典"机型赋予二次生命，服务成熟节点与二手设备市场

三、服务分类

客户支持

  • 约 10,000 名客户支持员工（服务工程师 + 应用专家）驻客户晶圆厂，保障设备运转
  • CustomerNet / SupplierNet：客户与供应商在线协作门户

设备升级服务

  • System Node Enhancement Package：NXT 浸没式系统的性能升级包，旧机可升级至最新平台技术，延长设备生命周期

软件服务

  • 图形工艺控制（patterning control）软件：与计量/检测/光刻硬件联动的建模与修正套件

四、解决方案分类

整体光刻方案（Holistic Lithography）

  • 把计算光刻建模、光学计量（YieldStar）、电子束检测（HMI）与光刻机整合为一体，覆盖从研发到量产的图形工艺全链条，帮助客户以最优成本快速达成最严苛图形要求

先进节点量产方案

  • EUV（NXE/EXE）+ 计算光刻 + 计量检测组合，支撑 2 nm 及以下 Logic 与先进 DRAM/High-NA 过渡；与 Intel Foundry、三星等头部客户联合开发产业就绪方案

成熟节点与特色工艺方案

  • DUV 干式/浸没式 + 翻新机组合，面向 3D NAND、功率器件、IoT、汽车电子等成本敏感场景

生态绑定方案

  • 与头部晶圆厂的战略协作（联合研发、High-NA 导入、长期供货协议），客户预付与深度技术耦合形成转换成本

六、总结

强势业务或产品推荐

  • EUV（NXE/EXE 系列）：全球唯一供应，无替代品，是 AI 芯片军备竞赛的"卖铲人"，定价权与毛利率（52.8%）顶级
  • DUV 浸没式（NXT）：成熟现金牛，几乎所有晶圆厂的基础产能依赖
  • 装机基数服务 + 升级包：巨大存量设备带来高粘性、类年金的售后收入

强势战略留意

  • High-NA EXE 放量节奏：2025–2026 年量产导入是下一个十年的增长引擎，Intel/三星/台积电导入进度直接决定订单结构
  • 地缘出口管制：对华 EUV 禁售、DUV 受限是最大政策变量，影响中国区收入占比与成熟节点竞争格局
  • 2026 指引 €340–390 亿：AI 需求兑现度与存储客户资本开支是关键观察点（Q3 2026 财报 2026-10-14 发布）
  • 产能布局：埃因霍温新园区动工，应对长期订单积压的产能扩张值得跟踪
