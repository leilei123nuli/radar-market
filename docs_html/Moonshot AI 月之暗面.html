Moonshot AI 月之暗面

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：1. AI / 模型 / AI 平台 | 地区：国内 | 类型：新型 | 成立：2023 护城河：Kimi 长文本，C 端产品化领先

一、公司概况

主营业务与产品服务

月之暗面（Moonshot AI，2023 年春成立于北京）是国内大模型头部创业公司，业务分三层：底层是自研 Kimi K 系列大模型（当前旗舰为 Kimi K3，2026-07-16 发布，2.8 万亿参数、原生多模态、百万 token 上下文，主打长程编程、知识工作与深度推理）；中间层是 Kimi API 开放平台（模型即服务，兼容 OpenAI 与 Anthropic API 格式）；上层是 C 端产品 Kimi 智能助手（App / 网页 / 桌面端 / 插件）。K2 系列模型走开源路线，K3 官网称其为"向更开放、更强大的智能迈进一步"。

整体战略方向

  • 使命导向 AGI，官方表述为"寻求将能源转化为智能的最优解"
  • 开源换生态：Kimi K2 系列（K2 / K2 Thinking / K2.5 / K2.6）持续开源，在全球开发者社区建立影响力，定位接近"中国开源模型旗手"
  • Agent 与编程差异化：模型与产品均围绕长程编程、Agent 任务、知识工作打造（K2.7 Code 编程模型、API 兼容 Claude Code 等工具接入）
  • C 端商业化：Kimi 助手付费 + 效率型功能（深度研究、一键建站、智能制表、PPT 自主编辑）
  • 全球化：据公开报道，2026 年初起海外收入增长迅速并已反超国内；据公开报道公司 2026 年完成 E 轮融资（超 20 亿美元）、投后估值突破 200 亿美元，并有港股 IPO 筹备传闻（非官方信息，仅作留意）

二、产品分类

消费级产品

  • Kimi 智能助手：核心 C 端入口，覆盖 App、网页（kimi.com）、macOS/Windows 桌面端与浏览器插件，支持对话与 Agent 任务
  • 深度研究：基于大模型能力的多步骤检索与研究型任务
  • 一键建站 / 智能制表 / PPT 自主编辑：面向知识工作的一站式办公生成能力
  • Kimi Doodle：节日/话题彩蛋式运营功能，强化 C 端品牌心智

模型产品

  • Kimi K3 系列：旗舰模型（2026-07 发布），2.8 万亿参数、原生多模态、1M token 上下文，支持 reasoning_effort 推理强度分档（low / high / max）
  • Kimi K2.7 Code：编程专用模型，256K 上下文，支持文本/图片/视频输入与思考模式，另有高速版 kimi-k2.7-code-highspeed
  • Kimi K2.6：通用模型，256K 上下文，多模态输入，思考/非思考双模式，适合通用对话、Agent 任务与复杂推理
  • Kimi K2 开源系列：K2、K2 Thinking（2025-11 开源，强化 Agent 与推理）、K2.5、K2.6 等，面向全球开源社区

开发者/企业产品

  • Kimi API 开放平台：模型调用平台，兼容 OpenAI（Chat Completions / Responses API）与 Anthropic（Messages API）格式
  • 官方工具集：Web Search、Memory、Excel 分析、Code-Runner、QuickJs、FetchURL、Rethink、单位转换等即插即用工具
  • 开发工作台 / Kimi Playground：免写代码测试提示词与工具调用

三、服务分类

API 平台服务

  • 模型推理按 token 计费：K3 / K2 系列分档定价，输入输出分别计费
  • Context Caching 上下文缓存：重复前缀自动缓存（5min / 1h 两档 TTL），命中低价计费，官方称最高可省约 90% 调用成本
  • 文件接口：文件内容抽取/存储限时免费（内容作为输入仍按量计费）
  • 企业级 API：2024-08 起正式提供企业级 API 服务

订阅服务

  • Kimi C 端会员订阅：据公开报道为收入主力之一（ARR 2026 年快速增长），但官网未明示订阅分层细节，公开信息有限

企业服务

  • Kimi 企业服务：官网设有独立入口，面向企业客户的服务方案，具体形态公开信息有限

四、解决方案分类

企业解决方案

  • Kimi 企业服务 + 企业级 API：面向企业的模型能力与部署支持（公开信息有限，官网仅列入口）
  • 开放平台"与创新企业同行"计划：资源对接类企业合作入口

开发者生态方案

  • 开源模型权重 + 兼容主流 API 格式，支持 Anthropic SDK、Claude Code 等第三方工具直接接入
  • 官方工具集覆盖联网搜索、代码执行、文件分析等 Agent 常见场景

六、总结

强势业务或产品推荐

  • Kimi K 系列模型：K3 旗舰 + K2 开源线组合，编程与 Agent 能力是其全球最鲜明的标签，值得持续跟踪迭代节奏
  • Kimi C 端助手：国内 C 端 AI 助手产品化第一梯队，办公生成类功能（深度研究/建站/制表/PPT）是付费转化抓手
  • API 开放平台：OpenAI/Anthropic 双兼容 + 官方工具集，开发者迁移成本低，是承接开源口碑的变现层

强势战略留意

  • 开源策略的可持续性：K3 是否延续开源、开源与闭源商业化的边界如何划
  • 海外收入反超国内后的全球化打法，以及由此带来的地缘与合规变量
  • C 端订阅收入增速与 IPO 进程（据公开报道筹备港股），决定其从"融资驱动"转向"收入驱动"的节奏
  • 与 DeepSeek 等国内开源模型的生态位竞争：编程/Agent 心智能否守住
