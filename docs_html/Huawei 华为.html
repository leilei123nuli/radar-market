Huawei 华为

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：4. 汽车 / 智驾 | 地区：国内 | 类型：龙头 | 成立：1987 护城河：乾崑 ADS 全栈（芯片+算法+云），鸿蒙智行生态

一、公司概况

主营业务与产品服务

华为 1987 年创立于深圳，定位"全球领先的 ICT（信息与通信）基础设施和智能终端提供商"。业务横跨六大板块：运营商业务（无线/固定网络、云核心网）、企业业务（企业网络、存储、计算）、消费者业务（手机/穿戴/PC 等终端 + HarmonyOS）、华为云、智能汽车解决方案（华为乾崑）、数字能源。在本雷达中，华为以"汽车/智驾"赛道（乾崑 ADS 全栈 + 鸿蒙智行）收录；其昇腾算力与华为云分别作为独立条目"Huawei Ascend 华为昇腾"（赛道2）、"Huawei Cloud 华为云"（赛道3）跟踪。华为未上市，无公开财报投资者关系页面。

整体战略方向

  • 2023 年提出"全面智能化（All Intelligence）"战略，2025 年起深化为"跃升行业智能化"，强调创新领先与全面开源开放
  • 算力底座自主化：鲲鹏（通用计算）+ 昇腾（AI 计算）双生态，2025 年开发者分别达 380 万 / 400 万，与 9,800+ 伙伴孵化 26,000+ 行业解决方案；2026-09 开源 openPangu-2.0 预训练与后训练代码
  • 终端生态鸿蒙化：HarmonyOS 5/6 终端设备超 3,600 万台，注册开发者超 1,000 万，彻底脱离安卓生态独立演进
  • 汽车"不造车、帮车企造好车"：以乾崑智能汽车解决方案（智驾+座舱+车控+车云）做增量部件供应商，叠加鸿蒙智行智选车模式
  • 联接主业持续演进：5G-A 商用（全球用户超 6,000 万），2026-09 发布阿尔法6000系列全天面解决方案与 AgenticCore 下一代核心网

二、产品分类

智能终端（消费者业务）

  • HUAWEI Mate 系列：旗舰手机（当前主力 Mate 90 系列，含 Mate 90 RS 非凡大师）
  • HUAWEI Pura 系列：影像旗舰（Pura 90 系列、Pura X 阔折叠）
  • HUAWEI Mate XT 非凡大师：三折叠形态产品线
  • HUAWEI WATCH / FreeBuds：智能穿戴与音频（WATCH 6/GT 7/Ultimate 2、FreeBuds Neo 等）
  • HUAWEI MateBook / MatePad / 智慧屏：PC、平板与大屏，全场景协同
  • HarmonyOS：自研操作系统（当前至 HarmonyOS 7），全屋智能与路由等家居产品

智能汽车部件（华为乾崑）

  • 乾崑智驾 HUAWEI ADS：高阶智能驾驶系统，ADS 4 为业界首个面向高速 L3 商用解决方案（官网已出现 ADS 5 搭载车型预售信息）
  • 鸿蒙座舱 HarmonySpace：智能座舱系统
  • 乾崑车控 / XMC 数字底盘引擎：车辆运动控制与数字底盘
  • 乾崑车载光 / 乾崑车云：车载光显示与车联网云服务

ICT 基础设施（运营商 + 企业业务）

  • 无线网络：5G/5G-A 基站、SingleRAN、阿尔法6000系列全天面方案
  • 光与固定网络：OptiXaccess 光接入、OptiXtrans 光传送、千兆家宽
  • 数据存储：OceanStor Dorado 全闪存、OceanStor Pacific 分布式存储、AI 存储
  • 计算：昇腾 AI 计算、鲲鹏通用计算（TaiShan 服务器）
  • 企业网络：园区/数据中心交换机、路由器、网络安全、智能协作（IdeaHub、CloudLink）
  • 数字能源：站点能源、数据中心能源及关键供电、智能光伏与储能

三、服务分类

企业与运营商服务

  • ICT 部署与集成服务：网络规划、建设、集成
  • ICT 运维与辅助运营：智能运维、精品网保障、移动网络数字化运营
  • 培训与认证服务：HCIA/HCIP/HCIE 等 ICT 人才认证体系
  • 软件平台与服务：核心网软件、AgenticCore、自动驾驶网络软件单元

消费者与生态服务

  • 华为商城 + 零售店体系：终端销售与售后"服务支持"
  • 华为云服务（独立条目跟踪）：盘古大模型、CloudMatrix AI 原生基础设施、华为云 Stack 混合云
  • 开发者生态服务：鸿蒙/鲲鹏/昇腾开发者计划、华为乾崑 APP（车主社区与车控服务）

六、总结

强势业务或产品推荐

  • 乾崑智驾 ADS：国内高阶智驾头部方案，ADS 4 率先打出"高速 L3 商用"，ADS 5 已随新车预售曝光；累计辅助驾驶里程超 70 亿公里，数据闭环规模领先
  • 鸿蒙智行生态：智选车模式绑定多家车企，"界"字辈品牌矩阵已成国内高端新能源重要一极
  • 昇腾 + HarmonyOS 双底座：分别在国产 AI 算力与自主 OS 两条国产替代主线上占据核心位置（昇腾另有独立条目跟踪）

强势战略留意

  • 智驾"全栈自研 + 多模式输出"（部件供应 / HI / 智选车）三条路线的资源分配与边界演变
  • L3/L4 法规落地节奏与 ADS 版本迭代（ADS 5 商用进展）——智驾赛道最直接的政策敏感点
  • 昇腾算力、盘古模型、华为云与乾崑的"芯片+算法+云"协同是否形成对手难以复制的闭环
  • 未上市 + 轮值董事长制度下的组织与资本运作动向（如引望（车 BU 主体）股权开放进展，公开信息有限，本档案未展开）
