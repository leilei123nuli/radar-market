一、公司概况

主营业务与产品服务

Cloudflare 是全球连接云（connectivity cloud）龙头：底层是覆盖 335+ 城市、距全球 95% 人口 50ms 以内的边缘网络，向上分为三层业务——应用服务（CDN/DNS/WAF/DDoS 等安全与加速）、Zero Trust / SASE（Cloudflare One）、开发者平台（Workers 无服务器计算 + R2/D1/KV 等存储 + Workers AI 边缘推理）。官网称服务 45% 的 Fortune 500、保护约 20% 的全球网站，前 50 大 GenAI 公司约 80% 跑在 Cloudflare 上。2026 Q2 营收 $696.1M（同比 +36%），年付超 $10 万大客户 4,698 家（+27%），平台开发者超 740 万（公开财报报道）。

整体战略方向

  • 从"CDN/安全厂商"升级为"connectivity cloud"：安全、连接、代码跑在同一张全球网络上，一个控制台、一份账单
  • 全力押注"agentic internet"（智能体互联网）：把 Workers 定位为 AI Agent 的首选运行环境，提供内置推理、MCP 门户安全、身份感知访问，让生产级 AI 一键部署
  • 商业模式差异化：按用量/按席位计费，免 egress 流量费（R2），"只为代码实际运行付费"，以此打传统云厂商
  • 普惠策略：持续推进"消除两层产品准入"，把 Logpush、多账号治理等企业级能力下放给所有套餐
  • 主权 AI 立场：支持各国本地开源模型 + 模型无关的安全工具，争取政府与受监管行业

二、产品分类

计算（Compute）

  • Workers：全球无服务器函数，开发者平台核心
  • Cloudflare Pages：前端站点构建与部署
  • Containers / Sandboxes：任意语言容器运行、安全代码执行环境
  • Durable Objects：有状态计算
  • Workflows：多步骤流程编排
  • Workers for Platforms：可编程平台（让客户在自己产品上开放 Workers）
  • Browser Run：托管自动化浏览器
  • Email Service：邮件收发
  • Workers Observability：Workers 原生可观测性

存储与数据（Storage）

  • R2：免 egress 费对象存储
  • D1：无服务器 SQL 数据库
  • KV / KV Instant：超快键值存储（KV Instant 为 2026 Birthday Week 发布，p99 读延迟 <2ms）
  • K2：基于 R2 的无服务器事件流（2026 Birthday Week 发布）
  • Queues：消息队列处理
  • Hyperdrive：全局数据库加速
  • Artifacts / Basin / Cache Reserve：Git 原生版本化存储、数据摄取编目查询、静态内容持久缓存

AI

  • Workers AI：全球 GPU 网络上的边缘模型推理（按用量计费，护城河核心）
  • Agents：构建有状态 AI 智能体
  • AI Gateway：AI 可观测与治理网关，2026-10 新增原生 Web Search API（合作方 Ceramic.ai、Exa、Linkup）
  • AI Search：即时检索
  • Vectorize：向量数据库
  • Clef / Clef-flash：自研开源决策模型，托管于 Workers AI，配 RL 微调平台（2026-10 发布）
  • Web3：Web3 基础设施

媒体（Media）

  • Stream：视频流媒体
  • Images：图像优化
  • RealtimeKit：实时通信

安全（Security）

  • DDoS Protection / Magic Transit：DDoS 缓解（含网络层）
  • WAF：Web 应用防火墙
  • Bot Management：恶意 Bot 拦截
  • SSL / Turnstile：证书与 CAPTCHA 替代方案
  • Rate Limiting / Client-Side Security / Network Firewall：滥用防护、浏览器供应链防护、企业 WAN 云原生防火墙

网络（Network）

  • CDN / DNS：核心加速与解析服务（1.1.1.1 公共 DNS）
  • Argo Smart Routing：智能路由加速
  • API Shield：API 安全与监控
  • Load Balancing / Waiting Room：负载均衡与流量排队
  • Spectrum：TCP/UDP 应用 DDoS 防护
  • Network Interconnect：直连/伙伴互联
  • China Network：中国区高性能方案

SASE / Zero Trust（Cloudflare One）

  • Access：零信任访问私有资源
  • Gateway / Secure Web Gateway：Web 过滤与 DNS 过滤
  • CASB：SaaS 与云姿态管理
  • Data Loss Prevention：敏感数据防泄漏
  • Email Security：AI 反钓鱼邮件安全
  • Browser Isolation：安全浏览隔离
  • Mesh：私有网络组网
  • AI Security for Apps：AI 应用安全防护

三、服务分类

应用服务订阅（按站点分层）

  • Free / Pro（$20/月）/ Business（$200/月）/ Contract（定制）：同一套 CDN+DDoS+SSL+WAF+Bot 底座，付费层级增加防护深度与服务等级

开发者平台服务（按用量计费）

  • Workers 请求/计算时长计费，"代码不运行不付费"
  • R2/D1/KV/Queues/Vectorize 等存储与数据服务按量计费，R2 免 egress
  • Workers AI 推理按用量计费

企业安全服务（按席位/套餐）

  • Cloudflare One SASE 套餐（Interna packages）：按用户席位计价，免带宽费，含 CASB、DEM 等
  • 企业级合同：网络优先级、24/7 支持、定制合同

六、总结

强势业务或产品推荐

  • Workers 开发者平台 + Workers AI：增长飞轮核心，Q2 单季新增约 200 万开发者；Agent 时代"轻量、低成本、可扩展"的运行环境卡位清晰
  • Cloudflare One（SASE/Zero Trust）：Gartner 2025 SASE 魔力象限 Visionary，Forrester Zero Trust Wave 战略分第二；对 AI 采用治理（MCP 安全、prompt DLP）的差异化切入值得跟踪
  • AI Gateway + Clef 开源决策模型：AI 流量治理层的入口级产品

强势战略留意

  • "Agentic internet"叙事正在兑现为财报数字：2026 Q2 营收 +36% 加速增长、DBNR 回升至 120%，盘后股价 +17%——验证 AI Agent 流量能否持续驱动企业预算迁移
  • Cloudflare OS（托管 Agent 工作空间）：若落地将把平台从开发者扩展到全员，打开新客群
  • 按用量计费 + 免 egress 的定价对传统云厂商的侵蚀速度
  • 主权 AI 与后量子安全投入：政府/受监管行业订单的前瞻信号
