一、公司概况

主营业务与产品服务

Google（Alphabet）AI 业务以 Google DeepMind 为研发中枢，形成"模型 → 产品 → 算力"全栈结构：底层是 Gemini 系列基础模型（当前旗舰为 Gemini 4 Argon，2026-09 发布）与自研 TPU 算力，中层是多模态生成模型家族（Veo 视频、Nano Banana 图像、Lyria 音乐、Gemini Omni、Gemini Audio），上层是消费者入口（Gemini App）、开发者平台（Google AI Studio、Antigravity）与企业级 Agent 平台（Gemini Enterprise Agent Platform）。AI 能力同时回填搜索、Android、YouTube、Google Cloud 等分发入口。

整体战略方向

  • 全栈一体化：Gemini 模型 + TPU 自研算力 + 搜索/安卓/云三大分发入口，成本控制与迭代速度自主
  • AGI 路线明确：Demis Hassabis 公开阐述以"世界模型 + 仿真"通往 AGI（Genie 3 为代表），Shane Legg 提出分级 AGI 框架
  • Agent 化：从对话转向自主智能体（Gemini Enterprise Agent Platform、agentic video understanding、Private AI Compute 提供服务器端安全记忆）
  • 科学发现为第二曲线：AlphaGenome Atlas（基因组）、WeatherNext 3（气象）、SynthID Bio（生物水印）、$40M Genesis Mission 投入
  • 具身智能布局：Gemini Robotics 2 / Robotics ER 2，定位"任意机器人的智能层"

二、产品分类

基础模型

  • Gemini 4 Argon：旗舰前沿模型（2026-09 发布），官方定位"next era of frontier intelligence"
  • Gemini 3.8 / 3.7 / 3.6 Flash 系列：轻量快速模型，含 Flash-Lite 变体
  • Gemini Live / Live Avatar：实时语音交互与 Live Avatar 形象（3.8 Live 支持 Extended Thinking）
  • Gemma / EmbeddingGemma 2：开放模型系列，EmbeddingGemma 2 为轻量多模态 embedding 模型

多模态生成模型

  • Veo：视频生成主力模型
  • Gemini Omni："create anything from anything"（以视频为起点的跨模态生成），有 Omni 1.1 Flash 开发者版
  • Nano Banana（Gemini Image）：图像生成与编辑
  • Lyria 3.5：音乐生成模型，已接入 Google Flow Music
  • Gemini Audio / 3.8 text-to-speech / 3.5 Transcribe：实时音频、TTS 与智能转写

前沿/科学模型

  • Genie 3：世界模型（world models）前沿方向
  • Gemini Robotics 2 / Robotics ER 2：机器人全身智能与多机协作、任务编排
  • AlphaGenome Atlas：人类基因组全位点变异预测图谱
  • WeatherNext 3：全球气象预测 AI，气旋预测有突破

消费者与开发者产品

  • Gemini App（gemini.google.com）：C 端核心入口（页面为 JS 应用，抓取内容有限，公开信息有限）
  • Google AI Studio：模型与工具的开发上手平台
  • Google Antigravity：AI-first 开发平台，"让任何人都成为 builder"

三、服务分类

订阅服务

  • Gemini App 免费/付费分层订阅（具体套餐档位公开抓取页面未展开，公开信息有限）

平台/开发者服务

  • Gemini API（经 Google AI Studio / Google Cloud Vertex AI 提供）：模型调用、Gemini Omni Flash 等开发者版本
  • Private AI Compute：带安全服务器端记忆的私密 AI 计算服务

安全与责任服务

  • SynthID / SynthID Bio：AI 生成内容嵌入水印识别，扩展到生物领域
  • Gemini 3.5/3.8 Flash Cyber：面向网络安全的模型变体，主打政府与企业的主动网络防御
  • 双盲 AI 评估试点（Responsibility & Safety 线）

四、解决方案分类

企业解决方案

  • Gemini Enterprise Agent Platform：企业级 Agent 的构建、扩展与治理平台
  • 政府/企业网络安全方案：Flash Cyber 系列模型 + 主动防御定位

科学/公共解决方案

  • Genesis Mission：Google 承诺 $40M 加速科学发现（2026-07）
  • 气象（WeatherNext 3）、基因组（AlphaGenome Atlas）、手语 AI 等公益/科研落地

生态与硬件协同

  • TPU 自研算力支撑内部训练/推理并对外经 Google Cloud 输出（Google Cloud 另有独立条目建档）
  • 与 Android、搜索等自有入口的模型级集成

六、总结

强势业务或产品推荐

  • Gemini 模型矩阵：旗舰 Argon + Flash 轻量梯队 + Live 实时交互，产品线最完整的厂商之一
  • Gemini Enterprise Agent Platform：Agent 治理层的卡位动作，企业市场正面战场
  • Gemma 开放模型线：在开源阵营（vs Meta Llama、Qwen）中保持存在感，值得跟踪

强势战略留意

  • 世界模型路线（Genie 3 + Demis 的 AGI 论述）：与纯 LLM 扩规模路线的差异化赌注
  • 具身智能（Gemini Robotics 2/ER 2）：定位"机器人智能层"，可能成为具身赛道的平台型玩家
  • Private AI Compute + 双盲评估：隐私与评估信任基建，回应企业采纳的核心顾虑
  • 科学发现第二曲线（Genesis Mission、AlphaGenome、WeatherNext）：AI for Science 商业化路径值得观察
  • TPU 全栈的成本曲线：与 OpenAI/Stargate 的资本开支竞赛对照看
