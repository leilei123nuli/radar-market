Microsoft Azure

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国外 | 类型：龙头 | 成立：2010 护城河：OpenAI 独家云 + 企业客户基础，AI 云增速最快

一、公司概况

主营业务与产品服务

Microsoft Azure 是微软的云计算平台，全球第二大公有云，产品线覆盖 IaaS（计算/存储/网络）、PaaS（数据库/容器/开发者工具）到 AI 平台（Microsoft Foundry，原 Azure AI Foundry 更名）的全栈云服务。当前业务重心明显向 AI 倾斜：以 Microsoft Foundry 为"AI 应用与智能体工厂"，向上承接 Copilot 体系，向下依托全球区域最多的数据中心与自研芯片基础设施，主要客户为大型企业与开发者。

整体战略方向

  • AI 云一体化：把 Azure 从通用云重塑为"智能体云"——Foundry（模型与智能体平台）+ Microsoft IQ（Work IQ / Fabric IQ / Foundry IQ 构成的上下文知识层，Build 2026 宣布 GA）+ Copilot 入口，三层打通
  • 模型开放策略：Azure OpenAI in Foundry Models 提供 OpenAI 模型（独家云地位），同时引入第三方模型（2026-10 博客宣布 Anthropic Claude Opus 5.5 上线 Foundry），走"模型货架"路线
  • 基础设施军备：从数据中心到自研芯片（silicon to systems）全栈优化，区域数量号称全球云厂商最多，主攻 AI 训练/推理工作负载
  • 混合云与多云：Azure Arc / Azure Local / Azure Stack 系列把云能力延伸到本地与边缘，绑定企业存量 IT
  • 开发者生态：GitHub Copilot、VS Code、AKS 组成开发者入口；2026 年获 Gartner 容器管理魔力象限领导者

二、产品分类

AI 与机器学习

  • Microsoft Foundry：AI 应用与智能体工厂，统一模型目录、智能体运行时与治理（原 Azure AI Foundry）
  • Foundry Models / Azure OpenAI in Foundry Models：多模型调用服务，含 OpenAI 系列与第三方模型
  • Foundry Agent Service：托管智能体服务，自动化复杂业务流程
  • Foundry IQ / Foundry Control Plane：智能体统一知识层；跨组织观察、管控、治理智能体
  • Azure Machine Learning：企业级端到端机器学习生命周期平台
  • Azure AI Search：面向 RAG 与智能体的统一检索层
  • Phi open models：微软自研小语言模型（SLM）系列，主打低成本低时延

数据与分析

  • Microsoft Fabric：AI 驱动的一体化数据平台，统一数据湖、数仓、BI
  • Power BI：交互式数据可视化与报表
  • Azure Synapse Analytics / Azure Databricks / Azure Data Factory：分析、Spark 数据工程、混合数据集成
  • Microsoft Purview：数据治理与合规

计算与容器

  • Virtual Machines / Azure Compute Fleet / Spot VMs：按需与规模化算力
  • Azure Kubernetes Service (AKS)：托管 Kubernetes，容器管理领导者象限产品
  • Azure Container Apps：Serverless 容器应用平台（Container Apps Sandboxes 已 GA，为 AI 智能体提供隔离沙箱）
  • Azure Functions：事件驱动 Serverless 计算

数据库

  • Azure SQL 系列：SQL Database / Managed Instance，托管 SQL Server 云化
  • Azure Cosmos DB：全球分布式多模型 NoSQL 数据库
  • Azure HorizonDB（预览）：新一代 PostgreSQL 云数据库，面向关键任务应用
  • Azure Database for PostgreSQL / MySQL、Azure Managed Redis：开源数据库托管

存储与网络

  • Azure Blob Storage / Files / Disk Storage / Elastic SAN：对象/文件/块/云原生 SAN 存储
  • Azure Virtual Network / ExpressRoute / Front Door / Firewall：虚拟网络、专线、CDN 入口与云防火墙

安全与身份

  • Microsoft Entra ID（原 Azure AD）：身份与访问管理
  • Microsoft Sentinel：云原生 SIEM 与安全分析
  • Microsoft Defender for Cloud / Security Copilot：多云混合防护、生成式 AI 安全助手
  • Azure Key Vault：密钥与机密管理

混合云与边缘

  • Azure Arc：跨本地、多云、边缘的统一管理平面
  • Azure Local / Azure Stack Hub / Azure Stack Edge：本地分布式云、一体机、边缘计算设备

开发者工具与 IoT

  • Visual Studio / VS Code、Azure DevOps、GitHub Copilot：开发工具链与 CI/CD
  • Azure IoT Hub / IoT Operations / Digital Twins：物联网连接、边缘智能与数字孪生

三、服务分类

云资源服务（IaaS/PaaS）

  • 按量付费（Pay-as-you-go）、预留实例、Spot 折扣等多种计费模式
  • Azure Free：新用户 30 天免费试用额度

AI 平台服务

  • Foundry Models 按 token 计费的模型推理服务（OpenAI + 第三方模型）
  • Foundry Agent Service 托管智能体运行服务
  • Content Safety / Observability in Foundry Control Plane：内容安全与智能体可观测服务

企业协议与支持服务

  • 企业协议（EA）等大客户采购框架；分档技术支持计划；销售专家一对一咨询
  • Microsoft Learn：免费自学式云技能培训与认证体系

开发者平台服务

  • GitHub Enterprise / GitHub Advanced Security for Azure DevOps：代码托管与安全服务
  • Microsoft Dev Box：云端即用开发工作站

四、解决方案分类

按工作负载

  • AI 应用与智能体：Microsoft Foundry + Microsoft IQ + Copilot，构建企业级生成式 AI 应用与自定义智能体
  • 数据与分析现代化：Microsoft Fabric 统一数据底座，近实时分析洞察
  • 应用现代化：AKS + Container Apps + App Service，支持开源框架（Ray、vLLM、KAITO）跑关键 AI 应用
  • 上云迁移与灾备：Azure Migrate、Azure Site Recovery、Azure Data Box（离线大数据迁移）
  • 基础设施韧性：Azure Infrastructure Resiliency Manager，面向现代化改造的韧性目标管理

混合云/多云方案

  • Azure Arc 统一管理本地、边缘与其他云资源；Azure Multicloud Interconnect 跨云互联
  • Azure VMware Solution / Nutanix Cloud Clusters：存量虚拟化负载平移上云

行业方案

  • 医疗：Azure Health Data Services（PHI 数据）、Health Bot（虚拟医疗助手）
  • 能源：Microsoft Energy Data Services（能源数据现代化）

  • 官网客户案例覆盖制造（Fortune Brands）、医疗（Solv）、化工（Syensqo 基于 Azure OpenAI Service 构建 SyGPT）等

六、总结

强势业务或产品推荐

  • Microsoft Foundry：Azure AI 战略的核心载体，"模型目录 + 智能体运行时 + 治理"一体化，是观察企业级 AI 落地进度的最佳窗口
  • Azure OpenAI in Foundry Models：OpenAI 独家云分发 + 第三方模型上架，模型货架模式护城河明显
  • AKS + Container Apps：容器管理层 2026 Gartner 领导者象限，AI 工作负载容器化（Ray/vLLM/KAITO）增长动能强
  • Microsoft Fabric：数据分析一体化平台，与 Foundry 共同构成 AI 数据闭环

强势战略留意

  • Microsoft IQ（Work IQ / Fabric IQ / Foundry IQ）：Build 2026 推出 GA 的上下文知识栈，意在让"智能体理解企业上下文"成为平台级壁垒，是 Copilot 与 Foundry 之间的关键粘合层
  • 更名与整合信号：Azure AI Foundry → Microsoft Foundry、Azure AD → Entra 等品牌去 Azure 化，说明 AI/安全产品线正被拔高到公司级平台定位
  • 自研芯片与数据中心扩张：AI 云增速依赖巨额资本开支，其回报率是判断 Azure 长期竞争力的核心变量
  • 模型中立化：引入 Claude 等第三方模型，短期扩大模型货架吸引力，长期需观察与 OpenAI 独家关系的演变
