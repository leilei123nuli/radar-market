一、公司概况

主营业务与产品服务

Anthropic 是一家以安全为核心的前沿 AI 公司（公共利益公司 PBC 架构），底层是 Claude 系列基础模型（官网模型线分 Mythos / Fable / Opus / Sonnet / Haiku 五档），向上分为三层业务：消费者/办公产品（Claude 应用、Claude Design 等）、Agent 产品（Claude Code、Claude Cowork、@Claude）、开发者/企业平台（Claude Platform API、多云分发）。2026 年 9–10 月密集发布 Opus 5.5 / Sonnet 5.5 / Haiku 5.5，主打更快、更便宜的 5.5 代。

整体战略方向

  • 安全对齐立司：Responsible Scaling Policy、Alignment Science、Claude's Constitution 等公开承诺是品牌核心，安全叙事直接服务企业采购决策
  • 企业级优先：Enterprise 方案、行业 Verification Program（网络安全、生命科学）、与 Barclays 等大客户共建，走"高信任企业市场"路线
  • Agent 化产品形态：Claude Code（编程智能体）+ Claude Cowork/任务托管，把 Claude 从问答助手升级为"交任务"的工作执行体
  • 多云中立分发：同时上架 Amazon Bedrock、Google Cloud、Microsoft Foundry，不与单一云绑定
  • 科学发现新方向：Claude Science 产品线 + 用 Claude 发现新型 CRISPR 类酶系统，切入 AI for Science
  • 人才与生态投入：出资 1 亿美元培训 1 万名工程师，设 Frontier Academy / Campus / Startups 等项目，补企业 AI 人才缺口

二、产品分类

消费级/办公产品

  • Claude：核心助手应用（Web/桌面/移动端），支持任务托管、定时任务、语音、Memory
  • Claude Design / Slides / Docs：设计、幻灯片、文档生成（Pro 及以上）
  • Artifacts：可分享的交互式作品（图表、页面、应用原型）
  • Claude in Chrome：浏览器内助手
  • Claude for Microsoft 365 / Outlook：嵌入微软办公套件
  • @Claude：Slack 内 @ 唤起的工作助手（Team/Enterprise 内测）

Agent / 专业产品

  • Claude Code：编程智能体，企业版为 Claude Code for Enterprise
  • Claude Cowork：任务协作/托管形态（官网说明正与 Claude 主应用合并统一）
  • Claude Science：面向科研工作者的产品线
  • Claude Security：面向安全团队的产品线（配合 Cyber Verification Program）

模型产品

  • Mythos / Fable：官网模型线最高两档（公开细节有限）
  • Claude Opus 5.5（2026-09-22）：旗舰档，官方称多数工作达 Fable 5.1 水平、运行成本比 Opus 5 低 40%
  • Claude Sonnet 5.5（2026-09-28）：主力档，比 Sonnet 5 快 30%、多数工作便宜至多 30%
  • Claude Haiku 5.5（2026-10-07）：小模型档，主打高并发、成本敏感场景

平台能力组件

  • Skills：可录制、可复用、可团队分发的技能包
  • Connectors / Plugins：连接器与插件市场（含 MCP）
  • Computer use（beta）/ Browser use：屏幕与浏览器操作能力

三、服务分类

订阅服务

  • Claude Free / Pro（$20/月，年付折 $17）/ Max（$100/月起，5x/20x 用量）：C 端与个人重度用户分层
  • Team / Enterprise：团队与企业版，含 SSO、审计日志、SCIM、合规 API、SIEM 对接（OpenTelemetry）等管理功能

平台/API 服务

  • Claude Platform：模型 API 按量计费，Console 控制台，上下文窗口最高 1M tokens
  • Marketplace：第三方连接器/插件/技能市场
  • Claude Academy / 培训认证：开发者与用户教育（Claude Academy、Courses、Tutorials）

云分发服务

  • Claude on AWS（Bedrock）、Google Cloud（Vertex AI）、Microsoft Foundry：三大云渠道分发同一模型

生态与人才项目

  • Frontier Academy / Campus / Scientists / Startups：面向工程师、校园、科研、创业者的支持项目（含 1 亿美元人才培训投入）

四、解决方案分类

通用解决方案

  • AI Agents：企业智能体落地
  • Coding / Code modernization：编程与遗留代码现代化（Claude Code 为核心）
  • Customer support / Sales / Commerce：客服、销售、电商场景
  • Cybersecurity：安全运营，配套 Cyber Verification Program（向合格安全专家开放高阶能力）

行业解决方案

  • Financial services：金融服务（标杆客户 Barclays 已规模化部署）
  • Government：政府
  • Healthcare / Life sciences：医疗与生命科学（配套 Life Sciences Verification Program）
  • Higher education / K-12 teachers：高等教育与 K-12（含专门条款）
  • Legal：法律
  • Nonprofits / Small business：非营利组织与中小企业

信任与合规方案

  • Enterprise Frontier Safeguards：与企业客户共建的前沿模型安全措施
  • Model Hardware Standard（预览中）：模型硬件标准
  • 区域合规 / 安全合规页：Regional compliance、Security and compliance 等企业采购支持材料

六、总结

强势业务或产品推荐

  • Claude Code：编程智能体头部产品，企业版 + 微软 365/Chrome 全入口分发，是 Anthropic 增长最快的抓手，值得重点跟踪
  • Opus/Sonnet/Haiku 5.5 代：一个月内三档齐发且"更快更便宜"，成本曲线攻势明显
  • Enterprise + Verification Program 组合拳：用安全合规资质换金融、政府、生命科学等高信任行业订单，差异化于 OpenAI 的消费者路线

强势战略留意

  • 安全品牌即商业策略：RSP、对齐科学、宪法 AI 等投入直接转化为企业信任溢价，2026 版 Usage Policy 持续加码（反影响行动、武器软件、监控条款细化），留意其是否继续兑现
  • 网络安全升为一级战略：Cyber Mission（CIDP 关键基础设施防御 + OSS Scanner 开源扫描）把 Claude 推向 OT/关基防御一线，11 家安全巨头背书，是 Cyber Verification Program 之后的又一次能力开放
  • Genesis Mission 1.5 亿美元承诺 + Claude Science：绑定联邦科研体系（NASA/NIH/NSF 等 15+ 机构），AI for Science 从产品线升级为政府级入口
  • 多云中立（AWS + Google + Microsoft 同时上架）与"亚马逊/谷歌双加持"资本结构的关系演变
  • Mythos/Fable 高档模型线公开信息极少，留意后续发布节奏
  • 1 亿美元人才培训计划：意在缓解企业 AI 人才缺口、锁定下一代工程师生态
