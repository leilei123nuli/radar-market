一、公司概况

主营业务与产品服务

Broadcom Inc.（NASDAQ: AVGO，CEO：Hock Tan 陈福阳）是"半导体 + 基础设施软件"双轮巨头，2025 财年收入约 639 亿美元（半导体解决方案约 369 亿 + 基础设施软件约 270 亿）。半导体侧两大 AI 支柱：定制 AI 加速器（XPU/ASIC）——为谷歌 TPU、Meta MTIA 等联合设计，2026 年确认 OpenAI 为第六家超大客户（百亿美元级推理芯片，约 10GW 规模，2026 下半年量产），另含 Anthropic、Fujitsu（2nm FUJITSU-MONAKA SoC）等；AI 集群网络芯片——Tomahawk / Jericho 以太网交换/路由芯片是超大 AI 集群的事实标准。软件侧为 2023 年收购的 VMware，已全面转向订阅制，主打 VMware Cloud Foundation（VCF）私有云平台；另有大型机软件（原 CA）、企业安全（Symantec/Carbon Black）等。

整体战略方向

  • AI 半导体爆发式增长：FY2026 AI 半导体收入指引上调至约 580 亿美元，并首次给出 FY2027 约 1150 亿、FY2028 约 2300 亿美元的多年目标，称供应已锁定至 2027 年、客户部署规划合计约 30GW
  • 定制 XPU 路线：主张超大客户"自研芯片必须依赖 Broadcom 联合设计"（人才、量产、封装、网络门槛），靠硬件-软件协同优化绑定客户
  • 以太网开放阵营：以 merchant silicon + 开放标准对抗 NVIDIA 垂直整合（NVLink/UALink），主推 Ethernet 覆盖 AI scale-up / scale-out / scale-across
  • 软件高毛利化：VMware 取消永久授权、强制订阅并捆绑至 VCF，定位为"AI 软件与物理芯片之间的永久抽象层"，同时持续并购整合式资本配置

二、产品分类

AI / 数据中心半导体

  • 定制 XPU / ASIC：与超大客户联合设计的 AI 加速芯片（谷歌 TPU、Meta MTIA、OpenAI 推理引擎等），采用 3.5D XDSiP 先进封装，2nm 平台已流片出货（Fujitsu SoC）
  • Tomahawk 系列交换芯片：Tomahawk 6 达 102.4 Tbps，2026 年 3 月量产，为带宽最高的商用以太网交换芯片；另有 Tomahawk Ultra
  • Jericho 系列路由/fabric 芯片：Jericho4（3nm），面向百万级 XPU 规模集群互联
  • AI 网卡与 PCIe/CXL：800G AI NIC、PCIe switches/retimers、ExpressFabric
  • 光互联：400G Optical DSP（OFC 2026 首发）、co-packaged optics（CPO 共封装光学）、光纤模块与组件、SerDes IP

网络与连接芯片

  • Ethernet 控制器/适配器、PHY 与 PoE、车载以太网
  • 宽带接入：cable、xPON、xDSL、机顶盒芯片

无线与射频

  • Wi-Fi / Bluetooth 组合芯片（Wi-Fi 8 生态）、无线局域网基础设施
  • RF 前端模块与 FBAR 滤波器、GNSS/GPS SoC、毫米波、触控 ASIC、无线充电 ASIC

存储芯片

  • SAS/SATA 控制器、RAID 控制器/RAID-on-Chip、HBA、NVMe switch adapter、SAS expander
  • Fibre Channel（原 Brocade）：HBA、directors、SAN 交换机、光模块

光电器件与工业

  • 光学传感器（环境光/接近/ToF 3D）、运动控制编码器、LED 与显示器件、光耦

基础设施软件产品

  • VMware Cloud Foundation（VCF 9.x）：私有云平台（vSphere 计算、vSAN 存储、NSX 网络、Tanzu 容器），VCF 9.1 面向大规模 AI 部署
  • 大型机软件（原 CA）：DevOps、数据库管理、Workload Automation、Watchtower 可观测性、安全
  • 企业安全：Carbon Black 端点威胁检测/响应、Symantec 网络安全
  • 身份与 API 安全：SiteMinder、VIP、PAM、IGA、Layer7 API Security
  • IT 运营软件：AIOps/可观测性、自动化、FinOps、Value Stream Management、支付安全

四、解决方案分类

AI 数据中心基础设施方案

  • 整套以太网 AI 网络：Tomahawk（交换）+ Jericho（路由/fabric）+ 800G NIC + 光互联，覆盖 scale-up / scale-out / scale-across
  • 定制 XPU 一体化方案：从芯片设计到 HBM 集成、先进封装、量产的 turnkey 交付

私有云 / 私有 AI 云方案

  • VMware Cloud Foundation：把 CPU、GPU、存储、网络整合为统一私有云，承接企业传统负载与 AI 负载

企业安全与身份方案

  • 端点安全（Carbon Black）、网络安全（Symantec）、身份治理与特权访问（IGA/PAM/VIP）

大型机现代化方案

  • 大型机 DevOps、可观测性（Watchtower）、 workload 自动化与安全合规

六、总结

强势业务或产品推荐

  • 定制 XPU/ASIC：约七成定制 ASIC 市场份额，谷歌 TPU 为核心基本盘，OpenAI/Anthropic/Meta 多点开花，订单能见度到 2028
  • AI 以太网网络芯片：Tomahawk 6 / Jericho4 垄断级地位，AI 集群扩建的直接受益者
  • VMware（VCF）：订阅迁移完成后成为高毛利现金牛（调整后 EBITDA 利润率约 68%）

强势战略留意

  • FY2027 约 1150 亿 / FY2028 约 2300 亿美元 AI 收入目标能否兑现——押注约 30GW 客户部署，是全行业最激进的 AI 指引
  • 以太网开放阵营 vs NVIDIA NVLink/UALink 的 scale-up 之争，决定网络侧份额走向
  • OpenAI 约 10GW 推理芯片 2026 下半年量产爬坡进度；2nm XPU 与 CPO 共封装光学落地
  • 风险点：客户高度集中、全部先进制程依赖台积电、VMware 订阅强推引发的客户流失与监管审查、AI 资本开支波动
