版本：v2 | 更新日期：2026-10-09 赛道：3. 云 / 开发者基础设施 | 地区：国外 | 类型：龙头 | 成立：2012 护城河：企业数据云入口 + Cortex AI

一、公司概况

主营业务与产品服务

Snowflake 是"AI Data Cloud"（AI 数据云）厂商：核心是全托管、跨云（AWS / Azure / GCP）的企业数据平台，向上叠加 Cortex AI（在 SQL / API 内直接调用业界主流大模型）与 Snowflake Intelligence（企业级自然语言智能体），并通过 Snowflake Marketplace 形成数据 / 应用 / agent 的分发生态。商业模式为按量计费（compute 按消耗 + storage 按 TB/月）。

经营近况（据公开财报报道，FY2026 至 FY2027 上半年）：FY2026 Q4 产品收入约 12.3 亿美元（同比 +30%），净收入留存率（NRR）125%，剩余履约义务（RPO）97.7 亿美元（同比 +42%）；FY2027 Q1 产品收入增速回升至 +34%，并与 AWS 签下约 60 亿美元多年期协议；FY2027 Q2 产品收入约 14.9 亿美元（同比 +37%），超 9100 个账户使用其 AI 功能，Snowflake Intelligence 上线三个月获近 2500 个账户采用。

整体战略方向

  • 定位从"云数据仓库"→"数据云"→"AI Data Cloud"，主打把企业数据直接变成 AI / agent 可用的资产
  • Agent 化入口：Snowflake Intelligence（企业智能体）+ CoWork（个人 AI agent）+ CoCo（编码 agent），争夺"企业 AI 入口"
  • 模型中立：Cortex AI 托管多家主流模型（Claude、GPT、Kimi 等），不与单一模型厂绑定
  • 开放互操作：支持开放表格式（Iceberg），以 Marketplace 生态强化网络效应
  • 向事务型扩展：推出 Snowflake Postgres，把生产级 Postgres 纳入 AI Data Cloud，模糊 OLTP/OLAP 边界

二、产品分类

数据平台核心

  • Snowflake Platform：全托管跨云数据平台，serverless 能力，免基础设施运维
  • Snowgrid：跨云、跨区域的数据共享与复制，支撑业务连续性
  • Snowflake Postgres：新推出的生产级 Postgres，与分析负载同平台运行
  • Horizon Catalog：统一治理目录（数据发现、合规、访问历史、对象标签）

AI / Agent 产品

  • Snowflake Intelligence：企业智能体，全员用自然语言查询企业数据并采取行动
  • Cortex AI：在 SQL / API 内调用业界主流 LLM（近期上架 Anthropic Claude Sonnet 5.5 / Opus 5.5、OpenAI GPT-6 Sol / Luna、Moonshot Kimi K3），支持多模态数据分析与 agent 构建，全程在 Snowflake 安全边界内运行
  • Snowflake CoWork：个人 AI agent（官网解决方案页展示的新产品）
  • Snowflake CoCo：治理化的 AI 编码 agent（官网解决方案页展示的新产品）

开发者产品

  • Snowpark：开发者数据处理框架
  • Streamlit in Snowflake：数据应用构建
  • Native Apps：在平台内构建与分发应用
  • Hybrid Tables / Iceberg 支持：混合负载与开放表格式

生态产品

  • Snowflake Marketplace：连接 820+ 提供商、3400+ 个 AI-ready 的数据 / agent / SaaS 产品，支持企业自建内部 Marketplace

三、服务分类

平台云服务

  • 全托管数据云服务：计算按量计费、存储按 TB/月计费
  • 跨云部署与灾备：AWS / Azure / GCP 多区域，Snowgrid 复制保障业务连续性
  • Cost Management Interface：内置 FinOps 成本可视、控制与优化

安全与治理服务

  • 端到端加密、RBAC、网络策略、多因素认证、数据脱敏
  • Horizon Catalog 统一治理与合规工具

可观测性服务

  • 基础可观测性：metrics / traces / logs / 通知告警
  • 基础设施、数据管道、应用、AI 四层可观测性（含 AI agent 评估与改进）

六、总结

强势业务或产品推荐

  • Cortex AI：模型中立的"数据旁 AI"路线，直接变现存量企业数据；多家前沿模型上架速度快（Claude 5.5 系、GPT-6、Kimi K3 同期上线），是 AI 收入增长的核心引擎（9100+ AI 账户）
  • Snowflake Intelligence：企业 agent 入口级产品，上线三个月近 2500 账户采用，渗透速度值得持续跟踪
  • Snowflake Marketplace：820+ 提供商的网络效应，数据云护城河的主要来源

强势战略留意

  • 增速重新加速（FY27Q2 产品收入 +37%）验证"AI 拉动数据云"逻辑；留意 NRR 125% 与 RPO 高增能否持续
  • Agent 产品线（Intelligence / CoWork / CoCo）：从"数据平台"向"企业 AI 入口"跃迁的关键动作，与微软 Copilot、OpenAI 企业版正面竞争
  • 与 AWS 的 60 亿美元协议：深度绑定底层云的同时保持跨云叙事，竞合关系演变值得留意
  • Snowflake Postgres：向事务型数据库扩张，若成功将显著扩大 TAM，也会加剧与 Postgres 生态厂商的竞争
  • 开始上线自研模型（Snowflake Decision 决策模型，私有预览）：在"模型中立托管"之外补自研专用模型，覆盖高并发低成本决策场景，与托管第三方模型形成互补，留意自研与中立定位的平衡
