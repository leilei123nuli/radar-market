DeepSeek 深度求索

版本：v1（首次建档） | 建档日期：2026-10-08 赛道：1. AI / 模型 / AI 平台 | 地区：国内 | 类型：新型 | 成立：2023 护城河：极致低成本训练 + 开源，V3/R1 改写成本曲线

一、公司概况

主营业务与产品服务

DeepSeek（杭州深度求索人工智能基础技术研究有限公司）由幻方量化孵化，2023 年 7 月成立于杭州，创始人梁文锋，专注大语言模型与多模态 AI 技术研究。业务分三层：底层是 DeepSeek 系列开源基础模型（V 系列通用模型、R 系列推理模型，当前主力为 V4 系列）；C 端是 DeepSeek 助手（App/Web，chat.deepseek.com）；B 端/开发者是 DeepSeek API 开放平台（platform.deepseek.com），兼容 OpenAI/Anthropic 接口格式。2026 年 6 月完成首轮外部融资约 510 亿元（投后估值近 4000 亿元，投资方含腾讯、宁德时代、京东、网易、IDG、国家 AI 产业投资基金等），7 月被彭博报道已启动 IPO 筹备。

整体战略方向

  • 开源开放为核心战略：模型权重持续开源、免费商用，用开源换生态标准地位与全球影响力
  • 极致成本效率：从 V3/R1 起以极低训练/推理成本改写行业成本曲线，API 定价维持行业低位（硬盘上下文缓存、峰谷分时定价进一步压价）
  • Agent 化转型：V4 系列重点强化 Agent 能力（工具调用、代码智能体），并开源 DeepSeek Harness 智能体框架，从"模型提供方"向"Agent 开发生态"延伸
  • 长期主义研究导向：使命指向 AGI，早期不融资、不设 KPI 式商业化，2026 年起融资与 IPO 筹备标志商业化提速

二、产品分类

C 端产品

  • DeepSeek 助手（App/Web）：chat.deepseek.com，免费对话产品，2025 年 1 月 R1 发布后曾登顶美区 App Store 免费榜；第三方报告称月活过亿

模型产品（API 在售）

  • DeepSeek-V4-Pro（API 名 deepseek-v4-pro，当前版本 V4-Pro-0813）：旗舰通用模型，2026-08-13 GA，Agent 能力大幅强化，支持 thinking 低/高/最高三档推理强度
  • DeepSeek-V4.1-Flash（API 名 deepseek-flash）：2026-09-10 发布，新架构家族最小模型，原生多模态视觉理解，主打高吞吐、低成本；上一代 V4-Flash 与 V4-Flash-Vision-Exp 已退役并路由至该模型
  • 历史/开源模型线：DeepSeek-Coder（2023 首个开源代码模型）、V2/V2.5、V3 系列（V3.1 → V3.1-Terminus → V3.2）、R1 / R1-0528 推理模型；旧 API 名 deepseek-chat / deepseek-reasoner 已于 2026-07-24 停用

开发者工具

  • DeepSeek Harness：全栈插件化 Agent 框架，2026-08-13 开源开发者预览版，支持 4 种运行模式、多模型接入、跨平台兼容，是其 Agent 生态核心抓手

三、服务分类

API 平台服务

  • 模型推理 API：兼容 OpenAI Chat Completions / Anthropic 格式，原生支持 Responses API（专项适配 Codex）；1M 上下文，最大输出 384K
  • 能力接口：JSON Output、Tool Calls、Chat Prefix Completion（Beta）、FIM Completion（Beta）、Vision（V4.1-Flash）
  • 定价机制：按 token 计费，缓存命中大幅折价（硬盘上下文缓存，2024-08 首创），2026-08 起实行峰谷分时定价（低谷半价）
  • Agent 工具集成：官方支持 Claude Code、GitHub Copilot、OpenCode、Codex 等编程/智能体工具直接接入

企业/生态服务

  • 公开信息有限：官网未列出独立的企业服务条目；主要通过开源权重私有化部署 + API 服务覆盖 B 端，第三方云平台（含国产芯片厂商 Day 0 适配）广泛分销其模型

六、总结

强势业务或产品推荐

  • DeepSeek API 平台：国内开发者调用量第一梯队，低价 + OpenAI/Anthropic 双兼容 + 峰谷定价，开发者粘性最强的一环
  • V4 系列模型：V4.1-Flash 以"新架构最小模型"打出极致性价比，V4-Pro 主打 Agent 生产环境能力，开源第一梯队位置稳固
  • DeepSeek Harness：Agent 框架生态卡位动作，值得跟踪其开发者采用率

强势战略留意

  • IPO 进程：若 2026 年内递交申请，将从"幻方输血"转向公开资本市场，商业化压力与披露透明度同步上升
  • Agent 化转型：模型评测与定价体系全面向 Agent 场景倾斜，Harness 能否成为事实标准决定其生态上限
  • 融资后股东结构（腾讯/宁德时代/京东/国家队）对中立性与云厂商合作关系的长期影响
  • 开源策略的可持续性：商业化提速后是否维持权重全开源，是与 Meta Llama 路线同频的关键观察点
