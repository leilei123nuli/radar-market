一、公司概况

主营业务与产品服务

Arm（NASDAQ: ARM，总部英国剑桥，软银集团为控股股东）是全球 CPU IP 授权的事实标准：传统商业模式为 IP 授权（licensing）+ 按芯片出货量抽版税（royalty），累计出货 3500 亿+ 颗 Arm 架构芯片，覆盖 99% 智能手机，软件开发者超 2200 万。产品体系按"IP → Compute Subsystems (CSS) → 自研芯片"三层展开：CPU（Cortex-A/R/M/X、Neoverse）、GPU（Mali）、NPU（Ethos）、系统/安全 IP，以及 2026-03-24 历史性推出的首款 Arm 自研数据中心芯片 Arm AGI CPU。最新财季（Q1 FYE27，截至 2026-06-30）总营收 12.9 亿美元，同比 +22%，创单季纪录。业务叙事按三大市场组织：Cloud AI、Edge AI、Physical AI，各由一位 EVP 负责。

整体战略方向

  • "From IP to Platform"：从卖 IP 升级为平台公司，授权 IP、CSS 子系统、自研 silicon 三层并行，让客户按需求选择集成深度
  • 数据中心 agentic AI：押注"agentic AI 推高 CPU 需求"判断，以 AGI CPU（自研）+ Neoverse CSS（客户定制）双路径进攻；IDC 报告 Arm 架构加速服务器平台支出已超 x86
  • 自研芯片落地：AGI CPU 由 Meta 任联合开发 lead partner，TSMC 3nm 代工，客户需求管道已超 20 亿美元（FYE27+FYE28），2026 下半年起规模上市
  • Physical AI 生态卡位：Arm Total Design 扩展至 physical AI（80+ 公司加入），推出 Robotics Capability Framework 试图定义机器人能力分级标准
  • 边缘 AI：CSS for Mobile 2 + Arm Neural Technology（神经图形）巩固移动端，并向 AI PC（NVIDIA RTX Spark 基于 Arm CSS）延伸

二、产品分类

数据中心（Cloud & Data Center）

  • Arm AGI CPU：首款 Arm 自研数据中心 CPU/SoC，最多 136 个 Neoverse V3 核、300W TDP，主打 agentic AI 基础设施，宣称每机架性能 2 倍于 x86 平台
  • Neoverse CSS N4：可配置度最高的计算子系统，单 die 最多 128 核，支持 LPDDR6 与 PCIe Gen7，面向客户自研数据中心芯片（DPU、网络、定制计算等）
  • Neoverse CPU 平台：云厂商自研芯片底座（AWS Graviton、Google Axion、Microsoft Cobalt、NVIDIA Vera 等均基于此），累计出货超 15 亿核

移动与 PC（Mobile & PC）

  • CSS for Mobile 2：AI 原生移动计算平台（2026-09 发布），整合 CPU/GPU/系统 IP 与软件栈
  • Arm C2 CPU cluster：C2-Ultra + C2-Pro 移动 CPU 集群，双 SME2 单元，C2-Ultra 对比上代 AI 性能最高 1.7 倍
  • Mali GPUs：移动 GPU 系列；最新 Mali G2-Ultra NX 为首款集成专用神经加速器的 Mali GPU，配合 Arm Neural Technology 实现神经图形

汽车与机器人（Autonomous Machines）

  • Zena CSS：面向 AI-defined 汽车与机器人的计算子系统
  • AE technologies：面向自主负载的功能安全与实时计算技术

嵌入式与物联网

  • Cortex-A / Cortex-R / Cortex-M / Cortex-X：应用、实时、微控制器、高性能移动 CPU IP 系列
  • Ethos NPUs：端侧 AI/ML 推理 NPU（如 Ethos-U85 用于超低功耗边缘 AI SoC）

架构与系统 IP

  • Arm 架构（当前主力 Armv9，版税率更高）：指令集与架构授权
  • System IP / Security IP / Subsystem IP：互连、安全、子系统级 IP 模块

三、服务分类

  • Arm Total Access：最全量 IP + 工具 + 支持 + 培训的订阅式授权包
  • Arm Flexible Access：低成本准入，tape-out 时才付授权费，面向中小芯片公司

支持与培训服务

  • 产品支持：文档、下载、support cases、产品安全中心、生命周期状态查询
  • 培训与认证：讲师/按需技术培训、design checklists & reviews（SoC 设计专家评审）
  • Arm Approved Partners：认证设计/ISP/培训合作伙伴体系

开发者服务

  • Arm Developer Program / Arm Community：2200 万开发者生态
  • Arm AI Portal：模型、代码与工具的统一入口（2026-09 发布）
  • Arm Performix：面向 Arm 基础设施的工作负载分析与优化工具（Microsoft、MongoDB、Redis、SAP 支持）
  • 开发工具链：Keil MDK、KleidiAI、Arm Neural Graphics Development Kit、Arm MCP Server

四、解决方案分类

Cloud AI

  • 云计算 / 数据中心 AI / HPC / 电信网络：Neoverse 平台 + AGI CPU + Neoverse CSS，配套 Arm Total Design 生态协作计划（加速定制芯片从设计到量产）

Edge AI

  • 智能手机、AI PC、游戏、工业、智慧城市/家居、可穿戴、XR/AR/VR：CSS for Mobile 2、Cortex + Ethos 组合、神经图形方案（Neural Dawn 演示，与 Sumo Digital、腾讯、网易等合作落地）

Physical AI

  • AI-defined 汽车：Zena CSS + 数字座舱参考方案（与 AWS、Google、Siemens 等合作，硅前软件开发）
  • 机器人：Arm Total Design for Physical AI（80+ 成员含 AWS、NXP、QNX、Unitree、Hugging Face 等）+ Robotics Capability Framework 能力分级框架

生态合作方案

  • 超大规模客户联合开发：Meta（AGI CPU 多代路线图）、NVIDIA（Vera CPU 量产、RTX Spark）、AWS/Google/Microsoft 自研 Arm 芯片
  • 与 Qualcomm 等授权客户并存竞合：Qualcomm 宣布基于 Arm 进入数据中心 CPU 市场（Dragonfly C1000）

六、总结

强势业务或产品推荐

  • Neoverse 数据中心平台：版税同比翻倍以上增长，15 亿核出货且增速加快，是版税结构升级的核心引擎
  • Arm AGI CPU：公司史上首款自研芯片，需求管道超 20 亿美元，决定未来两年营收弹性
  • CSS（Compute Subsystems）全线产品：授权单价与版税率双高的载体，云/移动/汽车三线均已落地

强势战略留意

  • 自研 silicon 与授权客户的竞合边界：AGI CPU 让 Arm 从"卖图纸"变成"卖芯片"，与 Qualcomm、Marvell 等客户部分市场正面重叠，生态反噬风险值得持续跟踪
  • "agentic AI 吃 CPU"的叙事兑现度：该逻辑是 AGI CPU 与 Neoverse 增长的共同前提，关注云厂商实际部署数据
  • Physical AI 标准卡位：Robotics Capability Framework 若成为行业语言，将复制其在移动端的架构话语权
  • 软银控股结构与资本运作：控股股东利益与其他股东的潜在冲突（公司在 20-F 风险因素中自列）
