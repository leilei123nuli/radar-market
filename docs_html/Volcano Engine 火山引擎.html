版本：v1（首次建档） | 建档日期：2026-10-08 赛道：3. 云 / 开发者基础设施 | 地区：国内 | 类型：龙头 | 成立：2020 护城河：字节系，豆包模型 + 低价策略抢份额

一、公司概况

主营业务与产品服务

火山引擎是字节跳动旗下云与 AI 服务平台，定位"你的 AI 云"，主张"模型、工具、应用到云底座，企业 AI 一站构建"。业务分两层：底层是 IaaS/PaaS 云基础设施（云服务器、对象存储、云数据库等）；上层是 AI 主线——以字节自研豆包大模型系列为核心，通过"火山方舟"一站式大模型服务平台对外输出模型 API、训练与应用构建能力，并向上延伸出 Agent 平台（AgentKit、Managed Agents、HiAgent）、AI 开发工具（TRAE CN）与行业 AI 应用（剧创 Agent）。

整体战略方向

  • 全面转向"AI 云"叙事：官网首页即主打"AI 云让 Agent 更快上线、更稳运行、更易扩展"，把 Agent 落地作为云的核心卖点
  • 模型高频迭代 + 激进定价：豆包大模型以 Evolving 方式持续更新（聚焦 Coding & Agent 场景），配合低价/免费额度策略（如方舟 Agent Plan 限时 9.9 元起、每日免费 Tokens）抢开发者与企业份额
  • 工具链生态绑定：方舟 CLI 支持 Claude Code、Cursor、TRAE 等主流开发工具，降低接入门槛，争夺 Agent 开发入口
  • 安全可信做企业级背书：构建"模型可信—智能体可控—运营安全"三层防护体系，强调已获 Gartner、IDC、信通院等 20+ 项认证

二、产品分类

大模型产品（豆包系列，经火山方舟提供）

  • Doubao-Seed 系列（豆包大模型）：旗舰语言模型，含 Seed-Evolving、Seed-2.1-pro/turbo、Seed-Character 等版本，主打 Coding & Agent 场景
  • Doubao-Seedance 系列：视频生成模型，Seedance 2.5 支持 30 秒超长叙事与全模态参考
  • Doubao-Seedream 系列：图像创作模型，Seedream 5.0 支持联网检索的智能可控创作
  • Doubao 语音模型：声音复刻、语音合成、流式语音识别、录音文件识别 2.0
  • Doubao-embedding-vision：多模态向量模型

Agent / AI 应用产品

  • 火山方舟：一站式大模型服务平台，模型广场 + API + 训练 + 应用实验室

  • Managed Agents：全托管 AI Agent 服务，覆盖 Agent 构建到部署
  • HiAgent："1+N+X"一站式智能体工作站
  • TRAE CN：AI 编程工具（The Real AI Engineer），面向 Vibe Coding 全流程
  • 剧创 Agent：企业级一站式 AI 短剧创作平台

三、服务分类

模型与推理服务

  • 模型 API 按量付费：语言/视频/图像/语音/向量模型在线推理，支持上下文缓存计费
  • 包天预付费（TPM 计费）：面向稳定并发场景的吞吐保障
  • 模型单元：独占算力包月/按小时，适合精调后模型的私有化推理
  • 免费额度：各模型 50 万 tokens 或等量额度，联网插件 2 万次/月

Agent 与开发服务

  • 方舟 CLI：命令行完成认证、模型调用与资源管理，兼容 Claude Code、Cursor、TRAE
  • 应用实验室 / 最佳实践：提示词指南、快速开始等应用构建支持
  • 协作奖励计划：开发者免费 Tokens 激励

安全与可信服务

  • Jeddak AICC、大模型安全测评：模型与算力可信底座

  • 安全运营智能体、飞连智能体：7×24 小时企业安全运营

六、总结

强势业务或产品推荐

  • 火山方舟 + 豆包大模型：模型—平台—定价一体化打法，低价 + 免费额度是国内抢开发者份额最激进的组合之一，值得跟踪其模型迭代节奏与价格变动
  • Agent 平台矩阵（AgentKit / Managed Agents / HiAgent）：全托管 Agent 是"AI 云"叙事的落地抓手，覆盖从开发到部署的完整链路

强势战略留意

  • "企业 AI 一站构建"的全栈打法：模型、工具（TRAE/CLI）、应用、云底座四层通吃，正面与阿里云百炼、腾讯云 TI 竞争
  • 低价策略的可持续性：Agent Plan 9.9 元起、每日免费 Tokens 等补贴动作，观察其对国内模型 API 价格体系的冲击
  • Seedance / Seed 系列的高频迭代与 IP 合作（如 Seedance X 周星驰经典电影 IP），字节内容生态与云业务的协同值得留意
  • 与字节跳动内部流量/开发工具的绑定（TRAE、CLI 兼容 Claude Code、Cursor）是差异化分发优势
